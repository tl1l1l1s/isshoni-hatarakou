# 뽀모도로

뽀모도로 창에서 집중과 휴식 시간을 정해 타이머를 돌린다. 도는 동안 창에 남은 시간과 바퀴가 보이고 실행 화면 머리 위에 남은 분이 보인다. 단계가 끝나면 알림과 소리가 나고 다음 단계로 넘어간다.

## Sub-features

- `pomodoro-start`는 프리셋이나 직접 정한 시간으로 시작하는 것이다 (FOC-07).
- `pomodoro-control`은 일시정지, 다시 시작, 건너뛰기, 끝이다 (FOC-07).
- `pomodoro-end`는 집중이 끝나면 알림이 뜨고 짧은 휴식이 바로 시작하는 것이다 (FOC-07).
- `pomodoro-bubble`은 도는 동안 머리 위에 남은 분이 보이는 것이다 (FOC-06, FOC-07).
- `pomodoro-stale`은 앱을 끈 사이나 절전 중에 끝난 지 1분이 넘은 타이머를 알리지 않고 끝내는 것이다 (FOC-07).

## How to get to it (user POV)

- 실행 화면 ▼ 메뉴에서 `포커스 기록`을 누르고 창 아래 `뽀모도로`를 누른다. 도는 동안 이 단추에 남은 시간이 함께 보인다.

## Driving it with drive.ts

Preconditions:

- 새 `verify()` 세션에서 시작하기를 눌러 실행 화면에 있다.

- **창 열기.** `const rec = await menu(s, '포커스 기록', '포커스 기록')`, `await rec.getByRole('button', { name: '뽀모도로' }).click()`, `const w = await windowTitled(s.app, '뽀모도로')`를 실행한다. `button "25 / 5"`가 눌려 있고 `spinbutton "집중 (분)"`은 25이며 꺼져 있다.
- **1분으로 시작.** `await w.getByRole('button', { name: '직접' }).click()`, `await w.getByRole('spinbutton', { name: '집중 (분)' }).fill('1')`, `await w.getByRole('button', { name: '시작' }).click()`을 실행한다. 창에 `집중 1/4`와 `0:59` 같은 남은 시간이 보이고 실행 화면 머리 위에 `집중 1분 남음`이 보인다. 포커스 기록 창 단추는 `뽀모도로 0:5N`이 된다.
- **일시정지.** `일시정지`를 누르면 `다시 시작` 단추가 생기고 머리 위 말풍선이 사라진다. `다시 시작`을 누르면 이어진다.
- **끝날 때.** 1분을 기다린다. 실행 화면에 `집중이 끝났어요. 5분 쉬어요.` 알림이 뜨고 창에 `짧은 휴식`이 보이며 머리 위가 `휴식 5분 남음`이 된다.
- **끝.** `끝`을 누르면 설정 화면과 `시작` 단추로 돌아오고 포커스 기록 창 단추는 `뽀모도로`가 된다.
- **지난 타이머.** 타이머가 도는 중에 `s.stage.evaluate`로 `window.core.ctxs.get('pomodoro').ctx.local.update('device', (l) => ({ ...l, run: { ...l.run, endsAt: Date.now() - 120_000 } }))`를 실행해 2분 전에 끝난 타이머를 넣는다. 창이 설정 화면과 `시작` 단추로 돌아오고 머리 위 말풍선이 사라지며 `휴식이 끝났어요`나 `집중이 끝났어요` 알림이 뜨지 않는다. 앱을 껐다 켜는 상황을 화면에서 만들 수 없어서 쓰는 준비 조건이다.
- **증거.** 설정 화면, 도는 창, 머리 위 말풍선, 휴식으로 넘어간 실행 화면과 창을 `s.shot`으로 남긴다.

## Gotchas

- 가장 짧은 집중이 1분이라 끝나는 순서는 1분을 기다려야 한다. `toBeVisible({ timeout: 70_000 })`으로 기다린다.
- 머리 위 말풍선은 고른 상태 말풍선보다 낮고 오늘 집중 시간보다 높다. 상태를 골라 두면 남은 시간이 가려진다.
- 앱을 껐다 켜도 이어지는지는 `verify()`가 실행마다 데이터 폴더를 지워서 이 하네스로 확인할 수 없다.
- OS 알림과 소리는 스크린샷에 남지 않는다. 스테이지 알림으로 확인한다.
