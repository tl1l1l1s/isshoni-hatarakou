# 스티커 사진

방에서 스티커 사진 창을 연 사람은 촬영 자리 네 칸 가운데 하나를 잡고 함께 찍는다. 가장 작은 번호의 자리를 잡은 사람이 진행자가 되어 방향, 컷 수, 배경, 필터, 프레임을 고르고 촬영을 시작한다. 각자 키로 자기 캐릭터만 움직이고 다른 사람의 움직임은 방에서 받아 미리보기에 그린다. 컷마다 5초를 세는 동안 배경음악이 나오고 진행자가 남긴 컷 기록으로 모든 사람이 같은 사진을 받는다. 찍은 사진은 꾸미기 탭에서 펜과 스티커로 꾸민 뒤 내려받거나 방 사람에게 보낸다. 방 밖에서는 나 혼자 찍는다.

## Sub-features

- `photo-open`은 ▼ 메뉴 `스티커 사진`으로 창을 열면 찍기 탭과 함께 찍는 사람 목록이 보이는 것이다 (COM-15).
- `photo-solo`는 방 밖에서 나 혼자 찍는 것이다.
- `photo-slot`은 방에서 창을 열면 빈자리 가운데 가장 작은 번호를 잡고 창을 닫으면 자리를 놓는 것이다.
- `photo-host`는 진행자만 설정을 바꾸고 촬영을 시작하며 진행자가 아닌 사람에게는 설정과 `촬영 시작`이 꺼져 있는 것이다.
- `photo-pose`는 A D Q E W S Space 키와 거리 단추와 자세 단추가 내 캐릭터만 움직이고 다른 사람의 자세가 미리보기에 바로 그려지는 것이다. 자세 단추는 `왼쪽으로`, `오른쪽으로`, `돌아서기`, `점프`이고 펜으로 키 없이 움직일 때 쓴다.
- `photo-countdown`은 촬영 시작 뒤 컷마다 5부터 세고 그동안 배경음악이 나오는 것이다.
- `photo-same-sheet`는 진행자가 남긴 컷 기록으로 모든 사람에게 같은 사진이 꾸미기 탭에 들어오는 것이다.
- `photo-handover`는 진행자가 자리를 비우면 다음 번호의 자리 주인이 진행자가 되어 남은 컷을 찍는 것이다.
- `photo-quota`는 하루 촬영 한도를 켜면 창에 오늘 쓴 횟수가 보이고 다 쓰면 시작하지 않는 것이다.
- `photo-invite`는 방 사람이 처음 자리를 잡으면 함께 찍자는 안내가 뜨는 것이다.
- `photo-chat-button`은 대화하기 창 도구 줄의 `📷 스티커 사진`으로 창을 여는 것이다.
- `photo-decorate`는 꾸미기 탭에서 펜으로 긋고 스티커를 붙여 옮기고 손잡이로 크기와 각도를 바꾸며 되돌리기와 앞으로가 되는 것이다.
- `photo-save`는 저장하기로 960x720(가로)이나 720x960(세로) PNG를 내려받는 것이다.
- `photo-send`는 방에 보내기로 64KB 안으로 줄인 사진을 방 사람에게 보내는 것이다.
- `photo-inbox`는 방 사람이 보낸 사진이 안내와 함께 받은 사진 탭에 들어오고 저장하기로 내려받는 것이다.
- `photo-own-frame`은 진행자가 내 프레임으로 고른 PNG를 컷마다 겹치는 것이다.
- `photo-quiet`은 회사원 모드에서 ▼ 메뉴와 대화하기 창에 스티커 사진이 없고 열려 있던 창이 닫히는 것이다.

## How to get to it (user POV)

- 실행 화면 ▼ 메뉴에서 `스티커 사진`을 누른다. 방 밖에서는 나 혼자 찍는다.
- 방 안에서 대화하기 창의 `📷 스티커 사진`을 누른다.
- 방 사람이 함께 찍자고 하거나 사진을 보내면 OS 알림을 눌러 같은 창을 연다.

## Driving it with drive.ts

Preconditions:

- 새 `verify()` 세션에서 시작하기를 누른다. 방 안 흐름은 방 창에서 `devdev`로 참여해 `가짜 친구`가 보인 뒤에 한다.
- 가짜 친구의 자리와 자세와 진행은 화면에서 만들 수 없다. 메모리 서버에 직접 쓰고 보고에 적는다. 읽기와 쓰기는 `s.stage.evaluate((p) => devHub.read(p), path)`와 `devHub.write(path, value)`이다. 촬영 기록은 `mod/photo/r/DEVDEV` 아래 `slots/<번호>`(`{ uid, at }`), `p/<번호>`(`{ x, f, z, j }`), `cfg`, `shots/<컷 번호>`에 있다. 내 uid는 `window.core.deps.uid`이다.
- 저장하기는 OS 저장 창을 띄운다. 먼저 메인에서 내려받을 자리를 정해 둔다.
  ```ts
  await s.app.evaluate(({ BrowserWindow }, dir) => {
    const ses = BrowserWindow.getAllWindows()[0]!.webContents.session;
    ses.on('will-download', (_e, item) => item.setSavePath(`${dir}/${item.getFilename()}`));
  }, s.dir);
  ```
- 음악은 들을 수 없으니 `AudioContext`를 감싸 만든 것을 남긴다. `window.__acs = []`를 두고 `window.AudioContext`를 `super` 뒤에 `__acs.push(this)`하는 하위 클래스로 바꾼다.

- **혼자 찍기.** 방에 들어가기 전에 `const w = await menu(s, '스티커 사진', '스티커 사진')`을 실행한다. `함께 찍는 사람 이름 없음`이 보인다. `1컷`과 `촬영 시작`을 누르면 `status`에 숫자가 뜨고 5초쯤 뒤 `navigation "스티커 사진"`의 `꾸미기`가 `[pressed]`가 된다.
- **자리 잡기.** 창을 열어 둔 채 방에 들어가고 `찍기` 탭을 누른다. `내가 진행해요. 설정을 고르고 촬영을 시작해요.`가 보이고 `slots/0/uid`가 내 uid이다.
- **친구 자세.** `slots/1`에 `{ uid: 'devfriend', at: Date.now() }`, `p/1`에 `{ x: -8, f: 0, z: 0, j: 0 }`을 쓴다. `함께 찍는 사람 이름 없음, 가짜 친구`가 되고 미리보기에 두 캐릭터가 겹쳐 선다. 0.1초마다 `p/1`의 `x`를 바꿔 쓰면 미리보기 canvas의 `toDataURL()`이 바뀐다.
- **내 키.** `w.getByLabel('촬영 미리보기').click()` 뒤에 `KeyD`를 세 번, `KeyQ`, `KeyW`를 누른다. `p/0`이 `{ x: 3, f: 1, z: 1 }`이 되고 `navigation "거리"`의 `상반신`이 `[pressed]`이다. `Space`를 누르면 `p/0/j`가 0보다 커진다. `p/1`은 그대로다.
- **자세 단추.** 키를 쓰지 않고 `w.getByRole('button', { name: '오른쪽으로', exact: true })`를 세 번, `왼쪽으로`, `돌아서기`, `점프`를 누른다. `p/0`이 `{ x: 2, f: 1, z: 0 }`이 되고 `j`가 0보다 크며 `돌아서기`가 `[pressed]`다. 자세는 0.1초에 한 번까지 보내서 빠르게 누른 마지막 자세는 조금 뒤에 들어온다. `expect.poll`로 기다린다. 이어서 미리보기를 누르고 `KeyE`를 누르면 `돌아서기`의 눌림이 풀린다. 자리 시각 `slots/0/at`은 `devHub.now()`보다 크지 않다.
- **진행자 설정.** `1컷`, `배경 하늘`, `흑백`, `별`(`exact: true`)을 누른다. `cfg`가 `{ n: 1, bg: '#d3e9ff', fl: 'mono', fr: 'star', t0: 0 }`이 된다.
- **찍기와 음악.** `촬영 시작`을 누른다. `컷 1 / 1 찍는 중이에요.`가 보이고 `__acs.at(-1).state`가 `running`이다. 5초쯤 뒤 `꾸미기`가 `[pressed]`가 되고 `shots/0/ppl`에 내 자세와 친구 자세 두 개가 들어 있으며 `cfg/t0`이 0으로 돌아오고 음악의 `state`가 `closed`가 된다. 기다릴 때 `timeout`을 8초 넘게 준다.
- **한도.** 방에 들어가기 전에 `mod/photo/g/tunables`에 `{ photoDailyCap: 1 }`을 쓴다. 방에서 창 아래에 `오늘 0 / 1`이 보이고 한 번 찍은 뒤 `오늘 1 / 1`이 된다. 다시 `촬영 시작`을 누르면 `alert`에 `오늘 찍을 수 있는 횟수를 다 썼어요. 오전 6시 뒤에 다시 찍어 주세요.`가 뜬다. 한도를 2로 두고 `촬영 시작`을 `dblclick()`해도 `오늘 1 / 2`가 된다.
- **자리 놓기와 채팅 단추.** `await w.close()`로 창을 닫으면 `slots/0`이 null이 된다. 친구가 남아 있으면 `cfg`는 남는다. `const chat = await menu(s, '대화하기', '대화하기')`에서 `button "📷 스티커 사진"`을 누르면 `windowTitled(s.app, '스티커 사진')`이 열리고 다시 `slots/0`을 잡는다.
- **진행자가 아닐 때.** 창을 열기 전에 친구가 `slots/0`, `p/0`, `cfg`(`{ o: 'wide', n: 2, bg: '#d5f4e5', fl: 'none', fr: 'none', own: '', t0: 0 }`)를 쓰게 한다. 창을 열면 내가 `slots/1`을 잡고 `가짜 친구님이 진행해요. 설정과 촬영 시작은 진행하는 사람이 해요.`가 보인다. `2컷`은 `[pressed]`이면서 꺼져 있고 `배경 민트`와 `촬영 시작`도 꺼져 있다.
- **친구가 찍은 컷.** `cfg/t0`에 `devHub.now()`를 쓰면 `컷 1 / 2 찍는 중이에요.`가 보인다. `컷 2 / 2`가 보이면 친구 자세와 `p/1`에서 읽은 내 자세로 `shots/0`을 쓴다. `l`은 멤버 기록의 `look`이고 없으면 빈 문자열이다.
- **진행자 넘기기.** `slots/0`과 `p/0`에 null을 쓴다. `내가 진행해요.`로 바뀌고 두 번째 셔터 시각에 내 앱이 `shots/1`을 쓴다. `shots/1`의 `t0`은 같고 `ppl`에는 나만 있다. `꾸미기`가 `[pressed]`가 되고 왼쪽 컷에 두 사람, 오른쪽 컷에 나만 찍힌 사진이 보인다.
- **초대 안내.** 방에서 `rooms/DEVDEV/ev/<devHub.pushKey()>`에 `{ t: 'photo.invite', uid: 'devfriend', p: '{}', at: devHub.now() }`를 쓴다. 사진 창이 닫혀 있으면 실행 화면에 `가짜 친구님이 스티커 사진을 같이 찍자고 해요.`가 뜬다.
- **꾸미기.** `w.getByLabel('꾸미기 캔버스')`의 boundingBox로 사진 좌표(가로 960x720)를 화면 좌표로 바꾼다. `무지개`를 누르고 마우스로 긋는다. `스티커 💖`를 누르면 `옮기기 [pressed]`가 되고 사진 가운데에 붙는다. 가운데를 끌어 옮기고 오른쪽 위 모서리 손잡이(가운데에서 크기 120의 절반만큼 오른쪽 위)를 끌면 커지고 돈다. `되돌리기`와 `앞으로`를 누른다.
- **저장.** `저장하기`를 누른다. `사진을 내려받았어요.`가 보이고 증거 폴더에 `스티커사진-날짜-시각.png`가 생긴다. PNG 머리의 너비와 높이가 960과 720이다.
- **방에 보내기.** `방에 보내기`를 누른다. `지금 방에 있는 사람들에게 보냈어요.`가 보인다. `devHub.read('rooms/DEVDEV/ev')`에 `t`가 `photo.shared`인 이벤트가 있고 그 `p`의 `file` 해시로 읽은 `devHub.read('files/<해시>')` 길이가 65536 이하이다.
- **받기.** 가짜 친구가 보낸 것처럼 `devHub.write('rooms/DEVDEV/ev/' + devHub.pushKey(), { t: 'photo.shared', uid: 'devfriend', p: JSON.stringify({ file }), at: devHub.now() })`를 쓴다. 실행 화면에 `가짜 친구님이 스티커 사진을 보냈어요.`가 뜨고 창의 탭이 `받은 사진 1`이 된다. 탭을 누르면 `img "가짜 친구님이 보낸 스티커 사진"`이 보이고 숫자가 사라진다. 목록의 `저장하기`로 파일이 하나 더 생긴다.
- **내 프레임.** `dialog.showOpenDialog`를 바꿔 테두리만 불투명한 PNG를 돌려주게 하고 진행자일 때 `내 프레임`을 누른다. `내 프레임 [pressed]`가 되고 미리보기 컷에 그 테두리가 겹친다. 방에서는 `cfg/own`에 64자 해시가 들어간다.
- **회사원 모드.** 설정 창 `화면` 탭의 `회사원 모드`를 체크한다([설정 창](./settings.md)). 열려 있던 스티커 사진 창이 닫히고 `slots`에서 내 자리가 빠진다. 대화하기 창에 `📷 스티커 사진`이 없고 ▼ 메뉴에도 `스티커 사진`이 없다.
- **회사원 모드의 알림.** 메인에서 `Notification.prototype.show`를 바꿔 알림 객체를 `globalThis.__notes`에 모은다. 회사원 모드에서 가짜 친구가 `photo.shared` 이벤트를 보내면 알림이 하나 생긴다. `s.app.evaluate(() => __notes[0].emit('click'))`로 누르면 스티커 사진 창이 열리지 않고 실행 화면에 `회사원 모드에서는 쓸 수 없어요.`가 뜬다. 회사원 모드를 끄고 새로 온 알림을 누르면 창이 열린다.
- **증거.** 혼자 찍은 사진, 방에 들어간 뒤, 친구 자세, 카운트다운, 함께 찍은 사진, 한도 안내, 진행자가 아닐 때, 넘긴 뒤 사진, 초대 안내, 채팅 단추, 회사원 모드 대화하기 창을 `s.shot`으로 남기고 `errors.json`이 `[]`인지 본다.

## Gotchas

- 자리는 창을 연 순서로 잡는다. 친구를 진행자로 두려면 창을 열기 전에 `slots/0`을 쓴다.
- 하루 한도는 창이 방 세션을 열 때 읽는다. 한도를 바꾼 뒤에는 방에 다시 들어가거나 창을 다시 연다.
- 키는 미리보기가 포커스를 가질 때만 받는다. 키를 누르기 전에 미리보기를 누른다. 자세 단추는 포커스와 상관없이 된다.
- 알림 하나는 한 번만 눌린다. 같은 알림을 두 번 누르는 대신 이벤트를 새로 보내 새 알림을 누른다.
- 창을 열어 둔 사람의 자리 시각은 5분마다 새로 쓰고 15분 지난 남의 자리는 빈자리가 없을 때만 잡는다. 15분을 기다려야 보이는 동작이라 drive 대신 `src/modules/photo/sim.test.ts`로 확인한다.
- 자세의 `x`는 -10부터 10까지 정수다. 10이면 그 사람이 칸 하나만큼 옮겨져 컷 밖으로 나간다. 소수를 쓰면 앱이 그 자세를 버린다.
- 촬영은 컷마다 5초라 4컷이면 20초 넘게 걸린다. 검증에서는 1컷이나 2컷으로 찍는다.
- 방에서 받은 사진은 64KB로 줄이면서 WebP가 될 수 있어서 저장한 파일 확장자가 `.webp`일 수 있다.
- 받은 사진은 앱을 끄면 사라진다. 새 세션에는 받은 사진이 없다.
