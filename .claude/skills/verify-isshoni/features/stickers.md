# 꾸미기

꾸미기 창에서 보관함 아이템이나 직접 그린 그림을 스티커, 책상 소품, 바닥 오브제로 캐릭터에 붙인다. 붙인 것은 미리보기에서 끌어 옮기고 손잡이로 크기와 회전을 맞춘다. 직접 그리기는 그림판을 열어 그린 부분만 스티커로 만들고 칠판 만들기는 흰 칠판에 글씨와 낙서를 해서 머리 위쪽에 붙인다. 저장하면 실행 화면 캐릭터에 바로 보이고 창을 다시 열어도 그대로 있다.

## Sub-features

- `multi-same`은 같은 보관함 아이템을 두 번 붙이고 하나만 옮기는 것이다 (AVT-19).
- `draw`는 직접 그리기 그림판에 그린 선이 `내 그림` 스티커로 붙는 것이다 (AVT-09).
- `draw-over`는 붙인 아이템을 고르고 그림에 그리기로 그 그림 위에 그리면 미리보기와 목록 그림이 바뀌고 원래 그림으로 되돌리는 것이다 (AVT-09).
- `pattern`은 그림판의 도안 불러오기로 고른 그림을 찍어 스티커로 만드는 것이다 (AVT-09).
- `board`는 칠판 만들기에서 칠판 글씨를 적고 낙서해 머리 위쪽에 칠판 스티커를 붙이는 것이다 (AVT-10).
- `floor`는 바닥 탭에서 그림 넣기, 보관함 아이템, 직접 그리기로 바닥 오브제를 놓으면 책상 앞 바닥에 보이는 것이다 (AVT-14).
- `pick-key`는 붙인 것 목록의 그림과 이름이 버튼이라 키보드로 고르는 것이다. 고른 줄은 `aria-pressed="true"`다.
- `handle-hit`은 고른 것의 손잡이가 보이는 점(16px)보다 넓게(32px) 눌리는 것이다. 그림판 색 칸도 높이 30px로 눌린다.
- `deco-save`는 저장 뒤 실행 화면에 붙인 것이 보이고 다시 연 창에 탭마다 붙인 수가 그대로인 것이다.

## How to get to it (user POV)

- 실행 화면 ▼ 메뉴에서 `꾸미기`를 누른다.
- 그림판은 꾸미기 창의 `직접 그리기`, `칠판 만들기`, 붙인 것을 고른 뒤의 `그림에 그리기`나 `칠판 새로 쓰기`로 연다. 그림판은 꾸미기 창 안에서 열리고 `완료`나 `취소`로 돌아온다.

## Driving it with drive.ts

Preconditions:

- 새 `verify()` 세션에서 시작하기를 눌러 실행 화면에 있다.
- 그림 파일 고르기 대화상자는 시험용 그림을 돌려주게 바꾼다. `tests/e2e/boot.spec.ts`의 `OffscreenCanvas`로 64px 노란 원 PNG를 만들고 `dialog.showOpenDialog`를 바꾸는 부분을 그대로 쓴다.
- 바닥 오브제가 책상 앞에 놓이는지 보려면 [캐릭터 만들기](./wardrobe.md)의 순서로 `나무 책상`을 골라 저장해 둔다.
- 보관함 아이템이 필요하면 [방 가챠의 기간 한정과 색 해금](./gacha.md)의 순서로 내 방을 만들고 방 설정에서 `별`을 넣은 뒤 작업 시간 1시간을 메모리 서버에 더하고 가챠 창에서 `1회 뽑기`를 눌러 `NEW!`를 기다린다. 작업 시간은 화면에서 만들 수 없어서 `core.deps.server.docs({ scope: 'user', module: 'gacha', uid, path: ['r'] }).update(code, { sec: { $inc: 3600 } })`로 더하고 보고에 적는다.

그림판 획은 마우스로 긋는다. 아래 `stroke`는 그림판 위 비율 좌표로 한 획을 긋는다.

```ts
const stroke = async (w: Page, label: string, x0: number, y0: number, x1: number, y1: number) => {
  const b = (await w.getByLabel(label).boundingBox())!;
  await w.mouse.move(b.x + b.width * x0, b.y + b.height * y0);
  await w.mouse.down();
  await w.mouse.move(b.x + b.width * x1, b.y + b.height * y1, { steps: 12 });
  await w.mouse.up();
};
```

- **창 열기.** `const d = await menu(s, '꾸미기', '꾸미기')`를 실행한다. 탭 `스티커 [pressed]`, `책상 소품`, `바닥`과 `직접 그리기`, `칠판 만들기`, `heading "보관함"`이 있다.
- **같은 아이템 두 번.** 보관함의 별 단추(`await d.getByRole('button', { name: /별.*방/ }).click()`)를 두 번 누른다. 붙인 것 목록의 줄도 이름이 `별`인 단추라서 이름에 방 이름까지 넣어 보관함 단추만 찾는다. `붙인 것 2개`가 보이고 목록에 `별`이 두 줄 있다. 고른 것(`d.locator('[data-on="true"]').first()`)을 마우스로 끌면 하나만 옮겨진다.
- **직접 그리기.** `직접 그리기`를 누르면 `heading "직접 그리기"`와 `canvas "스티커 그림판"`이 보인다. 붓 색 `분홍`을 누르고 `stroke(d, '스티커 그림판', 0.2, 0.3, 0.8, 0.6)`으로 긋는다. `되돌리기`가 켜진다. `완료`를 누르면 꾸미기 화면으로 돌아오고 `붙인 것 3개`와 `내 그림`이 보인다.
- **그림에 그리기.** 목록의 첫 `별`을 누르고 `그림에 그리기`를 누른다. `heading "그림에 그리기"` 그림판에 별 그림이 깔려 있다. `파랑`으로 한 획을 긋고 `완료`를 누르면 `원래 그림으로` 단추가 생기고 목록 그림과 미리보기 별에 파란 선이 보인다. 미리보기는 그림을 받은 뒤에 그려지므로 아래처럼 파란 픽셀을 기다린 뒤 찍는다.
  ```ts
  await expect.poll(() => d.evaluate(() => {
    const c = document.querySelector('canvas')!;
    const px = c.getContext('2d')!.getImageData(0, 0, c.width, c.height).data;
    for (let i = 0; i < px.length; i += 4) if (px[i + 2]! > 180 && px[i]! < 120 && px[i + 3]! > 200) return true;
    return false;
  })).toBe(true);
  ```
  `원래 그림으로`를 누르면 단추가 사라진다.
- **도안 불러오기.** `직접 그리기`, `도안 불러오기`를 누른다. 그림판에 노란 원이 꽉 차게 찍히고 `되돌리기`가 켜진다. `완료`를 누르면 `붙인 것 4개`가 된다.
- **칠판.** `칠판 만들기`를 누르면 `heading "칠판"`과 `textbox "칠판 글씨"`가 보인다. `await d.getByLabel('칠판 글씨').fill('집중하는 중\n말 걸어 줘')`를 실행하면 그림판 흰 판 가운데에 두 줄 글씨가 그려진다. 한 획을 긋고 `완료`를 누르면 `붙인 것 5개`, 목록의 `칠판`, `칠판 새로 쓰기`가 보이고 미리보기 머리 위쪽에 칠판이 붙는다.
- **바닥 오브제.** `await d.getByRole('button', { name: '바닥', exact: true }).click()`을 실행하고 `그림 넣기`를 누르면 `붙인 것 1개`가 된다. 보관함의 `별`을 누르면 `붙인 것 2개`가 된다. 미리보기에서 노란 원이 책상 왼쪽 앞 바닥에 놓인다. 바닥 탭에서 `직접 그리기`로 `주황` 대각선을 긋고 `완료`를 누르면 `붙인 것 3개`가 되고 `d.locator('[data-on="true"]')` 상자가 칸 아래쪽에 보인다. 가로로 긴 그림도 아래가 바닥에 닿는다.
- **키보드로 고르기 (pick-key).** `책상 소품` 탭에서 `그림 넣기`를 두 번 누르면 `button "내 그림"`이 둘이다. 첫 버튼에 `focus()`하고 `Enter`를 누르면 그 버튼이 `aria-pressed="true"`, 다른 것은 `false`이고 미리보기에 손잡이가 생긴다. `뒤로`, `앞으로`, `빼기`는 따로 있는 버튼이다.
- **손잡이 자리 (handle-hit).** `d.locator('[class*="handle"]')`의 너비는 16px이고 가운데에서 오른쪽 13px을 `elementFromPoint`로 보면 그 손잡이다.
- **저장과 유지.** `저장`을 누른다. 실행 화면에 `꾸미기를 저장했습니다.`가 뜨고 창이 닫힌다. 실행 화면 캐릭터 머리 위쪽에 칠판, 책상 앞 바닥에 노란 원이 보인다. 창을 다시 열면 스티커 탭 `붙인 것 5개`, 바닥 탭 `붙인 것 3개`이다.
- **증거.** 키보드로 고른 목록, 같은 아이템 두 개, 그림판 세 종류(직접 그리기, 그림에 그리기, 칠판), 각 단계 뒤의 꾸미기 창, 저장 뒤 실행 화면, 다시 연 창을 `s.shot`으로 남기고 `errors.json`이 `[]`인지 본다.

## Gotchas

- 꾸미기 창은 패널 창이라서 실행 화면 캐릭터가 바뀐 것은 저장 뒤에만 보인다. 저장 직후 실행 화면 사진은 `expect.poll`로 `window.core.self.get().appearance.slots.floor.length`가 바닥 오브제 수가 될 때까지 기다린 뒤 찍는다. 읽기만 하고 보고에 적는다.
- `그림 넣기`는 책상 소품과 바닥 탭에만 있다. 스티커 탭에서 내 그림을 붙이려면 직접 그리기나 도안 불러오기를 쓴다.
- 그림판의 `지우기`와 `지우개`는 그린 선과 찍은 도안만 지운다. 깔린 원래 그림과 칠판 판은 남는다.
- 그림판이 열린 동안 꾸미기 화면은 숨는다. `완료`나 `취소` 전에는 탭과 목록을 찾을 수 없다.
- 색조와 채도 칸은 같은 아이템을 4개 모아야 보인다. 이 순서에서는 한 번만 뽑아서 `같은 아이템을 4개 모으면` 안내가 보인다. 내 그림과 칠판은 처음부터 색을 바꿀 수 있다.
