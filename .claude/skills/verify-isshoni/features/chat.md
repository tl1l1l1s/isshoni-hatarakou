# 대화하기

방에 들어가 있으면 대화하기 창에서 메시지를 보낼 수 있다. Enter나 입력칸 옆 보내기 버튼으로 보낸다. 이모티콘은 입력칸 왼쪽 😊를 눌러야 펼쳐진다. 보낸 메시지는 대화하기 창 목록과 실행 화면의 내 캐릭터 말풍선에 함께 보인다. 목록의 이름 앞에는 프로필 사진이 있다. 보내지 못한 글은 입력칸 위에 다시 보내기와 함께 남고 창을 닫았다 열어도 남는다. 다른 방으로 옮기면 그 글은 버리기만 되고 원래 방에 돌아가면 다시 보낼 수 있다. 연결이 끊긴 동안에는 보내지 않고 그 글을 남긴다. 내 글은 바탕이 깔려 남의 글과 나뉜다. 창이 닫혀 있을 때 온 글은 OS 알림으로 30초에 한 번까지 알린다.

## Sub-features

- `chat-send`는 메시지 칸에 쓰고 Enter로 보내면 대화하기 창 목록에 보이는 것이다 (COM-01). 아직 글이 없으면 목록 자리에 `아직 대화가 없어요.`가 보인다.
- `chat-multiline`은 Shift+Enter로 쓴 여러 줄 글의 둘째 줄이 이름 아래에서 시작하는 것이다.
- `chat-emoji-toggle`은 입력칸 왼쪽 😊 단추로 이모티콘 고르기를 펼치고 접는 것이다 (COM-08). 채팅이 꺼진 방에서는 접지 않고 늘 보인다.
- `chat-bubble`은 보낸 메시지가 실행 화면 말풍선에 보이는 것이다 (COM-09).
- `chat-button`은 입력칸 옆 `보내기` 버튼으로 보내는 것이다. 입력칸이 비면 버튼이 비활성이다 (COM-01).
- `chat-photo`는 이름 앞 프로필 사진이다. 같은 사람이 이어 보낸 글에는 사진이 한 번만 있다 (SCR-03).
- `chat-offline`은 연결이 끊긴 동안 보낸 글이 목록과 말풍선에 나오지 않고 입력칸 위 알림에 `연결이 끊겨서 보내지 못했어요. 연결되면 다시 눌러 주세요.`와 함께 남는 것이다. 다시 연결된 뒤 `다시 보내기`로 보낸다 (0033).
- `chat-unsent`는 서버가 받기 전에 앱이 꺼진 글이 다음에 그 방에 들어갈 때 `보내지 못했어요. 보내는 중에 앱이 꺼졌어요.` 알림으로 돌아오는 것이다 (RES-2). 서버가 받기 전의 내 글은 목록에 흐리게 `보내는 중`으로 보이고 말풍선은 받은 뒤에 뜬다.
- `chat-mine`은 내가 보낸 글 줄에 바탕이 깔려 남의 글과 나뉘는 것이다.
- `chat-name`은 목록 이름과 OS 알림 제목이 글에 적힌 이름이 아니라 방 멤버 이름이고 방에 없는 사람은 공개 프로필 이름인 것이다.
- `chat-notify`는 창이 닫혀 있을 때 온 남의 글을 OS 알림으로 30초에 한 번까지 알리고 그사이 온 글은 30초 뒤 `새 메시지가 n개 더 왔어요.`로 한 번에 알리며 설정 일반 탭 `새 메시지 OS 알림 받기`로 끄는 것이다 (COM-01, D5). 알림은 소리가 없고 회사원 모드에서는 뜨지 않는다.
- `chat-retry`는 보내지 못한 글이 입력칸 위 알림에 `보내지 못했어요. 잠시 뒤에 다시 보내기를 눌러 주세요.`와 함께 남고 그사이 새로 쓴 입력칸 글은 그대로이며 `다시 보내기`로 보내는 것이다. 다른 방에 있으면 알림에 원래 방 코드가 보이고 `버리기`만 있으며 원래 방에 돌아가면 `다시 보내기`가 돌아온다 (COM-01).
- `chat-size`는 대화하기 창의 글자 크기를 작게, 보통, 크게, 아주 크게 가운데 고르면 목록 글자가 바뀌고 설정 창 일반 탭에도 같은 값이 보이는 것이다 (COM-04, SET-08).

## How to get to it (user POV)

- 방에 들어간 뒤 실행 화면 ▼ 메뉴에서 `대화하기`를 누른다.
- 안 읽은 글이 있으면 실행 화면 상태칩에 `💬`와 안 읽은 수가 보이고 누르면 열린다. 안 읽은 글이 없으면 이 칩은 없다. 수는 칩 오른쪽 위의 빨간 공용 배지(`[data-unread]`, 높이 16px, 11px 굵은 글자)다.
- 창이 닫혀 있을 때 온 글의 OS 알림을 누르면 열린다.

## Driving it with drive.ts

Preconditions:

- 새 `verify()` 세션에서 시작하기를 누른 뒤 [방](./rooms.md)의 코드로 참여 순서대로 `DEVDEV` 방에 들어가 있다.

- **창 열기.** `const chat = await menu(s, '대화하기', '대화하기')`를 실행한다. 안쪽 높이 600의 대화하기 창이 열리고 빈 목록에 `아직 대화가 없어요.`가 보인다. 이모티콘 단추(👍 같은 것)는 없고 `chat.getByRole('button', { name: '이모티콘', exact: true })`가 `aria-expanded="false"`다.
- **메시지 보내기.** `await chat.getByLabel('메시지').fill('검증 메시지')`와 `await chat.getByLabel('메시지').press('Enter')`를 실행한다. 대화하기 창 목록에 `검증 메시지`가 보인다.
- **말풍선 확인.** `await s.stage.getByText('검증 메시지').first().waitFor()`를 실행한다. 실행 화면에 같은 문구의 말풍선이 보인다.
- **두 줄 글 (chat-multiline).** 메시지 칸에 `줄1`을 쓰고 `Shift+Enter` 뒤에 둘째 줄을 써서 Enter로 보낸다. 둘째 줄의 왼쪽 끝이 이름(`strong`)의 왼쪽 끝과 같다. 글 칸 `[class*="text"]`의 `getClientRects()` 마지막 줄 `left`와 이름의 `left`를 비교한다.
- **이모티콘 펼치기 (chat-emoji-toggle).** `이모티콘` 단추를 누르면 `aria-expanded="true"`가 되고 이모티콘 12개와 `button "＋ 내 이모티콘 넣기"`가 입력칸 위에 보인다. 한 번 더 누르면 접힌다.
- **보내기 버튼 (chat-button).** `chat.getByLabel('메시지').fill('버튼으로 보냄')`, `chat.getByRole('button', { name: '보내기' }).click()`을 실행한다. 목록에 글이 보이고 입력칸이 빈다.
- **프로필 사진 (chat-photo).** 설정 창 `계정` 탭에서 `사진 넣기`를 하고 친구 사진을 `mod/account/u/devfriend/photo`에 쓴 뒤 친구가 글 두 개를 이어 보내고 내가 하나를 보내면 `chat.locator('[class*="msg"]').getByRole('img', { name: '프로필 사진' })`가 2개다.
- **끊긴 동안 (chat-offline).** `core.deps.server.goOffline()` 뒤 글을 써서 Enter를 누른다. 목록과 실행 화면에는 그 글이 없고 `chat.getByRole('alert')`에 `연결이 끊겨서 보내지 못했어요. 연결되면 다시 눌러 주세요.`, 그 글, `다시 보내기`, `버리기`가 보이며 입력칸은 빈다. `goOnline()` 뒤 `다시 보내기`를 누르면 목록에 보이고 알림이 사라진다.
- **다시 보내기 (chat-retry).** 보내기가 거절되는 상황은 화면에서 만들 수 없다. 스테이지에서 `devHub.write('rooms/DEVDEV/roster/<내 uid>', null)`을 부르고 글을 써서 `보내기`를 누른 뒤 입력칸에 새 글을 쓴다. `chat.getByRole('alert')`에 `보내지 못했어요. 잠시 뒤에 다시 보내기를 눌러 주세요.`와 처음 글이 보이고 서버 오류 원문(`PERMISSION_DENIED`와 경로)은 없으며 입력칸은 새 글 그대로다. 알림이 있어도 대화 목록은 세 줄 넘게 보인다. roster를 `Date.now()`로 되돌리고 `다시 보내기`를 누르면 처음 글이 목록에 보이고 알림이 사라지며 입력칸은 여전히 새 글이다.
- **다른 방에서 (chat-retry).** 알림이 남은 채 방 창에서 `방에서 나가기`와 `만들기`로 내 방을 만든다. 대화하기 창은 열린 채 알림에 `DEVDEV 방에서 보내지 못한 글이에요. 그 방에 다시 들어가면 보낼 수 있어요.`와 처음 글이 보이고 `버리기`만 있으며 `다시 보내기`가 없다. 입력칸은 새 글 그대로다. 다시 `방에서 나가기` 뒤 `devdev`로 참여하면 알림이 `보내지 못했어요.`로 돌아오고 `다시 보내기`가 보인다.
- **내 글 (chat-mine).** 내가 보낸 글 줄(`chat.locator('[class*="msg"]', { hasText })`)은 `data-mine`이 있고 `getComputedStyle`의 바탕이 `rgba(0, 0, 0, 0.05)`(밝게)다. 남의 글 줄은 바탕이 투명하다.
- **보낸 사람 이름 (chat-name).** 가짜 친구가 이름 칸을 바꿔 쓴 것처럼 `devHub.write('mod/chat/r/DEVDEV/msgs/<15자리 시각>_devfriend', { uid: 'devfriend', name: '관리자', text: '코드 보내 줘', at: devHub.now(), v: 1 })`를 쓴다. 목록의 그 글 이름(`strong`)은 `가짜 친구`다.
- **OS 알림 (chat-notify).** 메인에서 `Notification.prototype.show`를 바꿔 실제 알림 대신 `title`, `body`, `silent`를 모은다. 대화하기 창을 닫은 채 가짜 친구 글 5개를 0.4초 간격으로 위처럼 쓴다. 모인 알림은 `가짜 친구`, `메시지 1` 하나이고 `silent`가 true다. 30초 뒤 `대화하기`, `새 메시지가 4개 더 왔어요.`가 하나 더 모인다. 설정 창 일반 탭 대화하기 묶음의 `새 메시지 OS 알림 받기`를 끄면 30초가 지난 뒤 온 글에도 알림이 없다.
- **보내는 중에 끈 글 (chat-unsent).** 서버가 끊긴 줄 모르는 상태를 `core.deps.server.goOffline({ abrupt: true })`와 `core.deps.server.connection.online = () => true`로 만든다. 글을 보내면 목록에 없고 `core.ctxs.get('chat').ctx.local.get('account').out`에 그 글이 있다. `s.restart()` 뒤 시작하기를 누르면 `DEVDEV`에 다시 들어가고 대화하기 창 알림에 `보내지 못했어요. 보내는 중에 앱이 꺼졌어요.`, 그 글, `다시 보내기`가 있다.
- **글자 크기.** 대화하기 창 맨 위 `combobox "채팅 글자 크기"`는 처음에 `보통`이고 메시지 글자는 13px이다. `await chat.getByLabel('채팅 글자 크기').selectOption('xl')`을 실행하면 `getComputedStyle`로 본 메시지 글자가 18px이 된다. 설정 창 `일반` 탭의 대화하기 묶음 `채팅 글자 크기`도 `xl`이고 거기서 `l`을 고르면 열린 대화하기 창 글자가 15px이 된다. 대화하기 창을 닫고 다시 열어도 `l`과 15px이 그대로다.
- **증거.** 빈 목록 안내가 보이는 창, 두 줄 글이 보이는 창, 이모티콘을 펼친 창, 보낸 뒤 대화하기 창과 말풍선이 보이는 실행 화면, 사진이 보이는 목록, 보내지 못한 알림과 다른 방에서 본 알림과 다시 보낸 뒤 창, 글자 크기를 바꾼 대화하기 창과 설정 창을 `s.shot`으로 남긴다.

## Gotchas

- 혼자 모드에서는 메뉴의 `대화하기`와 `이모티콘`이 흐리게(`aria-disabled`) 보이고 이름 뒤에 `방에서만`이 붙는다. Playwright `click()`과 `menu()`는 흐린 항목을 누르지 못하고 시간이 지나 실패한다. `getByRole('button', { name: /^대화하기/ }).click({ force: true })`로 누르면 창 대신 실행 화면에 `방에 들어가면 쓸 수 있어요. 워킹룸에서 들어가요.`가 뜬다. 창을 열려면 먼저 방에 들어간다.
- 같은 문구가 창 목록과 말풍선에 동시에 있으니 `getByText(...).first()`로 찾는다.
- 대화하기 창의 이모티콘 고르기는 처음에 접혀 있다. 이모티콘이나 `＋ 내 이모티콘 넣기`를 누르려면 먼저 😊(`이모티콘`) 단추를 누른다. 이모티콘 창(▼ 메뉴 `이모티콘`)은 접지 않는다. `이모티콘` 이름은 `내 이모티콘` 단추와 겹치니 `exact: true`로 찾는다.
- `💬` 칩은 안 읽은 글이 있을 때만 보이므로 친구 글을 받은 뒤에 찾는다.
- 보내기 버튼 이름 `보내기`는 다른 창 버튼과 겹치지 않지만 대화하기 창 안에서 찾는다.
- 연결이 끊긴 동안 보낸 글은 바로 보내지 못한 글이 된다. 서버 거절은 연결된 채 roster를 지워서 만든다.
- 메모리 서버는 서버가 받기 전의 글을 목록에 먼저 보이지 않아서 `보내는 중` 표시는 Firebase 빌드에서만 보인다. `src/modules/chat/state.test.ts`가 그 표시와 말풍선이 받은 뒤에 뜨는 것을 본다.
- OS 알림은 30초 간격이라 알림 단계 사이에 30초를 기다린다. 대화하기 창을 열면 미뤄 둔 요약 알림은 버린다.
- 날리기를 체크하면 입력란 위에 날리는 글의 `글자 크기`가 따로 생긴다. 이 이름은 `채팅 글자 크기`에도 들어 있으니 날리는 글 크기는 `{ exact: true }`로 찾는다.
- 회사원 모드에서는 실행 화면 말풍선이 보이지 않는다. 말풍선을 확인할 때는 [설정 창](./settings.md)의 회사원 모드가 꺼져 있어야 한다.
