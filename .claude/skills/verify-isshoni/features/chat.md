# 대화하기

방에 들어가 있으면 대화하기 창에서 메시지를 보낼 수 있다. Enter나 입력칸 옆 보내기 버튼으로 보낸다. 보낸 메시지는 대화하기 창 목록과 실행 화면의 내 캐릭터 말풍선에 함께 보인다. 목록의 이름 앞에는 프로필 사진이 있다. 보내지 못한 글은 입력칸 위에 다시 보내기와 함께 남는다. 다른 방으로 옮기면 그 글은 버리기만 되고 원래 방에 돌아가면 다시 보낼 수 있다.

## Sub-features

- `chat-send`는 메시지 칸에 쓰고 Enter로 보내면 대화하기 창 목록에 보이는 것이다 (COM-01).
- `chat-bubble`은 보낸 메시지가 실행 화면 말풍선에 보이는 것이다 (COM-09).
- `chat-button`은 입력칸 옆 `보내기` 버튼으로 보내는 것이다. 입력칸이 비면 버튼이 비활성이다 (COM-01).
- `chat-photo`는 이름 앞 프로필 사진이다. 같은 사람이 이어 보낸 글에는 사진이 한 번만 있다 (SCR-03).
- `chat-retry`는 보내지 못한 글이 입력칸 위 알림에 남고 그사이 새로 쓴 입력칸 글은 그대로이며 `다시 보내기`로 보내는 것이다. 다른 방에 있으면 알림에 원래 방 코드가 보이고 `버리기`만 있으며 원래 방에 돌아가면 `다시 보내기`가 돌아온다 (COM-01).
- `chat-size`는 대화하기 창의 글자 크기를 작게, 보통, 크게, 아주 크게 가운데 고르면 목록 글자가 바뀌고 설정 창 일반 탭에도 같은 값이 보이는 것이다 (COM-04, SET-08).

## How to get to it (user POV)

- 방에 들어간 뒤 실행 화면 ▼ 메뉴에서 `대화하기`를 누른다.
- 안 읽은 글이 있으면 실행 화면 상태칩에 `💬`와 안 읽은 수가 보이고 누르면 열린다. 안 읽은 글이 없으면 이 칩은 없다.

## Driving it with drive.ts

Preconditions:

- 새 `verify()` 세션에서 시작하기를 누른 뒤 [방](./rooms.md)의 코드로 참여 순서대로 `DEVDEV` 방에 들어가 있다.

- **창 열기.** `const chat = await menu(s, '대화하기', '대화하기')`를 실행한다. 대화하기 창이 열린다.
- **메시지 보내기.** `await chat.getByLabel('메시지').fill('검증 메시지')`와 `await chat.getByLabel('메시지').press('Enter')`를 실행한다. 대화하기 창 목록에 `검증 메시지`가 보인다.
- **말풍선 확인.** `await s.stage.getByText('검증 메시지').first().waitFor()`를 실행한다. 실행 화면에 같은 문구의 말풍선이 보인다.
- **보내기 버튼 (chat-button).** `chat.getByLabel('메시지').fill('버튼으로 보냄')`, `chat.getByRole('button', { name: '보내기' }).click()`을 실행한다. 목록에 글이 보이고 입력칸이 빈다.
- **프로필 사진 (chat-photo).** 설정 창 `계정` 탭에서 `사진 넣기`를 하고 친구 사진을 `mod/account/u/devfriend/photo`에 쓴 뒤 친구가 글 두 개를 이어 보내고 내가 하나를 보내면 `chat.locator('[class*="msg"]').getByRole('img', { name: '프로필 사진' })`가 2개다.
- **다시 보내기 (chat-retry).** 보내기가 거절되는 상황은 화면에서 만들 수 없다. 스테이지에서 `core.deps.server.goOffline({ abrupt: true })`를 부르고 글을 써서 `보내기`를 누른 뒤 입력칸에 새 글을 쓴다. 그다음 `devHub.write('rooms/DEVDEV/roster/<내 uid>', null)`과 `core.deps.server.goOnline()`을 한 번에 부른다. `chat.getByRole('alert')`에 `보내지 못했어요.`와 처음 글이 보이고 입력칸은 새 글 그대로다. roster를 `Date.now()`로 되돌리고 `다시 보내기`를 누르면 처음 글이 목록에 보이고 알림이 사라지며 입력칸은 여전히 새 글이다.
- **다른 방에서 (chat-retry).** 알림이 남은 채 방 창에서 `방에서 나가기`와 `만들기`로 내 방을 만든다. 대화하기 창은 열린 채 알림에 `DEVDEV 방에서 보내지 못한 글이에요. 그 방에 다시 들어가면 보낼 수 있어요.`와 처음 글이 보이고 `버리기`만 있으며 `다시 보내기`가 없다. 입력칸은 새 글 그대로다. 다시 `방에서 나가기` 뒤 `devdev`로 참여하면 알림이 `보내지 못했어요.`로 돌아오고 `다시 보내기`가 보인다.
- **글자 크기.** 대화하기 창 맨 위 `combobox "채팅 글자 크기"`는 처음에 `보통`이고 메시지 글자는 13px이다. `await chat.getByLabel('채팅 글자 크기').selectOption('xl')`을 실행하면 `getComputedStyle`로 본 메시지 글자가 18px이 된다. 설정 창 `일반` 탭의 대화하기 묶음 `채팅 글자 크기`도 `xl`이고 거기서 `l`을 고르면 열린 대화하기 창 글자가 15px이 된다. 대화하기 창을 닫고 다시 열어도 `l`과 15px이 그대로다.
- **증거.** 보낸 뒤 대화하기 창과 말풍선이 보이는 실행 화면, 사진이 보이는 목록, 보내지 못한 알림과 다른 방에서 본 알림과 다시 보낸 뒤 창, 글자 크기를 바꾼 대화하기 창과 설정 창을 `s.shot`으로 남긴다.

## Gotchas

- 혼자 모드에서는 ▼ 메뉴에 `대화하기` 항목이 있어도 창이 열리지 않는다. `menu()`가 5초 뒤 `대화하기 창이 열리지 않았습니다` 예외를 던진다. 먼저 방에 들어간다.
- 같은 문구가 창 목록과 말풍선에 동시에 있으니 `getByText(...).first()`로 찾는다.
- `💬` 칩은 안 읽은 글이 있을 때만 보이므로 친구 글을 받은 뒤에 찾는다.
- 보내기 버튼 이름 `보내기`는 다른 창 버튼과 겹치지 않지만 대화하기 창 안에서 찾는다.
- 연결이 끊긴 동안 보낸 글은 실패하지 않고 다시 연결될 때 보내진다. 거절을 만들려면 다시 연결하기 전에 roster를 지워야 한다.
- 날리기를 체크하면 입력란 위에 날리는 글의 `글자 크기`가 따로 생긴다. 이 이름은 `채팅 글자 크기`에도 들어 있으니 날리는 글 크기는 `{ exact: true }`로 찾는다.
- 회사원 모드에서는 실행 화면 말풍선이 보이지 않는다. 말풍선을 확인할 때는 [설정 창](./settings.md)의 회사원 모드가 꺼져 있어야 한다.
