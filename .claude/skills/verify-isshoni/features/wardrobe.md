# 캐릭터 만들기

캐릭터 만들기 창에서 캐릭터 슬롯을 고르고 얼굴을 그리거나 자세 그림을 넣은 뒤 책상을 정해 저장한다. 저장 단추가 있는 아래 줄은 스크롤해도 창 아래에 붙어 있다. 저장하면 창이 닫히고 실행 화면에 저장 안내가 뜨며 창을 다시 열면 고른 값이 그대로 있다. 저장하지 않은 것이 있으면 창을 떠나기 전에 창 안에서 묻는다. 설정 창의 자리 추가 탭에서는 저장한 다른 캐릭터 슬롯을 혼자 모드 내 옆자리에 함께 앉힌다.

## Sub-features

- `wardrobe-open`은 캐릭터 만들기 창을 여는 것이다. 맨 위 한 줄에 캐릭터 슬롯과 종류(`사람`, `동물`)가 있고 동물이 잠겨 있으면 그 옆에 `동물은 30레벨부터`가 보인다. 다음 한 줄에 단계 `캐릭터`, `책상`과 만드는 방법이 있다. 아래 줄에 `파일로 내보내기`, `파일에서 불러오기`, `이전 모습 불러오기`, 검은 `저장`이 있다.
- `wardrobe-face`는 얼굴 그리기 그림판에 표정을 그리는 것이다 (AVT-03, AVT-04).
- `wardrobe-esc`는 저장하지 않은 그림이나 고른 값이 있을 때 어느 단계에서든 ESC, 창 닫기 단추(제목 표시줄 ×), 다른 캐릭터 슬롯 단추를 누르면 창 안에서 묻고 `나가기`(슬롯 단추는 `바꾸기`)를 눌러야 떠나는 것이다. 이미지 찍기 중 ESC는 그 그림만 버리고 창은 남는다. 바뀐 것이 없으면 묻지 않는다 (AVT-03).
- `wardrobe-pose`는 자세 그림 넣기에서 크기 안내(320x400px)가 보이고 얼굴 그림을 쓰는 자세 카드에는 `지금은 얼굴 그림을 써요`가, 그림을 넣은 카드에는 `얼굴 그림으로` 단추가 보이는 것이다. 캐릭터 단계에서는 위쪽 큰 미리보기가 없다 (AVT-04).
- `wardrobe-pen-eraser`는 펜 뒤쪽 지우개(button 5)로 그림판을 문지르면 `지우개`를 누르지 않아도 지워지는 것이다. 꾸미기 그림판도 같다.
- `wardrobe-desk`는 `책상` 단계에서 기본 책상을 고르는 것이다 (AVT-01).
- `wardrobe-preview`는 `책상` 단계와 이전 모습 화면의 위쪽 큰 미리보기가 저장하지 않은 몸 색과 얼굴을 그대로 그리는 것이다. 미리보기 때문에 그림을 서버에 올리지 않는다 (AVT-03).
- `wardrobe-trash`는 아래 줄의 `이전 모습 불러오기`로 덮어쓴 옛 모습 목록을 여는 것이다 (ACC-08).
- `wardrobe-slot`은 런처 슬롯 카드가 한 번도 저장하지 않은 슬롯을 `빈 캐릭터 (2/3)`처럼 보이고 저장한 슬롯은 `캐릭터 (1/3)`처럼 보이는 것이다 (AVT-15).
- `wardrobe-save`는 저장하면 창이 닫히고 실행 화면에 저장 안내가 뜨는 것이다 (AVT-11).
- `wardrobe-persist`는 다시 연 창에 저장한 얼굴과 책상이 그대로 있는 것이다.
- `solo-add`는 자리 추가 탭에서 다른 캐릭터를 앉히면 실행 화면에 그 캐릭터 좌석이 내 옆에 생기는 것이다 (AVT-22).
- `solo-order`는 ◀ ▶로 앉은 순서를 바꾸면 실행 화면 좌석 순서가 바뀌는 것이다.
- `solo-room`은 방에 들어가면 앉힌 캐릭터가 숨고 방에서 나오면 다시 앉는 것이다.
- `solo-switch`는 지금 캐릭터를 바꾸면 그 슬롯 자리에 내가 앉고 이전 캐릭터가 옆에 앉는 것이다.
- `solo-remove`는 빼기로 앉힌 캐릭터를 빼는 것이다.

## How to get to it (user POV)

- 실행 화면 ▼ 메뉴에서 `캐릭터 만들기`를 누른다.
- 런처의 `캐릭터 만들기` 버튼을 누른다.
- 자리 추가는 실행 화면 ▼ 메뉴 `설정`을 누르고 설정 창의 `자리 추가` 탭을 누른다.

## Driving it with drive.ts

Preconditions:

- 새 `verify()` 세션에서 시작하기를 눌러 실행 화면에 있다.

- **창 열기.** `const w = await menu(s, '캐릭터 만들기', '캐릭터 만들기')`를 실행한다. ARIA에 `navigation "캐릭터 슬롯"`의 `캐릭터 1 [pressed]`, `navigation "캐릭터 종류"`, `동물은 30레벨부터`, 단계 줄의 `캐릭터 [pressed]`와 `책상`, `navigation "만드는 방법"`의 `얼굴 그리기 [pressed]`, `button "이전 모습 불러오기"`, `button "저장"`이 있다. `캐릭터 슬롯`과 `캐릭터 종류`의 위쪽 y가 같고 단계 줄과 `만드는 방법`의 위쪽 y가 같다. 얼굴 그림판 위쪽은 창 위에서 310px 안쪽이고 스크롤하지 않은 창에서 `저장` 상자의 아래 끝이 `window.innerHeight` 안에 있다.
- **얼굴 그리기.** 붓 색 `파랑`을 누르고 그림판 위에서 마우스를 끌어 한 획을 긋는다.
  ```ts
  await w.getByRole('button', { name: '파랑' }).click();
  const board = (await w.getByLabel('얼굴 그림판').boundingBox())!;
  await w.mouse.move(board.x + board.width * 0.3, board.y + board.height * 0.25);
  await w.mouse.down();
  await w.mouse.move(board.x + board.width * 0.7, board.y + board.height * 0.3, { steps: 10 });
  await w.mouse.up();
  ```
  `await expect(w.getByRole('button', { name: '되돌리기' })).toBeEnabled()`로 획이 들어간 것을 확인한다. 그림판과 오른쪽 기본, 타이핑 미리보기에 파란 선이 보인다.
- **ESC와 떠나기 전 묻기 (wardrobe-esc).** 창에 `w.on('dialog', () => {})`를 먼저 붙인다(Gotchas). 그림 고르기 대화상자를 시험용 PNG로 바꾸고 `w.getByRole('button', { name: '그림 넣기', exact: true })`를 누르면 `찍기`가 보인다. `w.keyboard.press('Escape')`를 실행하면 `찍기`가 사라지고 창은 열려 있으며 묻지 않는다. 한 획을 긋고 `책상` 단계로 옮긴 뒤 ESC를 누르면 `alertdialog "캐릭터를 저장하지 않았어요. 나갈까요?"`와 `나가기`, `계속하기`가 보인다. `계속하기`를 누르거나 묻는 중에 ESC를 누르면 물음만 닫힌다. `캐릭터 2` 슬롯 단추를 누르면 `alertdialog "캐릭터를 저장하지 않았어요. 바꿀까요?"`와 `바꾸기`, `계속하기`가 뜨고 그동안 `캐릭터 1`이 `[pressed]` 그대로다. `바꾸기`를 누르면 캐릭터 2로 바뀐다. 메인에서 `BrowserWindow.getAllWindows().find((x) => x.getTitle() === '캐릭터 만들기')?.close()`를 실행하면(제목 표시줄 ×와 같다) 창이 닫히지 않고 같은 물음이 뜨며 `나가기`를 누르면 닫힌다. 아무것도 바꾸지 않은 창은 ESC 한 번에 닫힌다.
- **자세 그림 넣기 (wardrobe-pose).** `자세 그림 넣기`를 누르면 `320x400px에 배경이 투명한 PNG가 좋아요.`와 카드 세 장의 `지금은 얼굴 그림을 써요`가 보이고 `얼굴 그림으로` 단추는 없다. 위쪽 큰 미리보기도 없어서 창의 `canvas`는 카드의 세 장뿐이다. 첫 카드의 `그림 넣기`(exact)를 누르면 그 카드만 `얼굴 그림으로` 단추로 바뀐다.
- **펜 지우개 (wardrobe-pen-eraser).** 하네스는 펜 입력을 만들 수 없다. 창에서 `HTMLCanvasElement.prototype.setPointerCapture`를 빈 함수로 바꾸고 굵은 검정 획 위로 `new PointerEvent('pointerdown', { pointerType: 'pen', button: 5, buttons: 32, clientX, clientY, pointerId: 7, bubbles: true })`와 `pointermove`, `pointerup`을 그림판 canvas에 보낸다. 획 가운데 픽셀이 몸 색으로 돌아오고 `지우개`는 `aria-pressed="false"` 그대로다. 보고에 이 준비를 적는다.
- **저장 전 미리보기 (wardrobe-preview).** `캐릭터` 단계의 얼굴 그리기에서 `몸 색 하늘`과 붓 색 `파랑`을 누르고 한 획을 그은 뒤 `책상`을 누른다. 위쪽 128x160 미리보기 `canvas`(aria-label 없음)의 픽셀을 `getImageData`로 세면 하늘색(`#dcefff` 안팎) 픽셀과 파란 획 픽셀이 있고 기본 분홍 몸(`#ffe4ec`) 픽셀은 없다. `책상 없음`을 눌러도 같다. 다시 `캐릭터` 단계에서 `몸 색 분홍`을 누르고 `책상`으로 오면 분홍 몸에 파란 획이 보인다.
- **책상 고르기.** `await w.getByRole('button', { name: '책상', exact: true }).click()`과 `await w.getByRole('button', { name: /나무 책상/ }).click()`을 실행한다. `button "나무 책상" [pressed]`가 되고 `책상 그림도 320x400px로 맞추고 책상을 아래쪽에 두어 주세요.`가 보인다.
- **이전 모습 (wardrobe-trash).** `이전 모습 불러오기`를 누르면 새 세션에서는 `남아 있는 이전 모습이 없어요.`가 보이고 단계 줄에 눌린 단추가 없다. `캐릭터`나 `책상`을 누르면 그 단계로 돌아간다.
- **저장.** `await w.getByRole('button', { name: '저장', exact: true }).click()`을 실행한다. 실행 화면에 `캐릭터를 저장했어요.`가 보이고 묻지 않고 창이 닫힌다. 런처에서 연 창이면 같은 알림이 런처 창 위쪽에 뜬다. `await expect.poll(() => w.isClosed()).toBe(true)`로 확인한다.
- **유지 확인.** 창을 다시 연다. 그림판과 기본, 타이핑 미리보기에 파란 선이 남아 있다. `책상` 단계를 누르면 `button "나무 책상" [pressed]`이다.
- **슬롯 카드 (wardrobe-slot).** 새 세션 런처에 `빈 캐릭터 (1/3)`이 보이고 `다음 캐릭터`를 누르면 `빈 캐릭터 (2/3)`이 된다. 캐릭터 1을 저장하고 `« 런처로`로 돌아오면 `캐릭터 (1/3)`이다.
- **증거.** 획을 그은 창, 세 가지 물음이 뜬 창, 자세 그림 넣기 창, 책상을 고른 창, 저장 안내가 뜬 실행 화면, 다시 연 창, 슬롯 카드를 `s.shot`으로 남긴다.

자리 추가(`solo-*`)는 캐릭터 두 개를 저장한 상태에서 시작한다. 캐릭터 1을 `나무 책상`으로 저장하고 창을 다시 열어 `캐릭터 2` 슬롯 단추를 누른 뒤 `하얀 책상`을 골라 저장한다. 지금 캐릭터는 캐릭터 2가 된다. 설정 창은 `s.stage.locator('button[title="메뉴"]').click()`, `s.stage.getByRole('button', { name: '설정', exact: true }).click()`, `const set = await windowTitled(s.app, '설정')`, `set.getByRole('button', { name: '자리 추가' }).click()`으로 연다. 좌석 순서는 이름표 위치 `(await s.stage.getByText(이름, { exact: true }).boundingBox())!.x`로 비교한다. 내 이름표는 `이름 없음`이고 앉힌 캐릭터 이름표는 `캐릭터 1`처럼 슬롯 번호다.

- **앉히기.** 탭에 `캐릭터 2 (지금 캐릭터)`와 비활성 `캐릭터 3 앉히기`가 보인다. `캐릭터 1 앉히기`를 누르면 실행 화면에 `캐릭터 1` 이름표가 내 오른쪽에 생기고 `button "내 메뉴"`가 2개가 된다.
- **순서 바꾸기.** `캐릭터 1 왼쪽으로`를 누르면 `캐릭터 1` 이름표가 `이름 없음`보다 왼쪽으로 간다.
- **방에서 숨기.** 방 창에서 `devdev`로 참여하면 `캐릭터 1` 이름표가 사라지고 탭에 `지금은 방에 있어서 숨겨 두었어요.`가 보인다. `방에서 나가기`를 누르면 `캐릭터 1`이 다시 왼쪽에 앉는다.
- **지금 캐릭터 바꾸기.** 캐릭터 만들기 창에서 `캐릭터 1` 슬롯 단추를 누르면 실행 화면에 `캐릭터 2` 이름표가 내 오른쪽에 생기고 `캐릭터 1` 이름표는 없다.
- **유지와 빼기.** 설정 창을 다시 열면 탭에 `캐릭터 1 (지금 캐릭터)`가 맨 앞에 있다. `빼기`를 누르면 `캐릭터 2` 이름표가 사라지고 `캐릭터 2 앉히기`가 켜진다.
- **증거.** 각 단계 뒤의 실행 화면과 자리 추가 탭을 `s.shot`으로 남기고 `errors.json`이 `[]`인지 본다.

## Gotchas

- 새 세션의 실행 화면 캐릭터는 활동이 없어서 잠든 모습이다. 표정은 기본과 타이핑 자세에만 들어가므로 저장 직후 실행 화면에는 그린 선이 보이지 않는다. 얼굴 저장은 다시 연 창으로 확인한다.
- 다시 연 창에서는 `되돌리기`가 비활성이다. 얼굴이 남았는지는 버튼 상태가 아니라 그림판과 미리보기 화면으로 확인한다.
- 창을 닫는 ESC는 keydown에서 창이 닫혀서 `keyboard.press`의 keyup이 닫힌 창에 가다 예외가 난다. 마지막 ESC는 `w.keyboard.down('Escape').catch(() => undefined)`로 보낸다.
- 제목 표시줄 닫기를 막으면 CDP가 beforeunload 대화상자를 알리고 Playwright가 대신 닫으려다 `No dialog is showing` 예외로 스크립트가 끝난다. 묻기를 확인하는 창과 저장하지 않은 채 세션을 끝낼 창에는 `w.on('dialog', () => {})`를 먼저 붙인다.
- `그림 넣기`는 `자세 그림 넣기`와 이름 일부가 겹치고 단계 단추 `캐릭터`와 `책상`은 `캐릭터 1`, `나무 책상`과 겹친다. 모두 `exact: true`로 찾는다.
- 저장하면 창이 닫힌다. 저장 뒤에 같은 `Page` 객체를 쓰지 않고 창을 다시 연다.
- `동물` 캐릭터 종류는 30레벨 전에는 비활성이다. 새 세션은 1레벨이라 누를 수 없다.
- 그림 넣기와 파일에서 불러오기는 파일 고르기 대화상자를 연다. `dialog.showOpenDialog`를 먼저 바꿔 두지 않으면 실제 OS 대화상자가 뜬다.
- 설정 창이나 다른 패널 창이 실행 화면을 가리는 동안에는 새로 생긴 좌석 캔버스가 늦게 그려져 기본 그림으로 찍힌다. 실행 화면 사진은 가린 창을 닫고 좌석 캔버스에 책상 색이 나올 때까지 기다린 뒤 찍는다. 예를 들어 `window.core.seatViews.get('wardrobe.solo.0').el.querySelector('canvas')`의 픽셀에서 나무 책상 색 `#b9814a`를 `expect.poll`로 찾는다. 읽기만 하고 보고에 적는다.
- 한 번도 저장하지 않은 캐릭터 슬롯은 앉힐 수 없다. 새 세션은 캐릭터 1도 저장 전이라 먼저 저장한다.
