# 내 정보

런처의 `내 정보` 버튼을 누르면 런처 창 안의 화면이 내 정보로 바뀐다. 위쪽에 프로필 사진, 닉네임, 레벨, 수정 버튼, 친구 코드와 복사 버튼, 친구 랭킹이 있고 그 아래 자리비움 그림 칸과 보관함, 계정, 휴지통 탭이 있다. ◀를 누르면 런처 첫 화면으로 돌아온다.

## Sub-features

- `me-open`은 런처의 내 정보 버튼으로 화면을 열고 ◀로 돌아오는 것이다 (SCR-03).
- `me-code`는 친구 코드가 보이고 복사 버튼으로 클립보드에 들어가는 것이다.
- `me-rank`는 나와 친구 사이 레벨 순위가 보이고 1위면 사진에 왕관이 붙는 것이다.
- `me-account`는 수정 버튼이 계정 탭을 열고 사진 넣기와 닉네임 저장이 위쪽 프로필에 바로 보이는 것이다.
- `me-awaypic`은 자리비움 그림 칸에서 그림을 등록하는 것이다 (CHR-07, 설정 창 자리비움 그림 탭과 같은 화면).
- `me-box`는 보관함 탭이 방 가챠 보관함을 보여 주는 것이다.
- `me-trash`는 휴지통 탭 이름에 항목 수가 붙고 복원하면 그 모습이 원래 캐릭터 칸에 돌아오는 것이다.

## How to get to it (user POV)

- 앱을 켜면 뜨는 런처에서 아래 줄의 `내 정보` 버튼을 누른다.
- 실행 화면에 있으면 ▼ 메뉴 맨 아래 `« 런처로`를 누른 뒤 `내 정보`를 누른다.
- 프로필 사진은 설정 창 `계정` 탭에서도 바꾼다.

## Driving it with drive.ts

Preconditions:

- 새 `verify()` 세션이다. 런처 창 `s.launcher`가 열려 있다.
- 친구 코드, 친구 목록, 가짜 친구 레벨은 사용자가 화면에서 만들 수 없는 조건이라 스테이지에서 만든다. 친구 코드는 `s.stage.evaluate(() => { const c = (window as any).core; c.deps.profile = { ...c.deps.profile, friendCode: 'TEST-CODE' }; })`로 넣는다. 친구 목록과 가짜 친구 프로필 쓰기는 [플레이리스트와 소리](./sound.md)의 `asFriend`와 친구 목록 쓰기를 그대로 쓴다. 가짜 친구 레벨은 `asFriend([{ profile: { name: '가짜 친구', 'm/growth': { level: 7 } } }])`로 정한다.
- 사진 넣기와 그림 등록은 파일 고르기 대화상자를 연다. [자리비움과 자리비움 그림](./status.md)처럼 `dialog.showOpenDialog`를 시험용 PNG를 돌려주게 먼저 바꿔 둔다.

- **열기.** `await s.launcher.getByRole('button', { name: '내 정보' }).click()`을 실행한다. `heading "내 정보"`, `button "뒤로"`, `친구 코드 TEST-CODE`, `button "복사"`, `친구 랭킹`, `2위`, `2명 중`, `heading "자리비움 그림"`, `button "그림 등록"`, `button "보관함" [pressed]`, `button "휴지통 0"`, `아직 뽑은 아이템이 없습니다.`가 보인다.
- **복사.** `복사`를 누르면 `s.app.evaluate(({ clipboard }) => clipboard.readText())`가 `TEST-CODE`다.
- **수정과 사진.** `수정`을 누르면 `button "계정" [pressed]`가 된다. `사진 넣기`를 누르면 `사진을 바꿨습니다`가 뜨고 `img "프로필 사진"`이 위쪽과 탭 안에 2개 보인다. 서버 기록은 `c.deps.server.docs({ scope: 'user', module: 'account', uid: c.deps.uid }).get('photo')`가 64자 해시다.
- **닉네임.** `await L.getByLabel('닉네임').fill('토끼')`와 `저장`을 누르면 위쪽 이름이 `토끼`로 바뀐다. ◀로 돌아가면 런처 첫 화면 이름도 `토끼`다.
- **자리비움 그림.** `그림 등록`을 누르면 `img "등록한 자리비움 그림"`이 보인다.
- **왕관.** `asFriend`로 가짜 친구 레벨을 1로 바꾸고 ◀를 누른 뒤 `내 정보`를 다시 누른다. `1위`와 `img "친구 랭킹 1위 왕관"`이 보인다.
- **휴지통.** ◀로 돌아가 `시작하기`를 누르고 [캐릭터 만들기](./wardrobe.md) 창에서 `2 책상`의 `나무 책상`으로 저장한다. 창을 다시 열어 `하얀 책상`으로 한 번 더 저장한다. `« 런처로`로 돌아와 `내 정보`를 누르면 `button "휴지통 1"`이 있다. 누르면 `캐릭터 1`과 `10/19 사라져요` 같은 날짜, `button "복원"`이 보인다. `복원`을 누른 뒤에도 `휴지통 1`이다(하얀 책상 모습이 들어간다). ◀를 누르고 런처의 `캐릭터 만들기`로 창을 열어 `2 책상`을 누르면 `나무 책상`이 `[pressed]`다.
- **휴지통 최근 50개.** 새 세션에서 `내 정보`를 누르기 전에 스테이지에서 `devHub.write`로 `mod/wardrobe/u/<내 uid>/trash/<mtime>_0`에 기록 55개를 쓴다. 값은 `{ appearance, mtime, slot: 0, at, v: 1 }`이고 appearance는 `window.core.ctxs.get('seating').ctx.modules.get('wardrobe').appearance()`다. 앞의 5개는 mtime을 20일 전, at을 9일 전으로 두고 나머지 50개는 mtime과 at을 지금으로 둔다. `내 정보`에서 `휴지통 50`을 누르면 `복원`이 50개이고 내일 날짜의 `사라져요`는 하나도 없다. 화면에서 55번 저장하기 어려워서 쓰는 준비 조건이다.
- **증거.** 런처 첫 화면, 연 화면, 계정 탭, 그림 등록 뒤, 왕관, 복원 전과 뒤의 휴지통, 다시 연 캐릭터 만들기 창을 `s.shot`으로 남긴다. 휴지통 목록은 화면 아래에 있어서 찍기 전에 `복원` 버튼을 `scrollIntoViewIfNeeded()`로 보이게 한다.

## Gotchas

- 내 정보는 새 창이 아니라 런처 창 안의 화면이다. `windowTitled`로 찾지 않고 `s.launcher`를 그대로 쓴다. 실행 화면에서 `« 런처로`로 돌아오면 런처 창을 `windowTitled(s.app, 'Isshoni Hatarakou')`로 다시 찾는다.
- 내 정보 화면에 있는 동안 런처 첫 화면의 `시작하기`와 `캐릭터 만들기`는 보이지 않는다. 먼저 ◀를 누른다.
- 내 정보 화면은 처음 누를 때 불러온다. 그동안 `불러오는 중이에요.`가 잠깐 보일 수 있으니 `heading "내 정보"`를 기다린 뒤 조작한다.
- 랭킹과 친구 코드는 화면을 열 때 읽는다. 준비 조건을 바꾼 뒤에는 ◀로 나갔다가 다시 연다.
- 휴지통은 한 번이라도 저장한 칸을 다시 저장할 때만 생긴다. 새 세션의 첫 저장은 휴지통을 만들지 않는다.
- 메모리 서버는 친구 읽기 규칙을 검사하지 않는다. 친구가 아닌 사람이 사진을 읽지 못하는 것은 `src/modules/account/rules.test.ts` 에뮬레이터 시험으로 확인한다.
