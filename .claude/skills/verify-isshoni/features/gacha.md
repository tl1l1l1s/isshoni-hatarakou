# 방 가챠의 기간 한정과 색 해금

내 방의 방 설정에서 가챠 아이템을 넣을 때 기간을 정하면 그 기간에만 뽑힌다. 기간 밖 아이템은 가챠 창에 따로 보이고 확률에서 빠진다. 같은 아이템을 4개 모으면 꾸미기에서 그 스티커 색을 바꿀 수 있고 보관함에 진행도가 보인다.

## Sub-features

- `gacha-period`는 기간 한정 아이템을 넣고 가챠 창에서 기간 밖 아이템으로 보이는 것이다 (GCH-04).
- `gacha-hue`는 같은 아이템 개수에 따라 보관함에 색 n/4가 보이고 꾸미기의 색조와 채도가 열리는 것이다 (GCH-05).

## How to get to it (user POV)

- 내 방에 있을 때 방 창의 `방 설정`을 누르고 가챠 구역의 `아이템 넣기`에서 `기간 한정 시작 (선택)`과 `기간 한정 끝 (선택)`을 고른다. 방 가챠 창의 아이템 넣기에도 같은 칸이 있다.
- 실행 화면 ▼ 메뉴에서 `가챠`, `보관함`, `꾸미기`를 누른다.

## Driving it with drive.ts

Preconditions:

- 새 `verify()` 세션에서 시작하기를 눌러 실행 화면에 있다.
- 그림 파일 고르기 대화상자는 시험용 그림을 돌려주게 바꾼다. `tests/e2e/boot.spec.ts`의 `OffscreenCanvas`로 PNG를 만들고 `dialog.showOpenDialog`를 바꾸는 부분을 그대로 쓴다.
- [방](./rooms.md)의 내 방 만들기와 방 설정 열기 순서대로 방 설정 창(`rs`)을 열어 둔다.

- **아이템 넣기.** `await rs.getByLabel('이름', { exact: true }).fill('별')`과 `그림 고르고 넣기`를 누른다. 다시 이름을 `눈사람`으로 적고 `await rs.getByLabel('기간 한정 시작 (선택)').fill('2026-12-24')`, `await rs.getByLabel('기간 한정 끝 (선택)').fill('2026-12-25')` 뒤에 `그림 고르고 넣기`를 누른다. 방 설정 목록에 `가중치 10, 12/24부터 12/25까지`가 보인다.
- **뽑기 횟수 준비.** 4시간 작업은 화면에서 만들 수 없다. `boot.spec.ts`처럼 `core.deps.server.docs({ scope: 'user', module: 'gacha', uid, path: ['r'] }).update(code, { sec: { $inc: 4 * 3600 } })`로 더한다.
- **가챠 창.** `const g = await menu(s, '가챠', '가챠')`를 실행한다. `남은 뽑기 4회`, 아이템과 확률에 `별 100%`, `heading "기간 밖 아이템"` 아래 `눈사람 12/24부터 12/25까지`가 보인다.
- **한 번 뽑고 색 잠김 확인.** `1회 뽑기`를 누르고 `NEW!`를 기다린다. 보관함 창에 `색 1/4`가 보인다. 꾸미기 창에서 보관함의 `별`을 누르면 `같은 아이템을 4개 모으면 색을 바꿀 수 있어요. 지금 1개예요.`가 보이고 색조 칸이 없다.
- **네 개 모으기.** `1회 뽑기`를 세 번 더 누른다. 누를 때마다 버튼이 다시 켜지기를 기다리고 `N개째`를 기다린다. 보관함에 `색 바꾸기 가능`이 보이고 꾸미기 창에 `slider "색조 0도"`와 `채도 100%`가 생긴다. 색조를 200으로 옮기면 미리보기 스티커 색이 바뀐다.
- **증거.** 방 설정 창, 기간 밖 아이템이 보이는 가챠 창, 잠긴 꾸미기와 보관함, 열린 꾸미기와 보관함을 `s.shot`으로 남긴다.

## Gotchas

- 날짜 칸은 `type="date"`라서 `fill('YYYY-MM-DD')`로 넣는다. 하루는 오전 6시에 바뀌고 끝 날은 그날 하루를 포함한다.
- 기간 판정은 서버 시각이다. 위 날짜는 2026년 12월 24일 전에 돌릴 때 기간 밖이다. 그 뒤에 돌리면 더 뒤의 날짜를 쓴다.
- 기간 밖 아이템만 남으면 `1회 뽑기`가 꺼지고 `뽑을 아이템이 없습니다.`가 보인다. 기간이 없는 아이템을 하나 함께 넣는다.
- 꾸미기 창은 보관함을 구독하므로 뽑은 뒤 다시 열지 않아도 색 칸이 바뀐다.
