# 놀이

실행 화면에서 캐릭터끼리 장난을 주고받는다. 캐릭터를 짧게 누르면 쓰다듬고 누른 채로 좌우로 흔들면 어지러워한다. ▼ 메뉴로 춤추기와 러시안룰렛을 하고 다른 사용자 메뉴로 쓰다듬기, 때리기, 폭탄 던지기를 한다. 대화하기 창에서는 글을 화면 가득 날리거나 춤 명령을 쓰고 이모티콘 창에서는 내 그림을 이모티콘으로 등록한다. 연출은 화면 전체를 덮는 `효과` 창에 그려지고 같은 방 사람 모두에게 보인다.

## Sub-features

- `play-gate`는 레벨이 모자라면 ▼ 메뉴에 `춤추기`가 없고 다른 사용자 메뉴에 `폭탄 던지기`가 없는 것이다 (GRW-02).
- `play-dance`는 ▼ 메뉴 `춤추기`나 대화하기 창의 `/80`, `/150`으로 캐릭터가 춤추는 것이다 (COM-10).
- `play-show`는 같은 춤 명령을 1분 안에 세 번 보내면 깜짝쇼 안내가 뜨고 나머지 캐릭터가 날아가는 것이다 (COM-17).
- `play-roulette`는 ▼ 메뉴 `러시안룰렛`으로 머리 위 주사위가 굴러가고 1이 나오면 캐릭터가 날아갔다 돌아와 어지러워하는 것이다 (COM-14).
- `play-pet`은 캐릭터를 짧게 누르거나 다른 사용자 메뉴 `쓰다듬기`를 누르면 그 캐릭터 머리 위에 💗가 뜨는 것이다. 내 캐릭터, 다른 사람 캐릭터, 자리 추가로 앉힌 내 다른 캐릭터 모두 된다 (CHR-11).
- `play-shake`는 캐릭터를 누른 채로 좌우로 빠르게 흔들면 그 캐릭터 머리 위에 💫가 2.5초쯤 뜨는 것이다 (CHR-11).
- `play-hit`은 다른 사용자 메뉴 `때리기`로 그 캐릭터가 납작해졌다 돌아오고 💫가 뜨며 하루 횟수 안내가 나오는 것이다 (COM-11).
- `play-bomb`은 다른 사용자 메뉴 `폭탄 던지기`나 대화하기 창 💣 다음 캐릭터 고르기로 폭탄이 날아가 그 캐릭터가 날아가는 것이다 (COM-13).
- `play-fly-text`는 대화하기 창 `날리기`를 켜고 보낸 글이 화면을 가로질러 흐르고 대화 기록과 말풍선에는 남지 않는 것이다 (COM-05).
- `play-quiet`는 회사원 모드에서 날리기가 사라지고 흐르던 글이 지워지며 러시안룰렛과 폭탄이 막히는 것이다.
- `play-reaction-setting`은 설정 일반 탭 `머리 위 반응 보이기 (하트, 어지러움)`를 끄면 💗와 💫가 숨는 것이다 (CHR-11).
- `play-emoji`는 이모티콘 창에서 내 그림을 등록하고 누르면 내 캐릭터 머리 위에 그 그림이 뜨며 `빼기`로 지우는 것이다 (COM-18).

## How to get to it (user POV)

- 실행 화면 ▼ 메뉴의 `춤추기`, `러시안룰렛`, `대화하기`, `이모티콘`, `설정`을 누른다.
- 실행 화면의 캐릭터를 짧게 누르거나 누른 채로 좌우로 흔든다.
- 방에 들어간 뒤 다른 사용자 이름표를 누르거나 캐릭터를 오른쪽 클릭해 다른 사용자 메뉴를 연다.
- 대화하기 창 입력란 위의 `날리기`, `글자 크기`, `글자 색`, 💣를 쓰고 입력란에 `/80`, `/150`을 넣는다.

## Driving it with drive.ts

Preconditions:

- 새 `verify()` 세션에서 시작하기를 눌러 실행 화면에 있다.
- 레벨 80, 100, 150, 200은 화면에서 만들 수 없다. 잠금 해제를 확인한 뒤 sticky gate 기록을 써서 연다.
  ```ts
  await s.stage.evaluate(async () => {
    const c = (window as any).core;
    for (const g of ['dance', 'dance2', 'bomb', 'flyColor']) await c.deps.server.userPrivate.set(c.deps.uid, `gates/play:${g}`, 1);
  });
  ```
- 연출이 도는 동안 그 좌석 key는 `core.away`에 들어간다. 내 좌석 key는 아래처럼 구하고 가짜 친구 좌석 key는 `devfriend_dev`다.
  ```ts
  const me = await s.stage.evaluate(() => (window as any).core.deps.uid + '_' + (window as any).core.deps.deviceId);
  ```

- **잠금 확인.** gate를 열기 전에 ▼ 메뉴를 연다. `button "러시안룰렛"`은 있고 `button "춤추기"`는 없다.
- **혼자 춤.** gate를 연 뒤 ▼ 메뉴 `춤추기`를 누른다. `await windowTitled(s.app, '효과')`로 효과 창이 열리고 `expect.poll(() => s.stage.evaluate((k) => core.away.get().has(k), me)).toBe(true)`가 통과한다. 효과 창 화면에 캐릭터가 기울어져 있다.
- **러시안룰렛.** 결과가 무작위라서 누르기 직전에만 `Math.random = () => 0`으로 바꾸고 누른 직후 되돌린다. 실행 화면에 `🎲`로 시작하는 말풍선이 바뀌다가 `🎲 ⚀ ⚀`에서 멈추고 효과 창이 열린 뒤 `💫`가 뜬다. 바로 다시 누르면 `아직 어지러워요. 잠시 뒤에 굴려 주세요.` 안내가 뜬다.
- **내 캐릭터 쓰다듬기.** `await s.stage.getByRole('button', { name: '내 캐릭터 쓰다듬기' }).click()`을 실행한다. 내 머리 위에 `💗`가 뜨고 1.5초 뒤 사라진다.
- **흔들기.** 캐릭터 상자 가운데에서 누른 채로 좌우로 움직인다. `const b = (await body.boundingBox())!`, `await s.stage.mouse.move(cx, cy)`, `await s.stage.mouse.down()`, `for (let i = 0; i < 8; i++) await s.stage.mouse.move(cx + (i % 2 ? -20 : 20), cy, { steps: 2 })`, `await s.stage.mouse.up()` 순서다(`cx`, `cy`는 상자 가운데). 그 캐릭터 머리 위에 `💫`가 뜨고 `💗`는 뜨지 않으며 2.5초쯤 뒤 사라진다.
- **내 다른 캐릭터.** [캐릭터 만들기](./wardrobe.md)의 자리 추가 순서로 `캐릭터 1`을 앉힌다. `button "캐릭터 1 쓰다듬기"`를 누르면 그 캐릭터 상자 위에 `💗`가 뜨고 흔들면 `💫`가 뜬다. 이 좌석은 이 PC에만 있어서 방 이벤트를 보내지 않는다.
- **방 들어가기.** [방](./rooms.md)의 코드로 참여 순서대로 `devdev`에 들어간다.
- **친구 쓰다듬기와 흔들기.** `button "가짜 친구 쓰다듬기"`를 누르면 가짜 친구 머리 위에 `💗`가 뜨고 흔들면 `💫`가 뜬다. 방 사람에게 보낸 신호는 `await s.stage.evaluate(() => Object.values(devHub.read('rooms/DEVDEV/ev') ?? {}).map((e) => e.t + ' ' + e.p))`에 `play.pet {"to":"devfriend_dev"}`와 `play.shake {"to":"devfriend_dev"}`로 보인다. 방 안에서 내 캐릭터를 누르면 `play.pet {"to":"<내 key>"}`가 더해진다.
- **다른 사용자 메뉴.** `await s.stage.getByRole('button', { name: '가짜 친구 메뉴' }).click()`(이름표)이나 `await s.stage.getByRole('button', { name: '가짜 친구 쓰다듬기' }).click({ button: 'right' })` 뒤 `menu "가짜 친구"`에 `menuitem "쓰다듬기"`, `menuitem "때리기"`, `menuitem "폭탄 던지기"`가 있다.
- **메뉴로 쓰다듬기.** `menuitem "쓰다듬기"`를 누르면 메뉴가 닫히고 가짜 친구 머리 위에 `💗`가 뜬다.
- **때리기.** 내 `💫`가 사라진 뒤 `때리기`를 누른다. 효과 창이 열리고 `때렸어요. 오늘 1/30` 안내와 가짜 친구 머리 위 `💫`가 보인다.
- **폭탄 던지기.** `폭탄 던지기`를 누르면 효과 창에 검은 공이 보이고 `devfriend_dev`가 `core.away`에 들어간다.
- **날리기.** `const chat = await menu(s, '대화하기', '대화하기')` 뒤 `chat.getByLabel('날리기').check()`, `chat.getByLabel('글자 크기', { exact: true }).selectOption('l')`, `chat.getByLabel('글자 색').fill('#ff66aa')`를 하고 메시지 칸에 `날아가는 글`을 넣어 Enter를 누른다. 효과 창에 `이름 없음: 날아가는 글`이 글자 크기 40px, 색 `rgb(255, 102, 170)`로 보이고 대화하기 창과 실행 화면에는 `날아가는 글`이 없다.
- **회사원 모드.** 설정 창 `화면` 탭의 `회사원 모드`를 체크한다([설정 창](./settings.md)). 흐르던 효과 창이 닫히고 대화하기 창에서 `날리기`가 사라진다. ▼ 메뉴 `러시안룰렛`은 `회사원 모드에서는 쓸 수 없어요.` 안내를 띄우고 다른 사용자 메뉴에 `폭탄 던지기`가 없다. 체크를 풀어 되돌린다.
- **💣와 캐릭터 고르기.** 대화하기 창 `chat.getByTitle('폭탄')`을 누르면 실행 화면에 `누구에게 할지 캐릭터를 눌러 주세요`가 뜬다. `button "가짜 친구 고르기"`를 누르면 쓰다듬지 않고 효과 창이 열리며 가짜 친구가 날아간다.
- **춤 명령과 깜짝쇼.** 날리기를 끄고 `/80`을 보낸다. 내 캐릭터가 춤추고 대화 기록에 `/80`이 없다. 춤 사이에는 5초를 기다려야 하므로 `expect.poll(() => s.stage.evaluate(() => core.registry.reason('play.dance'))).toBeNull()`로 기다린 뒤 두 번 더 보낸다. 세 번째에 `이름 없음님의 깜짝쇼예요`가 뜨고 가짜 친구가 날아간다. `/150`도 같은 방법으로 보낸다.
- **받은 신호.** 가짜 친구는 신호를 보내지 못해서 서버가 준 것처럼 세션에 넣는다. 30초가 지난 신호는 버리고 새 신호만 보인다.
  ```ts
  await s.stage.evaluate(([t, p, ago]) => {
    const c = (window as any).core;
    c.session.onEvents([{ key: `fake-${Math.random()}`, t, uid: 'devfriend', at: c.deps.server.time.serverNow() - ago, p: JSON.stringify(p) }]);
  }, ['play.pet', { to: me }, 0] as const);
  ```
  `play.hit`을 `{ from: 'devfriend_dev', to: me, seed: 5 }`로 넣으면 내 캐릭터가 납작해지고 `💫`가 뜬다. `play.shake`를 `{ to: me }`로 넣으면 `💫`만 뜨고 31초 전 시각으로 넣은 `play.shake`는 아무것도 띄우지 않는다.
- **반응 끄기.** 내 머리 위에 `💗`가 떠 있을 때 ▼ 메뉴 `설정`을 열고 `settings.getByLabel('머리 위 반응 보이기 (하트, 어지러움)').uncheck()`를 실행한다. `💗`가 바로 사라진다.
- **내 이모티콘.** 그림 고르기 대화상자를 시험용 PNG로 바꾼다 (`tests/e2e/boot.spec.ts`의 `showOpenDialog` 예). `const emoji = await menu(s, '이모티콘', '이모티콘')` 뒤 `emoji.getByTitle('이모티콘 추가').click()`을 하면 `emoji.getByTitle('내 이모티콘')`이 보인다. 그것을 누르면 실행 화면에 `img[class*="bubbleImage"]` 말풍선이 뜬다. 창을 닫고 다시 열어도 그림이 남아 있다. `빼기` 다음 `emoji.getByTitle('이모티콘 빼기')`를 누르면 사라진다.
- **증거.** 효과 창은 `s.shot(fx, ...)`으로 찍는다. 투명한 창이라 흰 바탕에 캐릭터나 글만 보인다. 실행 화면은 말풍선이 떠 있을 때 찍는다.

## Gotchas

- 효과 창은 연출이 하나라도 도는 동안만 열려 있다. 다음 연출을 시작하기 전에 `효과` 창이 모두 닫혔는지 기다려야 `windowTitled`가 새 창을 돌려준다.
- 캐릭터가 효과 창으로 옮겨 가 있는 동안에는 그 좌석의 말풍선도 숨는다. 💫는 날아갔다 돌아온 뒤나 납작해졌다 돌아온 뒤에 뜬다.
- 러시안룰렛 뒤에는 내 머리 위 `💫`가 몇 초 남는다. 다음 단계에서 `💫`를 찾기 전에 `toHaveCount(0)`으로 사라지기를 기다린다.
- ▼ 메뉴 `춤추기`는 깜짝쇼 횟수에 들지 않는다. 깜짝쇼는 대화하기 창의 춤 명령만 센다.
- 때리기는 하루 30번까지이고 러시안룰렛은 하루 6번까지이며 이 PC의 계정 파일에 센다. 같은 세션에서 여러 번 돌리면 쓴 횟수가 이어진다.
- 잠든 캐릭터 머리 위의 z는 자세 그림에 들어 있어서 반응 설정과 상관없이 보인다.
- 캐릭터를 누르면 메뉴가 아니라 쓰다듬기다. 메뉴는 이름표(`내 메뉴`, `가짜 친구 메뉴`)나 오른쪽 클릭으로 연다.
- 흔들기는 캐릭터 상자 안에서 움직인 것만 센다. 실제 화면에서는 캐릭터 밖으로 나간 포인터를 앱이 받지 못한다. 한 번 누른 동안 한 번만 어지러워하고 누른 채로 12px 넘게 움직였으면 놓아도 쓰다듬지 않는다.
- 자리비움인 사람은 `자리비움` 말풍선이 💗와 💫보다 우선이라 반응이 보이지 않는다. 신호는 그대로 간다.
