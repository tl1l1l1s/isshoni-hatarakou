# 친구

친구 창에서 내 친구 코드를 복사해 알려 주고 친구 코드로 신청한다. 방에서는 다른 사용자 메뉴의 `친구 신청`으로도 신청한다. 보낸 신청은 상대가 답할 때까지 친구 창에 남고 받은 신청은 수락하거나 거절한다. 친구가 되면 목록에 접속 상태와 있는 방이 보이고 같이 들어가거나 지금 방으로 초대한다.

## Sub-features

- `friend-code`는 친구 창 맨 위의 내 친구 코드와 `코드 복사`다 (FRD-01). 복사하면 친구 창 위쪽에 `친구 코드를 복사했어요.`가 뜬다. 프로필을 아직 받지 못했으면(오프라인으로 시작) 코드 대신 `연결되면 친구 코드가 보여요.`가 보인다.
- `friend-request`는 친구 코드 8자를 넣고 `친구 신청`을 누르거나 다른 사용자 메뉴의 `친구 신청`을 누르는 것이다 (FRD-02, ROM-11).
- `friend-pending`은 보낸 신청이 친구 창에 `<이름>님의 수락을 기다리는 중이에요.` 카드로 남고 그동안 그 사람 메뉴에서 `친구 신청`이 빠지는 것이다. 상대가 수락하거나 거절하거나 내가 `신청 취소`를 누르면 카드가 사라진다.
- `friend-accept`는 받은 신청 카드의 `수락`과 `거절`이다 (FRD-02).
- `friend-list`는 친구 N명 목록과 접속 상태, `같이 들어가기`, `초대하기`, `끊기`다 (FRD-03, FRD-04).
- `friend-offline`은 목록 아래 맨 끝의 `친구에게 오프라인으로 보이기`다 (FRD-06). 조작 순서는 [계정과 운영](./account-ops.md)에 있다.

## How to get to it (user POV)

- 실행 화면 ▼ 메뉴에서 `친구`를 누른다.
- 방에서 다른 사용자 이름표(끝에 ▾)를 누르거나 캐릭터를 오른쪽 클릭하고 `친구 신청`을 누른다.
- 친구 신청을 받으면 친구 창이 저절로 열린다. 초대를 받으면 알림이 뜨고 누르면 친구 창이 열린다.

## Driving it with drive.ts

Preconditions:

- 새 `verify()` 세션에서 시작하기를 눌러 실행 화면에 있다. 내 uid는 `window.core.deps.uid`이다.
- 가짜 친구의 답(수락과 거절)은 화면에서 만들 수 없다. `globalThis.devHub`로 메모리 서버에 쓰고 보고에 적는다.

- **코드가 없을 때.** `const fw = await menu(s, '친구', '친구')`를 실행한다. 메모리 서버에는 친구 코드가 없어서 `내 친구 코드` 아래에 `연결되면 친구 코드가 보여요.`가 보이고 `코드 복사`는 없다. 창 맨 끝에 `checkbox "친구에게 오프라인으로 보이기"`가 있다.
- **코드 복사.** 창을 닫고 스테이지에서 `core.deps.profile = { ...core.deps.profile, friendCode: 'MATE2345' }`로 코드를 넣은 뒤 다시 연다. `MATE2345`와 `button "코드 복사"`가 보이고 누르면 친구 창 위쪽에 `친구 코드를 복사했어요.`가 뜬다. `await s.app.evaluate(({ clipboard }) => clipboard.readText())`가 `MATE2345`다.
- **메뉴로 신청.** 방 창에서 `devdev`로 참여한다. `가짜 친구 메뉴`를 열고 `menuitem "친구 신청"`을 누르면 실행 화면에 `가짜 친구님에게 친구 신청을 보냈어요.`가 뜬다. 메뉴를 다시 열면 `친구 신청`이 없고 친구 창에 `가짜 친구님의 수락을 기다리는 중이에요.`와 `button "신청 취소"`가 있다.
- **거절.** 가짜 친구가 거절한 것처럼 `devHub.write('mod/friends/u/devfriend/in/<내 uid>', null)`을 쓴다. 카드가 사라지고 메뉴에 `친구 신청`이 돌아온다.
- **취소.** 다시 신청하고 `신청 취소`를 누른다. 카드가 사라지고 `devHub.read('mod/friends/u/devfriend/in/<내 uid>')`가 null이다.
- **수락.** 다시 신청하고 가짜 친구가 수락한 것처럼 `devHub.write('mod/friends/u/<내 uid>/in/devfriend', { ok: { at: Date.now() } })`를 쓴다. 카드가 사라지고 `친구 1명`이 되며 실행 화면에 `<이름>님과 친구가 됐어요.`가 뜬다. 가짜 친구 메뉴의 첫 항목이 `마이홈 보기`가 된다.
- **증거.** 코드가 없는 친구 창, 복사 알림이 뜬 친구 창, 신청 뒤 메뉴, 기다리는 카드, 수락 뒤 친구 창과 메뉴를 `s.shot`으로 남기고 `errors.json`이 `[]`인지 본다.

## Gotchas

- 메모리 서버의 가짜 친구는 공개 프로필 이름이 없어서 친구 목록에 `이름 없음`으로, 수락 알림에 `친구님과 친구가 됐어요.`로 보인다.
- 알림은 마지막으로 누른 창에 뜬다. 친구 창의 단추를 눌렀으면 친구 창에서, 실행 화면 메뉴를 눌렀으면 실행 화면에서 찾는다.
- 친구 창은 친구 코드를 그릴 때 읽는다. 코드를 넣은 뒤에는 창을 다시 연다.
- 기다리는 신청은 이 실행 동안만 기억한다. 앱을 다시 켜면 카드가 없고 메뉴에 `친구 신청`이 다시 보인다.
- 친구가 된 뒤 같이 들어가기와 초대는 [계정과 운영](./account-ops.md)의 오프라인 순서처럼 `users/devfriend/presence`와 서로의 `list`를 써야 확인할 수 있다.
