# 마이홈

마이홈 창에서 내 마이홈을 꾸미고 친구 마이홈에 놀러 간다. 프로필 칸 맨 위에 주인의 프로필 사진이 있다. 방명록은 최근 글 30개씩 보이고 이전 글 더 보기로 30개씩 더 받는다. 되돌릴 수 없는 지우기는 창 안에서 한 번 더 묻고 연결이 끊긴 동안에는 쓰지 않고 알린다. 편집에서 배경음악, 마이홈 색, 창 바탕 그림, 박수 이모지를 고르고 바탕화면 영역의 북마크 책장에 링크를 꽂는다. 말랑이를 불러 누르거나 끌어 올린다. [스케줄러]와 [D-day] 탭에서 일정과 카드를 더하고 실행 화면 상태칩의 🔔로 다가오는 일정을 본다. 친구 마이홈에서는 공개한 것만 보이고 박수를 보낸다.

## Sub-features

- `hom-02-ask`는 편집한 것을 저장하지 않고 ESC, 창 닫기 단추, 다른 탭으로 떠나려 하면 창 안에서 묻는 것이다. 편집 중 도구 줄에는 박수, + 스티커, 미리보기, 취소, 저장만 한 줄에 있고 저장은 검은 단추다 (HOM-02).
- `hom-03`은 프로필 칸 맨 위의 주인 프로필 사진이다. 친구 마이홈에서는 친구 사진이 보인다. 주인은 보기 화면의 사진 칸(`button "사진 넣기"`)이나 편집 화면 사진 아래의 `사진 넣기`로 사진을 바꾸고 편집 화면에는 그 아래에 친구로 등록한 사람만 본다는 안내가 있다 (HOM-03).
- `hom-08`은 편집에서 붙인 스티커의 크기와 회전 손잡이다. 보이는 점은 16px이고 누르는 자리는 32px이다 (HOM-08).
- `hom-09`는 방명록이다. 처음에는 최근 30개가 보이고 이전 글 더 보기를 누르면 30개씩 늘어난다. 친구 마이홈에서는 글을 남기고 남기는 동안 `남기기`가 꺼진다. 글쓴이 이름은 글에 적힌 이름이 아니라 보낸 사람 프로필의 이름이고 이름 앞에 그 사람 사진이, 내가 쓴 글에는 `(나)`가 붙는다. 주인의 빈 방명록에는 친구가 남긴 글이 여기에 보인다는 안내가 있고 `지우기`는 창 안에서 묻는다. 친구를 끊어도 그 사람이 남긴 글과 선물과 박수는 내 마이홈에 그대로 보인다 (HOM-09).
- `hom-14`는 선물함과 말랑이 선물이다. 말랑이가 하나면 선물 양식이 그 말랑이를 골라 둔 채 열리고 둘 이상이면 고르라는 안내가 보인다. 보내는 동안 `보내기`가 꺼진다. 친구가 아직 받지 않은 내 선물이 30개면 보내지 않고 안내가 뜬다. 빈 선물함에는 친구가 보낸 선물이 여기에 온다는 안내가 있다. 프로필 이름이 없는 사람이 남긴 글과 선물은 `이름 없음`으로 보인다 (HOM-14).
- `hom-04`는 플레이리스트 곡을 배경음악으로 고르고 누를 때만 200x200 플레이어로 재생하는 것이다. 플레이어는 플레이리스트 음량을 따르고 플레이리스트와 번갈아 재생한다. 곡을 고르지 않았으면 보기 화면에 막대 대신 회색 안내 글만 있다 (HOM-04).
- `hom-07`은 마이홈 색과 창 바탕 그림을 고르고 저장하는 것이다 (HOM-07).
- `hom-10`은 친구 탭에서 친구 마이홈으로 가고 내 마이홈으로 돌아오는 것이다 (HOM-10).
- `hom-11`은 북마크 책장에 공개 책과 비공개 책을 꽂고 공개 책을 기본 브라우저로 여는 것이다. `빼기`는 창 안에서 묻는다 (HOM-11).
- `hom-12-draw`는 말랑이를 직접 그리는 240px 칸이다. 처음에는 칸 가운데에 안내가 있고 그리면 사라지며 지우면 다시 보인다. 펜 색 칸 앞에 `펜 색` 글자가 있다 (HOM-12).
- `hom-13`은 말랑이를 누르면 뛰며 하트를 띄우고 다른 말랑이 머리 위로 끌어다 놓으면 올라타는 것이다. OS의 동작 줄이기를 켜면 말랑이와 스티커의 되풀이 움직임이 멈춘다. 말랑이 관리의 ×는 창 안에서 묻는다 (HOM-13).
- `hom-15`는 박수 버튼이다. 주인은 이모지만 터지고 보기 화면에서는 친구가 박수를 치면 수가 오른다는 알림이 뜬다. 친구는 수가 오르며 하루 5번이 넘으면 안내가 뜬다. 편집에서 박수 이모지를 단추 여섯 개 가운데 눌러 고르거나 칸에 직접 적는다 (HOM-15).
- `hom-16`은 스케줄러 달력에서 오늘 일정을 더하는 것이다. 고른 날 칸은 달력과 높이가 같고 일정 목록이 그 높이를 쓴다. `지우기`는 창 안에서 묻는다 (HOM-16).
- `hom-21`은 D-day 카드를 더하는 것이다. 카드 색은 기본 색 여섯 개, 색 고르기 칸, `#RRGGBB`나 `#RGB` 색 코드로 정하고 고르는 대로 카드가 미리 보인다. 글자는 카드 색에 따라 검정이나 흰색이고 작은 글자도 4.5:1 대비를 넘는다. 카드가 없으면 무엇을 세는지 안내가 보인다. 양식의 `지우기`는 창 안에서 묻는다 (HOM-21).
- `hom-22`는 상태칩 🔔 배지, 다가오는 일정 창, 오늘 일정 OS 알림이다 (HOM-22). 🔔 칩의 접근 가능한 이름은 `다가오는 일정 2개`처럼 수를 함께 읽고 배지는 공용 배지(`[data-unread]`)다. 다른 기기가 이 계정을 쓰는 중이면 알림을 보내지 않는다. 친구가 이름을 정하거나 바꾸면 1분 안에 친구 일정 줄의 이름이 바뀐다. 띄어쓰기 없는 긴 제목과 친구 이름도 창 안에서 줄을 바꾼다.
- `hom-offline`은 연결이 끊긴 동안의 마이홈이다. 방명록 남기기, 선물 보내기, 박수, 저장, 북마크, 말랑이, 사진, 일정과 D-day 저장과 지우기를 하지 않고 `연결이 끊겨서 보내지 못했어요. 연결되면 다시 해 주세요.`를 띄우며 적은 글과 양식은 그대로 둔다. 끊긴 채로 연 마이홈은 `연결되면 불러와요.`를 보이고 연결되면 불러온다.

## How to get to it (user POV)

- 실행 화면 ▼ 메뉴에서 `마이홈`을 누른다. 창 제목은 `마이홈`이다.
- 다른 사용자 캐릭터 메뉴의 `마이홈 보기`를 누른다. 친구로 등록한 사람에게만 보인다.
- 마이홈 창의 `친구` 탭에서 친구 줄의 `마이홈 보기`를 누른다.
- 7일 안에 일정이 있으면 실행 화면 내 캐릭터 상태칩에 🔔(`button[title="다가오는 일정"]`, 이름 `다가오는 일정 N개`)이 보이고 누르면 `다가오는 일정` 창이 열린다. 일정이 없으면 이 칩은 없다. ▼ 메뉴에는 이 창 항목이 없다.

## Driving it with drive.ts

Preconditions:

- 새 `verify()` 세션에서 시작하기를 눌러 실행 화면에 있다.
- 그림 고르기, 기본 브라우저 열기, OS 알림은 메인에서 바꿔 둔다. `s.app.evaluate(({ dialog, shell, Notification }, p) => { dialog.showOpenDialog = async () => ({ canceled: false, filePaths: [p] }); shell.openExternal = async (u) => void (globalThis.opened = u); Notification.prototype.show = function () { (globalThis.notes ??= []).push({ title: this.title, body: this.body }); }; }, pngPath)`처럼 쓴다. 그림은 `tests/e2e/boot.spec.ts`처럼 OffscreenCanvas로 만든다.
- 배경음악을 고르려면 플레이리스트에 곡이 있어야 한다. `const player = await menu(s, '플레이리스트', '플레이리스트')`, `player.getByLabel('유튜브 링크').fill('https://youtu.be/dQw4w9WgXcQ')`, `player.getByRole('button', { name: '+ 추가' }).click()`을 실행한다.
- 받은 기록과 친구 화면에 보이는 친구 이름은 `users/devfriend/public`의 `name`이다. 받은 기록에 적은 `name`은 화면에 나오지 않으니 준비할 때 `devHub.write('users/devfriend/public', { name: '가짜 친구' })`를 함께 쓴다.
- 친구가 남긴 방명록과 박수와 선물은 화면에서 만들 수 없다. 스테이지에서 `devHub.writeMany`로 `mod/home/u/<내 uid>/in/devfriend/<13자리 시각>`에 `{ name, text, at }`, `in/devfriend/clap`에 수, `in/devfriend/gift/<시각>`에 `{ file, msg, name, at }`를 쓴다. 선물 그림은 `c.deps.server.files.put(bytes)`로 올린 해시다. 친구 사진은 `mod/account/u/devfriend/photo`에 해시를 쓴다. 서로 친구 기록은 `mod/friends/u/devfriend/list/<내 uid>`와 내 `friends`의 `list/devfriend`다.
- 친구 마이홈은 화면에서 만들 수 없다. 스테이지에서 `window.core.deps.server`로 `identity.signIn('dev-devfriend')` 한 뒤 `profile.write('devfriend', { name: '가짜 친구' })`, `docs({ scope: 'user', module: 'friends', uid: 'devfriend' }).set('list/<내 uid>', { since, v: 1 })`, 친구의 `home`, `shelf`, `shelfPub`, `mod/scheduler`의 `ev`와 `pub`, `mod/dday`의 `cards`와 `pub`를 쓰고 `identity.signIn('dev-<내 uid>')`로 돌아와 내 `friends`의 `list/devfriend`를 쓴다. 내 uid는 `window.core.deps.uid`다.

- **편집과 저장 (hom-04, hom-07).** `const home = await menu(s, '마이홈', '마이홈')`, `home.getByRole('button', { name: '편집' }).click()`, `home.getByLabel('배경음악').selectOption('dQw4w9WgXcQ')`, `home.getByRole('button', { name: '분홍 색' }).click()`, `home.getByRole('button', { name: '창 바탕 그림' }).click()`, `home.getByLabel('박수 이모지').fill('🎉')`, `home.getByRole('button', { name: '저장' }).click()`을 실행한다. 박수 이모지는 칸에 적는 대신 `home.getByRole('button', { name: '박수 🎉' })`를 눌러도 된다. `button "🎉 박수 0"`이 보이고 `마이홈을 저장했어요.` 알림이 마이홈 창 위쪽에 뜬다. 창을 닫았다 다시 열어도 `[data-themed="true"][data-wall="true"]`인 보기 화면이 있고 그 배경 그림이 `blob:` 주소다. 편집 중에는 `방명록`, `선물함`, `말랑이 관리`, `말랑이 부르기`가 없고 `저장`이 `+ 스티커`와 같은 줄에 있다.
- **떠나기 전 묻기 (hom-02-ask).** 창에 `home.on('dialog', () => {})`를 먼저 붙인다([설정 창](./settings.md)의 Gotchas). `편집`을 누르고 `분홍 색`을 고른 뒤 `home.keyboard.press('Escape')`를 누르면 `alertdialog "저장하지 않은 편집이 있어요. 닫을까요?"`가 뜨고 창은 그대로다. `계속하기`를 누르면 고른 색(`[data-themed="true"]`)이 남아 있다. `친구` 탭을 눌러도, 메인에서 `BrowserWindow.getAllWindows().find((w) => w.getTitle() === '마이홈')?.close()`를 실행해도 같은 물음이 뜨고 `계속하기`를 누르면 편집 화면에 남는다. `저장`을 누른 뒤의 ESC와 아무것도 바꾸지 않은 편집 화면의 ESC는 묻지 않고 창을 닫는다. `취소`는 묻지 않고 바로 버린다.
- **프로필 사진 (hom-03).** 그림 고르기를 바꿔 둔 채 마이홈 보기 화면의 `home.locator('aside').getByRole('button', { name: '사진 넣기' })`(사진 칸)를 누르거나 `편집`을 누른 뒤 사진 아래의 `사진 넣기`를 누르면 `home.locator('aside').getByRole('img', { name: '프로필 사진' })`가 보이고 스테이지의 `devHub.read('mod/account/u/<내 uid>/photo')`가 해시다. 편집 화면 사진 아래에 `프로필 사진은 친구로 등록한 사람만 봐요.`가 보이고 `취소`를 눌러도 사진은 그대로다. 설정 창 `계정` 탭의 `사진 넣기`도 같은 사진을 바꾼다.
- **배경음악 없음 (hom-04).** 곡을 고르지 않은 내 마이홈 보기 화면에는 `배경음악 없음. 편집에서 플레이리스트 곡을 고를 수 있어요.` 글만 있고 `배경음악 듣기` 단추가 없다. 친구 마이홈에서는 `배경음악 없음`만 보인다.
- **방명록 쪽 (hom-09).** 준비로 친구 글 35개를 쓰면 `방명록` 버튼 글자가 `방명록30`이다. 누르면 패널 `li`가 30개이고 첫 줄이 가장 새 글이다. `이전 글 더 보기`를 누르면 35개가 되고 버튼이 사라진다.
- **선물함 (hom-14).** 준비로 선물을 쓰면 메인 `globalThis.notes`에 `{ title: '말랑이 선물', body: '가짜 친구님이 말랑이를 보냈어요.' }`가 생기고 `선물함` 패널에 `가짜 친구님의 선물`이 보인다. `선물함` 단추의 수는 `[data-unread]` 배지(11px 굵은 흰 글자, 높이 16px)다. 선물이 없으면 패널에 `친구가 보낸 말랑이 선물이 여기에 와요.`가 보이고 방명록 패널에는 `친구가 내 마이홈에 놀러 와서 남긴 글이 여기에 보여요.`가 보인다.
- **보낸 사람 이름과 사진 (hom-09, hom-14).** 준비로 `in/devfriend/<시각>`에 `name: 'alice'`인 글, `in/devfriend/gift/<시각>`에 `name: 'mallory'`인 선물, 이름이 같은 `qa2`의 글(`users/qa2/public`의 name도 `가짜 친구`, 서로 친구 기록 포함)을 쓴다. 방명록 두 줄이 모두 `가짜 친구`이고 `alice`는 없으며 사진을 넣은 devfriend 줄에만 `img "프로필 사진"`이 있다. 선물함 줄은 `가짜 친구님의 선물`이다.
- **지우기 묻기 (hom-09, hom-11, hom-13, hom-16, hom-21).** 방명록 글의 `지우기`를 누르면 `alertdialog`에 `이 글을 지울까요? 지우면 되돌릴 수 없어요.`와 `지우기`, `취소`가 뜨고 `취소`를 누르면 서버 글이 남는다. 다시 눌러 `지우기`를 누르면 지워진다. 북마크 `빼기`는 `이 책을 뺄까요? 빼면 되돌릴 수 없어요.`, 말랑이 관리의 `×`는 `이 말랑이를 지울까요? 지우면 되돌릴 수 없어요.`, 스케줄러 `지우기`는 `이 일정을 지울까요? 지우면 되돌릴 수 없어요.`, D-day 양식의 `지우기`는 `이 D-day를 지울까요? 지우면 되돌릴 수 없어요.`를 묻는다.
- **두 번 누르기 (hom-09, hom-14).** 스테이지에서 `core.deps.server.docs`를 감싸 문서 호출마다 300ms를 늦춘 뒤(Firebase 왕복 흉내) `보내기`와 `남기기`를 120ms 간격으로 두 번 누른다. 두 번째 클릭은 단추가 꺼져 있어 닿지 않고 서버의 선물과 글이 하나씩이다. 친구 마이홈 방명록의 내 글에는 `(나)`가 붙는다.

## Gotchas

- 새 세션의 이름은 빈 문자열이라 마이홈 이름 칸이 비어 있다. 친구 마이홈에 남긴 내 글의 글쓴이도 `이름 없음 (나)`다.
- 지우기 물음(`alertdialog`)의 기본 포커스는 `취소`다. 물음 안의 `지우기`는 목록 줄의 `지우기`와 이름이 같으니 `home.getByRole('alertdialog').getByRole('button', { name: '지우기' })`로 찾는다.
- 검증 환경에서는 YouTube가 열리지 않아 플레이어가 검은 칸으로 보일 수 있다. 플레이어가 200x200으로 뜨는 것까지만 확인한다.
- 박수 이모지 칸의 이름은 `박수 이모지`이고 placeholder는 👏다. 박수 버튼 이름은 `<이모지> 박수 <수>`라서 이모지를 바꾸면 이름도 바뀐다.
- 북마크 패널, 말랑이 관리 패널은 오른쪽 위를 덮어서 말랑이를 누르기 전에 `닫기`로 닫는다.
- 편집 화면에는 `방명록`, `선물함`, `말랑이 관리`, `말랑이 부르기`가 없다. 이 단추를 쓰는 순서는 보기 화면에서 한다.
- 친구 일정 줄의 이름은 1분마다 다시 읽는다. 이름을 바꾼 뒤에는 75초까지 기다린다.
- 말랑이는 걷고 쉬고 벽을 타서 위치가 계속 바뀐다. 끌기 직전에 위치를 다시 읽는다. 벽 타기와 밀기는 무작위라 화면 검증 대신 `src/modules/home/logic.test.ts`로 확인한다.
- 🔔 배지는 오늘부터 7일 뒤까지만 센다. 지난날을 1일째로 세는 카드는 세지 않는다.
- 같은 일정 알림은 하루에 한 번이라 세션을 새로 켜야 다시 온다.
- 방명록과 박수는 보낸 사람 칸마다 읽는다. 내 마이홈은 내 친구 목록과 기록을 남긴 사람 색인 `senders`에 있는 사람의 칸을, 친구 마이홈은 내 친구 목록과 나의 칸만 읽는다. 준비 조건으로 친구 기록을 쓸 때 친구 목록에도 색인에도 없는 uid로 쓰면 보이지 않는다.
- 친구 창의 친구 이름은 `users/devfriend/public`이 없으면 `이름 없음`이다. 끊기 확인 줄은 `/친구를 끊을까요\?/`로 찾는다.
- 서버 시각을 옮긴 뒤에는 오늘이 바뀌어 같은 세션에서 날짜 기준 검사를 다시 하지 않는다. 날짜를 옮기는 검사는 마지막에 둔다.
- 방명록 글 키는 13자리 시각이어야 한다. 다른 모양의 키는 쪽 나누기 순서가 어긋난다.
- `스케줄러`와 `D-day` 탭은 처음 누를 때 불러온다. 그동안 `불러오는 중이에요.`가 잠깐 보일 수 있으니 탭 안의 요소를 기다린 뒤 조작한다.
