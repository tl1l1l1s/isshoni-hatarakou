# isshoni-hatarakou 검증 지도

이 폴더는 isshoni-hatarakou 사용자 기능을 검증할 때 따르는 기준이다. 앱을 조작하기 전에 이 목록을 읽고 해당 기능 파일의 순서대로 조작한다.

## 기본 전제

- `node .claude/skills/verify-isshoni/drive.ts doctor`가 `doctor ok`를 출력한다.
- 모든 조작은 새 `verify()` 세션 안에서 한다. 새 세션의 이름은 `이름 없음`이고 캐릭터 슬롯은 `캐릭터 (1/3)`이며 방에는 들어가 있지 않다(혼자 모드).
- 메모리 서버에는 방 코드 `DEVDEV`인 개발 방이 있고 그 방에 `가짜 친구`가 있다. 코드는 소문자 `devdev`로 넣어도 들어간다.
- 앞에 있는 앱과 유휴 시간은 실제 OS 대신 `fakePlatform`이 알려 준다. 세션을 새로 켜면 앞에 있는 앱은 없다.

## 조작 규칙

- 요소는 role과 접근 가능한 이름, placeholder, label로 찾는다. 이름 일부가 겹치는 버튼은 `exact: true`로 찾는다.
- 기능 창은 창 제목으로 찾는다. ▼ 메뉴로 연 창의 제목은 메뉴 항목 이름과 같다.
- 결과는 `expect`의 자동 대기, `expect.poll`, `toPass`로 기다린다. `waitForTimeout` 같은 고정 대기는 부하에 따라 모자라거나 남아서 결과가 실행마다 달라진다.
- 증거 파일 이름은 하위 기능 ID로 시작한다. 예를 들어 `room-join.png`처럼 쓴다.

## 증명과 건너뜀 보고

- 사용자 동작과 결과 상태를 모두 `s.shot`으로 남긴다.
- 변경은 다른 창이나 다시 연 창에서 한 번 더 읽어서 확인한다.
- `errors.json`이 빈 배열인지 확인한다.
- 도달하지 못한 경로는 시도한 코드와 갖춰지지 않은 전제를 함께 보고한다. 검증했다고 보고하는 경로는 실제로 조작한 경로뿐이다.

## 기능 파일 형식

각 파일은 H1 제목과 사용자가 보는 동작을 설명하는 한 문단으로 시작하고 H2 네 개를 이 순서로 둔다.

1. `Sub-features`는 하위 기능 ID와 한 줄 설명이다.
2. `How to get to it (user POV)`는 사용자가 그 기능에 들어가는 모든 경로다.
3. `Driving it with drive.ts`는 `Preconditions:`로 시작하고 사용자 동작, 실행할 코드, 보여야 할 결과를 짝지은 항목을 둔다.
4. `Gotchas`는 검증 시간을 낭비하거나 결과를 무효로 만드는 함정이다.

구현 내부는 적지 않는다. 사용자 경로, 요소를 찾는 이름, 필요한 상태, 코드, 관찰할 결과만 적는다.

- [런처와 실행 화면](./launcher-stage.md)은 런처 표시와 이름 줄, 시작하기, ▼ 메뉴, 런처로 돌아가기를 다룬다.
- [내 정보](./me.md)는 런처의 내 정보 화면에서 프로필 사진, 친구 코드 복사, 친구 랭킹, 자리비움 그림, 보관함, 계정, 휴지통 복원을 다룬다.
- [방](./rooms.md)은 코드로 참여하기, 다른 사용자 메뉴, 내 방 만들기, 방 설정 창, 절전 뒤 다시 들어가기, 다른 기기가 가져갔을 때의 접속 상태, 자동 퇴장을 다룬다.
- [집중 앱과 시간](./focus.md)은 집중 앱 등록, 포커스 기록의 시간 증가, 기록 미니 창, 다른 기기에서 쓰는 중일 때 시간이 멈추는 것을 다룬다.
- [캐릭터 만들기](./wardrobe.md)는 얼굴 그리기와 그 안의 ESC, 책상 고르기, 저장, 다시 열었을 때 유지되는지와 혼자 모드 자리 추가를 다룬다.
- [대화하기](./chat.md)는 방 안에서 메시지 보내기와 보내기 버튼, 이름 앞 프로필 사진, 보내지 못한 글 다시 보내기, 실행 화면 말풍선, 글자 크기를 다룬다.
- [자리비움과 자리비움 그림](./status.md)은 자동 자리비움과 자리비움 그림 등록, 캐릭터 대신 그림이 서는 것을 다룬다.
- [플레이리스트와 소리](./sound.md)는 프로필 줄과 소개글, 프리셋, 축소 플레이어, 친구 플리 구경과 파도타기, 채팅 알림음, 회사원 모드의 소리, 소리가 없을 때 AudioContext가 멈추는 것을 다룬다.
- [마이홈](./home.md)은 프로필 사진, 방명록 쪽 나누기, 선물함과 선물 한도, 스티커 손잡이, 배경음악, 마이홈 색과 창 바탕, 북마크, 말랑이 동작, 웹박수, 스케줄러, D-day, 다가오는 일정, 친구 마이홈 방문을 다룬다.
- [놀이](./play.md)는 춤추기, 러시안룰렛, 쓰다듬기와 흔들기, 때리기, 폭탄, 채팅 날리기, 깜짝쇼, 내 이모티콘, 머리 위 반응 설정을 다룬다.
- [올라타기와 동물탑, 벤치](./play-seats.md)는 동물 캐릭터가 남의 머리 위에 올라타 탑을 쌓는 것과 벤치 책상에 같이 앉는 것을 다룬다.
- [스티커 사진](./photo.md)은 촬영 자리와 진행자, 자세 주고받기, 하루 촬영 한도, 촬영 음악, 대화하기 창 단추, 혼자 찍기, 꾸미기, 저장, 방에 보내기와 받은 사진을 다룬다.
- [레벨과 레벨 보상](./growth.md)은 레벨 보상 표, 회차, 레벨 티어와 잠든 동안 멈추는 광택을 다룬다.
- [달성표](./goals.md)는 하루 집중 목표와 이번 주 요일별 표시를 다룬다.
- [뽀모도로](./pomodoro.md)는 타이머 시작, 일시정지, 단계가 끝날 때 알림, 머리 위 남은 시간을 다룬다.
- [폰 연결](./phone.md)은 연결 키, QR, 폰 신호로 시간이 쌓이는 것, 안내 페이지를 다룬다.
- [방 가챠의 기간 한정과 색 해금](./gacha.md)은 기간 한정 아이템과 같은 아이템 4개로 스티커 색을 여는 것을 다룬다.
- [꾸미기](./stickers.md)는 키보드로 고르기와 넓힌 손잡이, 같은 아이템 여러 개 붙이기, 직접 그리기와 도안, 칠판, 바닥 오브제, 저장 뒤 유지를 다룬다.
- [설정 창의 화면 탭과 일반 탭](./settings.md)은 회사원 모드와 화면 숨기기, 테마, 상태칩 자리, 도트 그림, 영상 겹침 우회, 버전과 개인정보 처리방침을 다룬다.
- [설정 코드와 오프라인 시작](./setup-code.md)은 첫 실행의 설정 코드 입력 창, 실패 안내, 창을 닫았을 때 다시 열리는 것, 인터넷 없이 켰을 때 런처가 뜨는 것을 다룬다.
