# 같이 작업하기

방 안에서 같이 작업하기 창으로 세션을 열면 방 사람들이 같은 시각에 집중을 시작하고 같이 쉰다. 다른 사람이 연 세션은 초대 알림과 상태칩 줄의 `같이 작업` 칩으로 보인다. 참여하면 한 줄 목표를 적을 수 있고 공유를 켠 목표만 다른 참여자에게 보인다. 개설자가 시작하면 5초 뒤 집중이 시작되고 참여자 머리 위에 `함께 집중 N분 남음`이, 칩에 `같이 N분`이 보인다. 집중과 휴식이 끝나면 알림이 뜬다. 개인 뽀모도로와는 함께 돌지 않는다. 개설자와 방 주인은 세션 전체를 끝낸다.

## Sub-features

- `cowork-open`은 방 안에서 ▼ 메뉴로 창을 열고 제목, 집중, 휴식, 한 줄 목표로 세션을 만드는 것이다. 혼자 모드에서는 메뉴 항목이 흐리다 (ROM-15).
- `cowork-invite`는 다른 사람이 연 세션이 초대 알림 한 번과 `같이 작업` 칩으로 보이고 참여하는 것이다 (ROM-15).
- `cowork-run`은 시작 뒤 5초 대기, 함께 집중, 함께 휴식, 끝 알림과 머리 위 남은 분과 칩의 남은 분이다 (ROM-15).
- `cowork-pomodoro`는 개인 뽀모도로가 도는 중에 참여하면 끝낼지 묻고 참여 중에 개인 뽀모도로를 시작하면 세션에서 나오는 것이다 (ROM-15, FOC-07).
- `cowork-end`는 나가기, 세션 끝내기, 한 번 더다 (ROM-15).
- `cowork-quiet`은 회사원 모드에서 칩과 머리 위 표시와 초대 알림이 숨는 것이다 (ROM-15, SET-03).

## How to get to it (user POV)

- 방에 들어간 뒤 실행 화면 ▼ 메뉴에서 `같이 작업하기`를 누른다. 둘째 묶음의 `워킹룸` 다음에 있다.
- 방에 진행 중인 세션이 있으면 상태칩 줄의 `같이 작업`(참여 중이면 `같이 N분`) 칩을 누른다.

## Driving it with drive.ts

Preconditions:

- 새 `verify()` 세션에서 시작하기를 누르고 [방](./rooms.md) 순서로 `devdev`에 들어가 `가짜 친구`가 보인다.
- 메모리 서버의 방 코드는 `DEVDEV`이고 가짜 친구 uid는 `devfriend`다. 내 uid는 `window.core.deps.uid`다.

- **혼자 모드 (cowork-open).** 방에 들어가기 전에 ▼ 메뉴를 열면 `button "같이 작업하기"` 뒤에 `방에서만`이 붙고 `aria-disabled="true"`다.
- **만들기 (cowork-open).** `const w = await menu(s, '같이 작업하기', '같이 작업하기')`를 실행한다. `getByLabel('제목 (선택)')`, `getByLabel('집중 (분)')`(기본 50), `getByLabel('휴식 (분)')`(기본 10), `getByLabel('한 줄 목표 (선택)')`, `getByLabel('이 세션에 공유')`가 있다. 집중 5, 휴식 1, 목표 `러프 끝내기`, 공유를 켜고 `만들기`를 누른다. 창에 `시작 전`, `내가 열었어요. 집중 5분, 휴식 1분`, `참여자 1명`이 보이고 실행 화면에 `button "같이 작업"`이 생긴다. `devHub.read('mod/cowork/r/DEVDEV/parts/<내 uid>')`의 `goal`이 `러프 끝내기`다.
- **친구 참여.** 가짜 친구의 참여는 화면에서 만들 수 없으니 `devHub.write('mod/cowork/r/DEVDEV/parts/devfriend', { sid: <cur.id>, at: Date.now(), goal: '채색', v: 1 })`를 쓰고 보고에 적는다. `cur.id`는 `devHub.read('mod/cowork/r/DEVDEV/cur/id')`다. 창이 `참여자 2명`이 되고 `채색`이 보인다.
- **진행 (cowork-run).** `시작`을 누르면 창에 `곧 시작해요`가 보이고 5초 안에 `함께 집중`과 `5:00`, `오후 3:29에 끝나요` 같은 끝 시각이 보인다. 같이 작업하기 창 위쪽에 `함께 집중을 시작해요. 5분 집중해요.` 알림이 뜬다. 실행 화면 두 좌석 머리 위에 `함께 집중 5분 남음`, 칩에 `button "같이 5분"`이 보인다. 단계가 끝날 때 알림은 `집중이 끝났어요. 1분 쉬어요.`와 `같이 작업이 끝났어요.`이고 OS 알림도 뜬다. 시간을 줄이려면 집중 5분 세션을 끝까지 기다리는 대신 [시뮬레이터 시험](../../../../src/modules/cowork/sim.test.ts)을 본다.
- **개인 뽀모도로 (cowork-pomodoro).** 참여 중에 `menu(s, '뽀모도로', '뽀모도로')` 창에서 `시작`을 누르면 뽀모도로 창 위쪽에 `개인 뽀모도로를 시작해서 같이 작업하기에서 나왔어요.`가 뜨고 같이 작업하기 창이 `참여자 1명`이 된다. 뽀모도로가 도는 채로 같이 작업하기 창의 `참여`를 누르면 `alertdialog "개인 뽀모도로를 끝내고 참여할까요?"`가 뜨고 `끝내고 참여`를 누르면 참여자가 다시 2명이 되며 뽀모도로 창은 `시작` 단추로 돌아온다.
- **끝내기 (cowork-end).** `세션 끝내기`를 누르고 `alertdialog`의 `끝내기`를 누른다. 창에 `같이 작업이 끝났어요.`와 `한 번 더`가 보이고 실행 화면의 `같이 작업` 칩이 사라진다. 참여 중에 `나가기`를 누르면 참여자 수가 1 줄고 칩은 `같이 작업`으로 돌아온다.
- **친구가 연 세션 (cowork-invite).** 새 세션에서 `devHub.writeMany({ 'mod/cowork/r/DEVDEV/cur': { id: 'friend1', by: 'devfriend', title: '마감', f: 25, b: 5, st: 'wait', at: devHub.now(), v: 1 }, 'mod/cowork/r/DEVDEV/parts/devfriend': { sid: 'friend1', at: devHub.now(), v: 1 } })`를 쓴다. 실행 화면에 `가짜 친구님이 같이 작업하기를 열었어요.`와 `button "같이 작업"`이 보인다. 칩을 누르면 창에 `가짜 친구님이 열었어요. 집중 25분, 휴식 5분`이 보이고 `시작`과 `세션 끝내기`는 없다(나는 devdev 방 주인이 아니다). 공유를 끈 채 `참여`를 누르면 내 참여 기록에 `goal`이 없다. `devHub.update('mod/cowork/r/DEVDEV/cur', { st: 'run', go: devHub.now() })`를 쓰면 5초 안에 `함께 집중`이 되고 칩이 `같이 25분`이다.
- **회사원 모드 (cowork-quiet).** 위 상태에서 [설정 창](./settings.md)의 `회사원 모드`를 켜면 `같이 25분` 칩과 머리 위 `함께 집중 25분 남음`이 사라지고 끄면 돌아온다.
- **증거.** 단계마다 `s.shot`으로 창과 실행 화면을 남긴다. 파일 이름은 `cowork-`로 시작한다.

## Gotchas

- 알림은 30초 안에 마지막으로 누른 창 위쪽에 뜬다. 시작을 누른 뒤의 알림은 같이 작업하기 창에서, 뽀모도로 시작 뒤의 알림은 뽀모도로 창에서 찾는다.
- 앞 단계에서 고른 상태 글(예 `밥 먹는 중`)이 있으면 머리 위에는 그 글이 먼저 보이고 `함께 집중`은 보이지 않는다(CHR-09). 칩으로 확인하거나 상태를 비운다.
- 메모리 서버는 규칙을 검사하지 않는다. 권한(개설자만 시작, 방 주인 끝내기, 남의 참여 기록 쓰기 거부)은 `npm run test:emulator`의 `src/modules/cowork/rules.test.ts`로 확인한다.
- `devHub.advance`로 서버 시각을 앞당기면 가짜 친구가 오래된 좌석으로 빠진다. 앞당긴 뒤 `rooms/DEVDEV/members/devfriend_dev/seenAt`에 `devHub.now()`를 다시 쓴다.
- Playwright `.or()`는 다른 창의 locator를 함께 쓰지 못한다. 알림을 찾을 창을 하나로 정한다.
