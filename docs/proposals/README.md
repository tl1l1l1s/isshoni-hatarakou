# 함께 작업하는 경험 확장 제안

작성일: 2026년 10월 10일 · 상태: 기획 초안, 미구현

현재 앱의 캐릭터, 집중 기록, 방, 꾸미기, 사진을 연결해 함께 시작하고, 공간을 만들고, 기억을 남기는 경험을 제안합니다. 구현 부담에 따른 축소나 개발 일정은 정하지 않았습니다. 문서의 수치와 동작은 검토 가능한 제안 기본값이며 출시가 확정된 명세가 아닙니다.

현재 동작을 설명하는 [기능 명세](../feature-spec/README.md)와 구현 결정을 기록하는 `docs/adr/`와 구분합니다. 구현 시 해당 기능 명세와 실제 검증 절차를 함께 갱신합니다.

| 문서 | 사용자가 얻는 경험 | 기존 기능과의 차이 |
|---|---|---|
| [01 공동 작업 세션](01-shared-work-session.md) | 같이 시작하고 같이 쉬기 | 개인 뽀모도로의 상태 공유에서 공동 시작·종료로 확장 |
| [02 함께 키우는 작업실](02-growing-workroom.md) | 작업하며 우리 공간 만들기 | 개인 레벨·가챠 외에 방에 남는 공동 성장 |
| [03 우리의 작업 앨범](03-work-album.md) | 함께한 날을 다시 꺼내 보기 | 파일로 저장하는 사진을 지속되는 공동 기록으로 확장 |
| [04 작업 카드와 완성 전시대](04-work-cards-and-showcase.md) | 무엇을 했는지 남기고 보여주기 | 앱별 시간·날짜별 일정에 작업 단위와 결과물을 추가 |
| [05 캐릭터의 작은 생활](05-character-daily-life.md) | 옆자리 친구의 존재 느끼기 | 수동 놀이 외에 상황에 따른 반응과 책상 선물 추가 |

작업 약속·반복 모임 기능은 이번 제안에서 제외합니다. 공동 세션은 지금 시작하는 활동이며 예약이나 출석 관리를 포함하지 않습니다.

## 함께 사용할 때

1. 작업 카드에 오늘 할 일을 적습니다.
2. 친구가 연 공동 작업 세션에 참여합니다. 카드를 고르지 않아도 참여할 수 있습니다.
3. 실제 집중 기록이 쌓이면 선택해 둔 방의 공동 프로젝트도 진행됩니다.
4. 휴식이 되면 캐릭터들이 기지개를 켜고 원하는 사람끼리 간식을 나눕니다.
5. 세션 소감, 사진, 완성작을 각자 선택해 앨범에 남깁니다.

다섯 기능을 모두 켤 필요는 없습니다. 세션 없이 카드에 시간을 기록하고, 카드 없이 세션에 참여하고, 앨범 없이 작업실을 키울 수 있습니다. 기능 연결은 공개 API와 이벤트로 하고 다른 모듈의 내부 상태를 직접 읽지 않습니다.

## 공통 원칙

- 기존 집중 판정이 시간의 기준입니다. 타이머가 흐르거나 캐릭터가 움직였다는 이유로 경험치를 더하지 않습니다.
- 작업명, 소감, 결과물은 사용자가 직접 고른 것만 공유합니다. 앱 이름, 창 제목, 화면 캡처를 자동으로 보내지 않습니다.
- 불참·중도 퇴장·휴식·며칠간 미접속에 벌점을 주지 않습니다. 개인 기여도 순위나 의무 출석을 만들지 않습니다.
- 알림은 창 포커스를 빼앗지 않습니다. 회사원 모드와 연출 줄이기 설정을 각 기능에서 존중합니다.
- 공동으로 보는 기록도 작성자별 수정·삭제 권한을 구분합니다. 내려받은 파일까지 원격으로 회수할 수 있다는 안내는 하지 않습니다.
- 오전 6시에 바뀌는 집중 일자와 일반 달력 날짜를 혼동하지 않습니다. 세션은 고유 ID, 사진과 기록은 실제 발생 시각도 함께 가집니다.

## 구현 전 함께 정할 사항

각 문서의 화면과 규칙을 검토한 뒤 구현 순서를 정합니다. 특히 공동 이미지의 보관 품질과 저장소, 방을 떠난 사람의 열람 권한, 공동 성장의 시간 보정 정책은 데이터 계약을 만들기 전에 확정해야 합니다. 현재 저장 구조에서 자동으로 지원된다고 가정하지 않습니다.
