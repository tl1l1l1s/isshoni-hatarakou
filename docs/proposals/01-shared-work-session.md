# 공동 작업 세션 — 같이 한 판 작업하기

작성일: 2026년 10월 10일 · 상태: 기획 초안, 미구현

## 경험과 목적

친구와 같은 방에 있어도 각자 시작을 미루거나 쉬는 시간이 엇갈릴 수 있습니다. “지금 50분 같이 하자”에 참여하면 시작과 끝을 함께 경험하도록 합니다. 참여 인원이나 완료율을 평가하는 기능은 아닙니다.

예: 민지가 `50분 원고 작업`을 열고 준호는 `러프 끝내기`, 수진은 `자료 읽기`를 적어 참여합니다. 함께 시작한 뒤 각자 작업하고, 끝나면 완료 여부와 무관하게 기지개를 켭니다. 쉬면서 오늘 한 일을 한 줄 남길 수 있습니다.

## 현재 기능과 연결

- [pomodoro](../../src/modules/pomodoro/index.ts)는 기기별 타이머와 남은 시간의 방 공유를 제공합니다. 공동 세션은 방의 공통 종료 시각과 참여 명단을 추가합니다.
- [focus](../../src/modules/focus/api.ts)의 실제 집중 기록은 그대로 유지합니다. 세션 50분과 실제 집중 32분은 서로 다른 값입니다.
- [작업 카드](04-work-cards-and-showcase.md)는 선택 사항입니다. 카드 없이 한 줄 목표를 적거나 목표 없이 참여할 수도 있습니다.

## 사용자 흐름과 화면

1. 방 메뉴의 `같이 작업하기`에서 제목, 집중 시간, 휴식 시간을 정합니다. 제안 기본값은 50분·10분이며 각각 5~180분, 0~60분으로 바꿀 수 있습니다.
2. 방 사람에게 조용한 초대가 한 번 표시됩니다. `참여`, `나중에`를 고르고 무시해도 됩니다. 대기 화면에 목표의 공개 범위도 표시합니다.
3. 개설자가 `시작`을 누르면 5초 뒤 집중이 시작됩니다. 혼자라도 시작할 수 있습니다.
4. 참여자의 상태칩에 `함께 집중 · 38분`이 표시됩니다. 펼치면 참여자, 각자 공개한 목표, 종료 시각을 봅니다. 등록 앱이나 개인 활동 내역은 보이지 않습니다.
5. 집중 종료 시 `완료했어요 / 조금 진행했어요 / 다음에 이어서`와 선택 소감을 남깁니다. 응답을 닫아도 휴식은 예정대로 시작합니다.
6. 휴식 종료 후 세션은 끝납니다. `한 번 더`는 새 세션을 만들며 이전 참여자를 자동으로 넣지 않습니다.

한 방에는 진행 중인 세션 하나를 둡니다. 세션 창은 `대기 → 집중 → 휴식 → 종료`를 표시하고, 기록 화면에는 예정 시간과 실제 참여 구간을 구분합니다. 개인별 집중 초는 본인에게만 기본 표시합니다.

## 동작 규칙

| 상황 | 제안 동작 |
|---|---|
| 늦게 참여 | 남은 시간으로 합류하며 과거 참여 시간을 소급하지 않음 |
| 개인 뽀모도로가 실행 중 | 참여 전에 개인 타이머를 멈출지 선택; 취소하면 공동 세션에 참여하지 않음 |
| 세션 도중 개인 타이머 시작 | 공동 세션에서 나간다는 안내 후 전환; 타이머 두 개가 종료 알림을 경쟁하지 않음 |
| 중도 퇴장·방 이동 | 해당 참여 구간 종료; 실패 표시나 경험치 차감 없음 |
| 개설자 연결 끊김 | 서버 기준 종료 시각으로 계속 진행; 개설자 PC의 틱에 의존하지 않음 |
| 절전·오프라인 후 복귀 | 현재 단계로 복구; 지난 종료 알림을 연달아 재생하지 않음 |
| 모두 퇴장 | 집중을 자동 연장하지 않음; 예정 종료 시각을 기준으로 완료 처리 |
| 시작 전 취소 | 개설자가 취소 가능; 방 주인은 방의 활성 세션을 취소 가능 |
| 시작 후 전체 중단 | 개설자 또는 방 주인이 확인 후 중단; 누구나 자기 참여만 끝낼 수 있음 |

시작 후 집중·휴식 길이를 바꾸거나 전체를 일시정지하지 않습니다. 누군가 잠깐 자리를 비워도 다른 참여자의 흐름은 이어집니다. 완료 소감은 나중에 작성할 수 있고 응답 기한을 출석 조건으로 사용하지 않습니다.

자정을 지나거나 집중 일자 경계인 오전 6시를 지나도 세션 ID는 같습니다. 집중 시간은 기존 focus의 날짜 규칙에 따라 나뉩니다.

## 기록과 공개 범위

- 세션 기록: ID, 방, 제목, 개설자, 단계별 기준 시각, 중단 여부, 참여 구간.
- 참여자 기록: 본인의 목표, 목표 공개 여부, 선택한 작업 카드 ID, 선택 소감. 비공개 카드 제목을 세션에 자동 복사하지 않습니다.
- 목표와 소감은 기본 비공개이며 `이 세션에 공유`를 켠 항목만 참여자에게 공개합니다. 타인의 목표를 개설자가 바꾸지 못합니다.
- 전체 세션 종료와 개인 소감 저장을 분리합니다. 소감 작성 중 끊겨도 타이머 종료가 취소되지 않습니다.
- 앨범으로 보내기는 종료 후 별도 선택입니다. 참여했다는 이유만으로 이름·목표·소감을 앨범에 게시하지 않습니다.

## 구현 연결 제안

`sessions` 모듈을 후보로 두고 방 상태, UI, 세션 기록을 맡깁니다. 개인 뽀모도로에는 실행 여부 조회와 사용자 동의에 따른 정지 계약이 필요합니다. 현재 공개된 계약처럼 취급하지 않습니다.

공동 타이머는 서버 기준 시작·종료 시각으로 계산합니다. 동시에 두 명이 시작하거나 종료를 저장해도 세션 하나만 성립하도록 원자적 전이를 검증합니다. 읽기 권한과 참여자의 자기 기록 쓰기는 서버 규칙에서 제한합니다. 장기 세션 기록의 보관 기간은 구현 전에 정합니다.

## 확인할 시나리오

- 두 사람이 서로 다른 시각에 창을 열어도 같은 종료 시각을 본다.
- 두 개설자가 동시에 생성해도 활성 세션은 하나다.
- 개설자 이탈, 중도 참여, 방 이동, 절전 복귀가 다른 사람 타이머를 초기화하지 않는다.
- 개인 타이머와 공동 타이머의 알림이 중복되지 않는다.
- 50분 동안 참여만 하고 집중 판정이 없으면 경험치는 추가되지 않는다.
- 비공개 목표가 다른 참여자의 데이터 응답과 앨범 초안에 포함되지 않는다.

## 검토할 선택

전체 중단 권한을 개설자와 방 주인에게 함께 줄지, 방 주인에게만 줄지 실제 사용 흐름으로 결정합니다. 참여 구간 기록은 제공하되 개인별 참여율 비교 화면은 만들지 않는 방향을 제안합니다.
