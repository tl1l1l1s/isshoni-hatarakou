## 1. 한눈에 보기

이 장은 Isshoni Hatarakou가 어떤 앱인지와 핵심 사용 흐름, 주요 화면과 창, 이 문서에서 쓰는 용어를 짧게 소개합니다. 기능별 동작은 2장부터 8장까지에 있고 이 장에는 해당 장 번호만 적었습니다.

### 1.1 어떤 프로그램인가

Isshoni Hatarakou는 친구에게 선물하는 Windows용 데스크톱 작업 메이트입니다. 친구가 직접 그린 2D 캐릭터가 책상과 함께 바탕화면 위에 떠 있고 등록한 작업 프로그램을 쓰는 동안 깨어 있다가 쓰지 않으면 잠듭니다. 작업한 시간은 포커스 기록으로 쌓이고 누적 1시간마다 레벨이 1 오릅니다. 같은 방 코드로 들어간 사람들의 캐릭터는 각자의 화면에서 내 캐릭터 옆자리에 나란히 앉아 깨어 있는지와 지금 상태를 바로 보여 줍니다. 방마다 방 사람들이 넣은 그림으로 가챠를 두고 그 방에서 작업한 시간으로 뽑은 아이템을 캐릭터에 스티커로 붙입니다.

계정은 선물하는 사람이 스크립트로 만들어 설정 코드로 건네고 앱은 이 계정으로 레벨, 캐릭터, 집중 기록을 PC와 서버에 함께 저장합니다. 앱 안에 구매 절차가 없고 모든 기능을 처음부터 씁니다. 앱은 Electron으로 만들었고 서버는 선물하는 사람이 만든 Firebase 프로젝트의 Realtime Database와 Authentication입니다. 키보드 입력 내용, 창 제목, 쓰는 프로그램 이름은 PC 밖으로 보내지 않습니다. 플랫폼과 보안은 8장에서 다루고 계정과 운영은 7장에서 다룹니다.

### 1.2 핵심 사용 흐름

친구가 설정 코드로 처음 앱을 켜고 선물하는 사람과 같은 방에서 함께 작업하기까지의 흐름입니다.

1. **설정 코드로 시작하기** 선물하는 사람이 `npm run account:create -- <이름>`으로 친구 계정을 만들고 출력된 설정 코드와 Windows 설치 파일을 건넵니다. 설치 파일은 GitHub Releases의 `isshoni-hatarakou-Setup-버전.exe`입니다. 친구가 앱을 처음 켜면 설정 코드 입력 창이 뜨고 코드를 넣어 시작하기를 누르면 로그인한 뒤 런처가 뜹니다. 코드가 틀리거나 인터넷이 끊겨 있으면 그 이유를 창 안에 보여 주고 다시 넣게 합니다. 로그인 상태는 PC에 남아서 다음부터는 바로 런처가 뜹니다. 자세한 내용은 7장에 있습니다.
2. **캐릭터 만들기** 런처의 캐릭터 만들기 버튼으로 캐릭터 만들기 창을 엽니다. 1 캐릭터 탭에서 사람이나 동물을 고르고 얼굴 그리기로 앱에 든 기본 몸에 표정과 감은눈을 그리거나 자세 그림 넣기로 기본, 타이핑, 잠듦 자세 그림 세 장을 넣습니다. 동물은 30레벨부터 고릅니다. 2 책상 탭에서 기본 책상을 고르거나 직접 그린 책상 그림을 넣고 저장합니다. 캐릭터 슬롯은 3칸입니다. 자세한 내용은 4장에 있습니다.
3. **작업 프로그램 등록하기** 설정 창의 집중 앱 탭에 작업할 때 쓰는 프로그램을 8칸까지 등록합니다. 등록할 프로그램을 잠깐 쓰고 돌아와 빈 칸의 직전에 쓴 앱 넣기를 누르면 그 프로그램이 들어갑니다. 자세한 내용은 3장에 있습니다.
4. **실행 화면 켜기** 런처의 시작하기를 누르면 런처가 닫히고 실행 화면이 뜹니다. 고른 모니터의 아래 가운데에 캐릭터와 책상이 뜨고 캐릭터 아래에 레벨이 적힌 이름표와 경험치 바와 상태칩이 붙습니다. 실행 화면 창은 포커스를 받지 않아서 작업 프로그램의 키보드 입력을 가져가지 않고 캐릭터와 버튼이 없는 곳의 클릭은 아래 창으로 넘어갑니다. 자세한 내용은 2장과 8장에 있습니다.
5. **작업하면 캐릭터가 깨어나기** 등록한 프로그램이 앞에 있으면 캐릭터가 깨어 있고 포커스 시간이 쌓입니다. 최근 1초 안에 입력이 있으면 타이핑 자세를 취하고 그림 앱이 앞에 있을 때는 이 기준이 4초입니다. 키보드와 마우스 입력이 멈춘 뒤 20분이 지나면 시간이 더 쌓이지 않고 상태가 자리비움으로 바뀝니다. 등록한 프로그램을 쓰지 않으면 캐릭터가 잠듭니다. ▼ 메뉴의 포커스 기록 창은 오늘과 누적과 앱별 시간을 보여 주고 오늘 기록은 한국 시간 오전 6시에 새로 시작합니다. 자세한 내용은 3장에 있습니다.
6. **방 만들고 친구 부르기** ▼ 메뉴나 런처의 방 만들기 / 참여하기 창에서 정원을 2명부터 10명까지 고르고 새 방 만들기를 누르면 6자 방 코드가 생깁니다. 방을 만든 사람이 방 주인이고 방은 주인이 지울 때까지 남습니다. 친구는 받은 방 코드를 코드로 참여하기에 넣어 들어옵니다. 앱을 다시 켜면 마지막 방에 다시 들어갑니다. 자세한 내용은 5장과 9.3의 OUR-01에 있습니다.
7. **같은 방에서 함께 작업하기** 같은 방에 들어가면 친구 캐릭터가 각자의 실행 화면에서 내 캐릭터 옆자리에 앉고 깨어 있음과 잠듦과 고른 상태가 바로 보입니다. 친구 PC의 네트워크가 갑자기 끊기면 150초 안에 그 좌석이 사라집니다. 친구 이름표를 누르거나 캐릭터를 오른쪽 클릭하면 다른 사용자 메뉴가 열립니다. 채팅은 대화하기 창에서 하고 처음에 켜져 있으며 방 주인이 방 설정에서 끌 수 있습니다. 그 방에서 작업한 시간이 방 주인이 정한 시간(기본 60분)만큼 쌓일 때마다 방 가챠를 1회 뽑고 뽑은 아이템은 꾸미기 창에서 캐릭터에 스티커로 붙입니다. 자세한 내용은 4장, 5장, 9.3의 OUR-02에 있습니다.

### 1.3 주요 화면과 창

- **설정 코드 입력 창** 로그인한 적이 없는 PC에서 처음 켤 때 뜨는 작은 창입니다. 닫아도 다시 열리고 앱을 끝내려면 트레이 메뉴의 종료를 누릅니다.
- **런처** 앱을 켜면 뜨는 380x560 창입니다. 캐릭터 미리보기, 이름과 레벨, 시작하기 버튼, 캐릭터 슬롯 카드, 워킹룸 카드, 캐릭터 만들기와 내 정보와 설정 버튼이 있습니다. 내 정보를 누르면 런처 창 안의 화면이 내 정보로 바뀌고 ◀로 돌아옵니다.
- **실행 화면** 시작하기를 누르면 뜨는 투명한 캐릭터 창이고 스테이지라고도 부릅니다. 내 좌석과 같은 방 사람들의 좌석을 감싸는 크기이고 좌석이 늘거나 줄면 창 크기도 바뀝니다.
- **기능 창** 상태칩의 ▼ 메뉴나 런처에서 여는 창입니다. 설정, 포커스 기록, 방 만들기 / 참여하기, 캐릭터 만들기, 꾸미기, 가챠, 보관함, 대화하기, 친구, 마이홈, 플레이리스트, 스티커 사진, 레벨 보상, 상태 고르기 창이 있습니다. 글을 입력하는 창만 포커스를 받고 ▼ 메뉴 맨 아래 `« 런처로`를 누르면 런처로 돌아갑니다.
- **설정 창** 일반, 화면, 집중 앱, 자리 추가, 자리비움 그림, 폰 연결, 계정 탭이 있습니다. 일반 탭에는 기능별 설정 묶음과 자동 실행, 그림 앱 목록, 버전, 진단 기록 폴더 열기가 있습니다.
- **효과 창** 춤추기, 폭탄, 채팅 날리기 같은 연출 동안만 화면 전체를 덮는 투명 창입니다. 클릭은 언제나 아래 창으로 넘깁니다.
- **트레이** 작업 표시줄 알림 영역의 아이콘입니다. 메뉴에는 보이기/숨기기, 위치 초기화, 종료가 있고 Windows에서는 아이콘을 누르면 실행 화면을 보이거나 숨깁니다.

### 1.4 용어집

이 문서와 앱 화면에서 쓰는 용어입니다.

| 용어 | 뜻 | 관련 장 |
|---|---|---|
| 선물하는 사람 | 친구에게 앱을 건네는 사람입니다. Firebase 프로젝트를 만들고 친구 계정을 발급하며 새 버전을 내고 운영 스크립트(`scripts/ops.ts`)로 공지와 편지를 보냅니다 | 7장, 10장 |
| 설정 코드 | 선물하는 사람이 계정을 만들 때 출력되는 한 줄 코드입니다. 친구는 첫 실행 때 이 코드를 넣어 로그인합니다. 코드를 잃으면 선물하는 사람이 새 코드를 만들고 옛 코드는 더 쓸 수 없습니다 | 7장 |
| 런처 | 앱을 켜면 처음 뜨는 창입니다. 시작하기로 실행 화면을 엽니다 | 2장 |
| 실행 화면, 스테이지 | 캐릭터와 책상이 바탕화면 위에 떠 있는 투명 창입니다. 포커스를 받지 않고 캐릭터와 버튼이 없는 곳의 클릭은 아래 창으로 넘어갑니다 | 2장, 8장 |
| 좌석 | 실행 화면에서 캐릭터 한 명이 차지하는 자리입니다. 캐릭터, 책상, 이름표, 말풍선이 함께 움직이고 좌석들은 한 줄로 놓입니다 | 2장, 3장 |
| 기능 창, 패널 | 실행 화면이 여는 설정, 포커스 기록, 대화하기 같은 창입니다. 글을 입력하는 창만 포커스를 받습니다 | 2장 |
| 효과 창 | 연출 동안만 열리는 화면 전체 크기의 투명 창입니다 | 5장, 8장 |
| 상태칩 | 내 좌석에 붙는 작은 버튼 줄입니다. 상태, 방 코드, 대화하기, 우편함, 다가오는 일정, 플레이리스트 버튼과 ▼ 버튼이 있고 상태칩 자리는 설정 화면 탭에서 이름표 아래, 캐릭터 오른쪽, 캐릭터 왼쪽 가운데 고릅니다 | 2장, 3장 |
| ▼ 메뉴, 다른 사용자 메뉴 | ▼ 메뉴는 상태칩의 ▼나 내 캐릭터 오른쪽 클릭으로 여는 기능 창 목록입니다. 다른 사용자 메뉴는 같은 방 사람의 이름표를 누르거나 캐릭터를 오른쪽 클릭해 여는 메뉴이고 친구 신청, 마이홈 보기, 쓰다듬기, 때리기 같은 항목이 있습니다 | 2장, 5장 |
| 이름표, 경험치 바 | 캐릭터 아래에 붙는 이름과 레벨 표시와 다음 레벨까지의 진행 막대입니다 | 3장 |
| 집중 앱 | 쓰는 동안 캐릭터가 깨어 있고 포커스 시간이 쌓이도록 설정 창의 집중 앱 탭에 등록한 프로그램입니다. 8칸입니다 | 3장 |
| 그림 앱 | 일반 탭의 그림 앱 목록에 든 프로그램입니다. 그림 앱이 앞에 있는 동안 캐릭터는 클릭을 받지 않아 펜 선이 끊기지 않고 타이핑 자세 기준이 4초로 늘어납니다. 자주 쓰는 그림 앱은 처음부터 들어 있습니다 | 3장, 8장 |
| 포커스 시간, 포커스 기록 | 집중 앱이 앞에 있는 동안 쌓이는 시간과 그 시간을 오늘, 누적, 앱별로 보여 주는 창입니다. 입력이 멈춘 뒤 20분이 지나면 시간이 더 쌓이지 않습니다. 하루는 한국 시간 오전 6시에 바뀝니다 | 3장 |
| 깨어 있음, 잠듦, 타이핑 자세 | 캐릭터 자세입니다. 집중 앱이 앞에 있으면 깨어 있고 아니면 잠들며 최근 1초 안에 입력이 있으면 타이핑 자세를 취합니다. 친구가 넣은 자세 그림 세 장이 이 세 자세에 쓰입니다 | 3장, 4장 |
| 자리비움 | 입력 없이 20분이 지나거나 상태칩에서 직접 고르면 바뀌는 상태입니다. 머리 위에 자리비움 말풍선이 뜨고 자리비움 그림을 등록해 두면 캐릭터 대신 그 그림이 섭니다. 남의 방에서 자동 자리비움이 6시간 이어지면 1분 전 안내 뒤 방에서 나갑니다 | 3장, 5장 |
| 피규어 모드 | 집중 앱 설정의 하나입니다. 켜면 잠든 모습을 숨기고 포커스 시간은 평소 규칙대로 쌓습니다 | 3장 |
| 회사원 모드 | 설정 화면 탭의 표시 모드입니다. 켜면 머리 위 말풍선, 마이홈, 스티커 사진이 잠기고 소리가 꺼지며 상태칩의 ▪ 버튼으로 실행 화면과 열린 창을 한 번에 숨깁니다 | 2장 |
| 레벨, 회차 | 레벨은 누적 포커스 시간 1시간마다 1 오릅니다. 999레벨분을 채울 때마다 회차가 넘어가 이름표의 Lv. 대신 ☆가 붙고 레벨이 1부터 다시 보입니다. 레벨 보상 창에서 레벨로 여는 기능을 봅니다 | 3장 |
| 캐릭터 슬롯, 자리 추가 | 캐릭터 슬롯은 캐릭터를 저장해 두는 3칸입니다. 자리 추가는 혼자 모드에서 다른 슬롯의 캐릭터를 내 옆자리에 함께 앉히는 설정 창 탭입니다 | 4장 |
| 사람 캐릭터, 동물 캐릭터 | 캐릭터 종류입니다. 동물 캐릭터는 30레벨부터 만들고 다른 사람 캐릭터 머리 위에 올라탈 수 있습니다 | 4장, 5장 |
| 꾸미기, 스티커 | 꾸미기 창에서 보관함 아이템이나 직접 그린 그림을 캐릭터에 붙이는 것이 스티커입니다. 끌어서 옮기고 손잡이로 크기와 회전을 맞춥니다 | 4장 |
