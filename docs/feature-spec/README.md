# Isshoni Hatarakou 기능 명세서

작성일은 2026년 10월 8일입니다.

## 요약

- Isshoni Hatarakou는 친구에게 선물하는 Windows용 데스크톱 작업 메이트입니다. 각자의 바탕화면에 직접 그린 캐릭터를 띄워 두고 같은 방에 들어가면 서로의 캐릭터가 옆자리에 앉으며 작업한 시간이 쌓여 레벨이 오릅니다.
- 기능 215개를 2장부터 8장까지 7개 장에 기능 영역별로 나눠 적었습니다. 기능마다 우선순위(P0, P1, P2, 제외)를 붙이고 앱이 지금 하는 일을 적었습니다.
- 9장에는 범위를 정한 결정, P0 기능만 만든 첫 버전의 모습, 이 앱에만 있는 방 주인과 방별 가챠와 직접 넣는 캐릭터 그림(OUR-01부터 OUR-03까지), 우선순위 표가 있습니다.
- 10장에는 기능 하나를 모듈 폴더 하나로 더하는 구조와 데이터와 서버 설계, M0부터 M5까지의 단계별 구현 순서가 있습니다.

## 0. 이 문서에 대해

### 0.1 목적

Isshoni Hatarakou는 친구에게 선물하는 데스크톱 작업 메이트입니다. 이 문서는 기능마다 앱이 하는 일과 우선순위를 적고 범위를 정한 결정과 구조 설계를 함께 담습니다. 기능 항목의 설명은 지금 코드가 하는 일을 기준으로 적었습니다.

### 0.2 읽는 방법

2장부터 8장까지 기능마다 ID를 붙였습니다. 9장의 OUR-01부터 OUR-03까지는 이 앱에만 있는 기능입니다.

| 접두어 | 장 | 범위 |
|---|---|---|
| SCR, SET | 2장 | 화면, 프로그램 설정 |
| CHR, FOC, GRW | 3장 | 캐릭터 표시, 집중 기록, 성장 |
| AVT, GCH | 4장 | 캐릭터 만들기와 꾸미기, 방 가챠 |
| ROM, COM, FRD | 5장 | 방, 소통, 친구 |
| HOM, SND | 6장 | 마이홈, 소리 |
| ACC, OPS | 7장 | 계정, 운영 |
| NFR | 8장 | 플랫폼과 비기능 요구사항 |
| OUR | 9장 | 이 앱에만 있는 기능 |

기능마다 맨 위에 붙은 표의 우선순위 칸은 아래 뜻입니다. 친구 몇 명이 함께 쓰는 규모를 기준으로 정했습니다.

- **P0** 첫 선물판에 꼭 필요한 기능입니다. 10.12의 M0와 M1에 넣었습니다.
- **P1** 첫 선물판 다음에 바로 더하는 기능입니다. 10.12의 M2a와 M2b에 넣었습니다.
- **P2** 여유가 있을 때 더하는 기능입니다. 10.12의 M3 묶음에 넣었습니다.
- **제외** 선물용 앱에 두지 않는 기능입니다. 항목에는 두지 않는 이유만 적었습니다.
