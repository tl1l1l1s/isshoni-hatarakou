### 2.2 메뉴 트리

화면 사이 이동은 아래 순서를 따릅니다.

1. 처음 실행하면 설정 코드 입력 창이 나옵니다. 선물받은 설정 코드를 넣고 [시작하기]를 누르면 런처가 뜹니다(7장 ACC-05).
2. 앱을 켤 때마다 런처가 먼저 뜹니다. 런처의 [시작하기]를 누르거나 런처 창을 닫으면 실행 화면으로 넘어갑니다.
3. 실행 화면에서 ▼ 메뉴의 [« 런처로]를 누르면 런처가 다시 뜹니다.
4. 기능 창은 ▼ 메뉴 항목, 상태칩 버튼, 런처 버튼으로 엽니다. 앱은 트레이 메뉴의 [종료]로 끕니다.

메뉴 경로는 아래 목록과 같습니다. 괄호 안에는 그 기능을 다루는 장이나 항목을 적었습니다.

### 2.3 화면 디자인

- **무채색과 유리** 창과 버튼은 회색 계열 무채색만 쓰고 강조색도 무채색입니다. 카드와 떠 있는 판은 반투명한 유리 재질로 그립니다. Windows 11(빌드 22621 이상)에서는 창 바탕에 Acrylic 재질을 쓰고 Mac에서는 vibrancy 재질을 씁니다.
- **밝기** 설정 창 [화면] 탭의 [테마]에서 고른 밝기를 모든 창이 따릅니다(SET-05).
- **이름표와 상태칩** 어떤 바탕화면 위에서도 읽히도록 테마와 상관없이 늘 어두운 반투명 바탕에 흰 글자를 씁니다.
- **캐릭터** 캐릭터는 자세 그림, 책상, 바닥 오브제, 책상 소품, 스티커를 층으로 겹쳐 2D 캔버스에 그립니다. 캐릭터와 책상은 배경 없이 바탕화면과 다른 프로그램 위에 바로 나타납니다. [도트 그림으로 보기]를 켜면 좌석을 큰 점과 적은 색으로 그립니다(SET-13).
- **글꼴** 운영체제 기본 글꼴을 씁니다. Windows에서는 Segoe UI와 맑은 고딕을 쓰고 Mac에서는 Apple SD Gothic Neo를 씁니다.

### SCR-02 런처 메인

| 우선순위 |
|---|
| P0 |

- 앱을 켜면 제목이 Isshoni Hatarakou인 380x560 크기의 런처 창이 먼저 뜹니다.
- 위쪽에는 지금 고른 캐릭터의 미리보기가 있고 그 아래에 이름과 레벨이 나옵니다. 이름이 없으면 [이름 없음]이 나옵니다.
- 캐릭터 슬롯 카드의 [◀] [▶]로 캐릭터 3칸 가운데 쓸 캐릭터를 고르고 카드에는 [캐릭터 (1/3)]처럼 몇 번째 칸인지 나옵니다(4장 AVT-15).
- 워킹룸 카드는 방에 없으면 [지금은 혼자 모드입니다.]를 보여 주고 방에 있으면 방 코드와 인원을 보여 줍니다. 카드의 버튼은 방 만들기 / 참여하기 창을 엽니다(5장).
- 맨 아래 줄에는 [캐릭터 만들기] [내 정보] [설정]이 있습니다.
- [시작하기]를 누르거나 런처 창을 닫으면 실행 화면으로 넘어갑니다. 런처가 떠 있는 동안 실행 화면은 좌석을 숨기고 안내 문구만 띄웁니다.

### SCR-03 내 정보 화면

| 우선순위 |
|---|
| P2 |

- 런처의 [내 정보]를 누르면 런처 창 안이 내 정보 화면으로 바뀌고 [◀]를 누르면 런처 첫 화면으로 돌아옵니다.
- 위쪽에는 프로필 사진, 이름, 레벨, [수정], 친구 코드와 [복사], 친구 랭킹이 있습니다. [수정]은 아래 [계정] 탭을 엽니다.
- 친구 랭킹은 나와 친구로 등록한 사람 사이의 평생 레벨 순위입니다. 나보다 레벨이 높은 친구 수에 1을 더해 순위를 매기므로 같은 레벨은 같은 순위입니다. 친구가 한 명 이상이고 내가 1위이면 사진에 왕관과 후광이 붙고 친구가 없으면 [친구를 등록하면 보여요]가 나옵니다.
- 가운데 자리비움 그림 칸은 설정 창 [자리비움 그림] 탭과 같은 화면입니다(3장 CHR-07).
- [보관함] 탭은 가챠에서 뽑은 아이템을 보여 주고(4장) [계정] 탭에서는 프로필 사진과 닉네임을 바꿉니다(7장 ACC-04).
- [휴지통 N] 탭에는 저장하거나 다른 PC와 맞출 때 덮어쓴 캐릭터가 10일 동안 남고 최근 50개까지 나옵니다. [복원]을 누르면 그 캐릭터를 원래 칸에 되돌리고 그 칸의 지금 모습을 휴지통에 넣습니다(7장 ACC-08).

### SCR-04 프로그램 설정 창

| 우선순위 |
|---|
| P0 |

- 런처의 [설정]이나 ▼ 메뉴 구분선 아래 [설정]을 누르면 제목이 [설정]인 420x520 크기의 창이 열립니다. 어디서 열어도 같은 창입니다(SCR-06).
- 탭은 [일반] [계정] [집중 앱] [폰 연결] [화면] [자리 추가] [자리비움 그림]입니다. [일반] 탭을 뺀 나머지 탭은 각 기능의 모듈이 넣습니다.
- [일반] 탭에는 설정 값이 있는 모듈마다 묶음이 하나씩 있습니다. 집중 기록 묶음에는 시간이 쌓이는 규칙과 피규어 모드(SET-02)가 있고 대화하기 묶음에는 채팅 글자 크기(SET-08)가 있습니다.
- [일반] 탭 맨 아래 시스템 묶음에는 [컴퓨터 켤 때 자동 실행](SET-01), 그림 앱 목록(8장 NFR-25), 버전과 [개인정보 처리방침](SET-12), [진단 기록 폴더 열기](SET-11), [이 PC 연결 해제](7장 ACC-05)가 있습니다.
- [화면] 탭의 항목은 SET-03부터 SET-07까지와 SET-13부터 SET-16까지에서 다룹니다. 다른 탭은 7장(계정), 3장(집중 앱, 폰 연결, 자리비움 그림), SET-17(자리 추가)에서 다룹니다.
- 저장 버튼은 없고 값을 바꾸면 바로 저장하고 적용합니다. [화면] 탭과 시스템 묶음의 값은 PC마다 따로 저장합니다.

### SCR-05 실행 화면 개요

| 우선순위 |
|---|
| P0 |

- [시작하기]를 누르면 고른 모니터 작업 영역의 아래 가운데에 투명한 실행 화면 창이 뜨고 내 캐릭터와 책상이 테두리 없이 바탕화면과 다른 프로그램 위에 나타납니다. 창 크기는 좌석 수와 캐릭터 크기와 열린 메뉴에 맞춰 바뀝니다.
- 실행 화면 창은 늘 다른 창 위에 있고 작업 표시줄에 나오지 않으며 포커스를 받지 않습니다. 커서가 캐릭터, 이름표, 상태칩, 메뉴 위에 있을 때만 클릭을 받고 나머지 자리의 클릭은 뒤의 프로그램이 받습니다.
- 좌석마다 캐릭터와 책상 아래에 이름표(상태 점, 이름, 레벨 배지)가 붙고 머리 위에 말풍선이 뜹니다. 방에 들어가면 같은 방 사람들의 좌석이 한 줄로 나란히 놓이고 방 정원은 최대 5명입니다(5장, 9.3 OUR-01).
- 상태칩은 내 좌석에만 붙고 지금 쓸 수 있는 기능 버튼과 맨 끝의 ▼로 이루어집니다(2.2).
- 내 캐릭터를 누르면 쓰다듬고 누른 채 좌우로 흔들면 흔들기를 하며 이름표를 누르거나 캐릭터를 우클릭하면 ▼ 메뉴가 열립니다(5장).
- 트레이 메뉴의 [보이기/숨기기]나 `Ctrl+Alt+H`로 실행 화면을 숨기고 다시 띄웁니다. 캐릭터 자세와 상태 규칙은 3장에 있습니다.

### SCR-07 보조 창 공통 동작

| 우선순위 |
|---|
| P0 |

- 런처, 설정 창, 기능 창은 모두 운영체제 제목 표시줄이 있는 따로 뜬 창입니다. 제목 표시줄로 끌어 옮기고 닫으며 크기는 창마다 정해져 있어서 늘이거나 줄이지 못합니다.
- 처음 여는 창은 화면 가운데에 뜹니다. 창을 닫거나 숨길 때 위치를 창마다 이 PC에 저장하고 다음에 열 때 그 자리에 띄우며 저장한 자리가 지금 모니터 작업 영역 밖이면 가운데에 띄웁니다.
- 이미 열린 창을 다시 열면 새 창을 만들지 않고 그 창을 맨 앞으로 올립니다. `Esc`를 누르면 포커스를 받은 기능 창이 닫힙니다.
- 키보드 입력이 필요한 창만 포커스를 받습니다. 포커스 기록, 이모티콘, 우편함 같은 창은 눌러도 포커스를 받지 않아서 작업 중인 프로그램의 포커스가 그대로 남습니다.
- 플레이리스트 창은 닫아도 숨기기만 해서 음악이 계속 납니다(6장).
- 화면을 숨기면(SET-03) 그때 보이던 창도 함께 숨고 다시 띄울 때 그 창만 돌아옵니다.

- 좌석 캔버스를 점 하나가 3 CSS 픽셀인 해상도로 그리고 색 채널마다 8단계로 줄이며 4x4 Bayer 디더링을 넣은 뒤 키워서 보여 줍니다. 반투명 픽셀은 반을 기준으로 비우거나 채웁니다.
- 런처와 캐릭터 만들기의 미리보기, 자리비움 그림, 효과 창 그림에는 적용하지 않습니다. 값은 PC마다 저장합니다.

### SET-14 머리 위 표시와 이모지 반응

| 우선순위 |
|---|
| P1 |

- 설정 창 [화면] 탭의 [머리 위 표시 (레벨 배지와 말풍선)]를 끄면 내 화면의 모든 좌석에서 이름표의 레벨 배지와 머리 위 말풍선이 사라집니다. 기본값은 켜짐입니다.

### SET-15 상태칩 배치

### SET-16 창 위치 초기화

| P1 |

### SET-17 캐릭터 탭의 크기 항목

| 우선순위 |
|---|
| P1 |

- 캐릭터 크기는 설정 창 [화면] 탭의 [캐릭터 크기] 막대 하나로 정하고 좌석 크기도 이 값을 따릅니다(SET-07, 4장 AVT-12).
- 설정 창 [자리 추가] 탭에서는 방에 들어가지 않았을 때 내 다른 캐릭터를 옆자리에 함께 앉힙니다. [캐릭터 N 앉히기]로 더하고 [빼기]로 빼며 [◀] [▶]로 앉은 순서를 바꿉니다.
