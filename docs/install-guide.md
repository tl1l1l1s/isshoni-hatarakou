Isshoni Hatarakou 설치 안내

1. 아래 주소의 Assets에서 이름이 .exe로 끝나는 파일을 받습니다.
   https://github.com/tl1l1l1s/isshoni-hatarakou/releases/latest
2. 브라우저가 경고하면 파일을 남겨 둡니다. Edge에서는 [유지] → [자세히 표시] → [그래도 유지]를 누릅니다.
3. 받은 파일을 실행합니다.
4. Windows의 PC 보호라는 파란 창이 뜨면 [추가 정보] → [실행]을 누릅니다. [실행] 버튼이 없으면 관리자에게 알려 주세요.
5. 설치가 끝나면 설정 코드 입력 창이 뜹니다. 받은 코드를 붙여 넣고 [시작하기]를 누릅니다.
6. 다음 창에서도 [시작하기]를 누르면 바탕화면에 캐릭터가 나옵니다.

설정 코드에는 계정 비밀번호가 들어 있으니 다른 사람에게 보내거나 보여 주지 마세요. 누가 봤다면 관리자에게 알려 주세요.

사용
1. 작업 표시줄 오른쪽 알림 영역에 동그라미 아이콘이 생깁니다. 안 보이면 위쪽 화살표를 누릅니다.
2. 아이콘을 클릭하거나 Ctrl+Alt+H를 누르면 캐릭터와 열린 창이 사라집니다. 다시 누르면 나타납니다.
3. 창을 모두 닫아도 앱은 켜져 있습니다. 끌 때는 아이콘을 오른쪽 클릭하고 [종료]를 누릅니다.
4. 새 버전은 앱이 받아 둡니다. [다시 시작] 버튼이 뜨면 눌러서 설치합니다.
5. 자동 실행은 처음에 꺼져 있습니다. 켜려면 [메뉴 ▼] → [설정] → [일반] 탭 맨 아래 시스템 항목에서 [PC를 켤 때 자동 실행]을 체크합니다.

삭제
1. [메뉴 ▼] → [설정] → [일반] 탭 맨 아래에서 [이 PC 연결 해제] → [연결 해제]를 누릅니다.
2. 설정 코드 입력 창이 다시 뜨면 아이콘을 오른쪽 클릭하고 [종료]를 누릅니다.
3. Windows 설정에서 [앱] → [설치된 앱]을 열고 Isshoni Hatarakou를 제거합니다. Windows 10에서는 [앱] → [앱 및 기능]입니다.
4. 이 PC에 남은 설정과 기록까지 없애려면 파일 탐색기 주소 창에 %APPDATA%를 입력하고 isshoni-hatarakou 폴더를 지웁니다.
5. 서버에 있는 기록은 관리자에게 지워 달라고 하세요.
