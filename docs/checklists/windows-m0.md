# Windows M0 수동 점검표

메인 프로세스와 platform adapter에 걸린 M0 완료 조건을 친구 PC와 같은 Windows PC에서 직접 확인하는 목록입니다. 패키징한 설치 파일로 시험하고 결과와 실제로 걸린 시간을 ADR에 적습니다.

## 준비

- `npm run dist:win`으로 만든 설치 파일
- 같은 개발 방에 들어갈 두 번째 PC
- 작업 관리자의 세부 정보 탭 (isshoni-hatarakou 프로세스를 모두 더해서 봅니다)
- 1080p 60fps 영상 파일
- 친구가 쓰는 그림 앱과 펜 태블릿

## 화면과 입력

- [ ] 캐릭터 아래에서 1080p 60fps 영상을 전체 화면으로 30분 재생해도 화면이 검어지거나 멈추지 않습니다. 문제가 생기면 환경 변수 `ISSHONI_OPACITY_252=1`을 켜고 다시 시험해 두 결과를 함께 적습니다.
- [ ] 친구 그림 앱에서 펜으로 30분 동안 그려도 선이 직선으로 바뀌지 않습니다. 캐릭터 가까이에서 그린 선도 확인합니다.
- [ ] 그림 앱 캔버스를 아래에 두고 커서를 멀리서 빠르게 캐릭터 위로 옮겨 바로 누릅니다. 20번 반복해도 캔버스에 점이 찍히지 않아야 합니다.
- [ ] 펜으로 캔버스에 선을 긋다가 펜을 감지 범위 밖으로 들어 올려 캐릭터 위에 바로 내려 찍습니다. 캐릭터 위를 지나가는 호버 없이 찍는 것이 핵심입니다. 20번 반복해 캔버스에 점이 찍힌 횟수와 캐릭터가 반응한 횟수를 적고 긋던 선이 끊기는지도 봅니다. Windows Ink를 켠 상태와 끈 상태에서 각각 합니다. 점이 찍히면 클릭 통과 판정을 펜 접촉 단위로 바꿔야 하므로 결과를 ADR에 적습니다.
- [ ] 캐릭터 바깥의 투명한 부분을 누르면 클릭이 아래 창에 그대로 전달됩니다.
- [ ] 캐릭터를 눌러도 작업 중이던 앱이 키보드 입력을 잃지 않습니다.

## 성능

- [ ] 10좌석 장면에서 캐릭터가 깨어 있을 때 CPU 사용률이 5% 이하입니다.
- [ ] 모두 잠든 10좌석 장면에서 CPU 사용률이 2% 이하입니다.
- [ ] 같은 장면에서 isshoni-hatarakou 프로세스 메모리 합계가 400MB 이하입니다.

## 숨기기와 절전

- [ ] 트레이 메뉴의 보이기/숨기기로 스테이지를 10분 숨겨도 다른 PC에서 내 좌석이 남아 있습니다.
- [ ] `Ctrl+Alt+H`를 누르면 스테이지가 숨겨지고 한 번 더 누르면 다시 보입니다.
- [ ] 트레이 아이콘을 왼쪽 클릭해도 스테이지가 숨겨지고 다시 보입니다. 오른쪽 클릭은 메뉴를 엽니다.
- [ ] 배율 100%, 125%, 150%에서 트레이 아이콘 원의 가장자리가 흐리거나 계단처럼 보이지 않습니다.
- [ ] PC를 절전하면 다른 PC에서 150초 안에 좌석이 사라지고 깨우면 다시 나타납니다. 두 시각을 ADR에 적습니다.
- [ ] 화면을 잠갔다가 풀어도 스테이지가 그대로 남아 있습니다.
- [ ] 로그오프가 프로그램 때문에 늦어지지 않습니다. 다시 로그인하면 바꾼 설정이 남아 있습니다.
- [ ] 설정 창 화면 탭에서 테마를 바꾸고 바로 로그오프해도 다시 로그인하면 바꾼 테마가 남아 있습니다. 다시 시작과 종료로도 한 번씩 합니다.
- [ ] 노트북 덮개를 닫아 Modern Standby로 들어갔다가 열면 캐릭터가 자리비움에서 돌아오고 다른 PC에서 내 좌석이 다시 보입니다.

## 모니터

- [ ] 모니터를 연결하거나 뽑으면 잠시 뒤 스테이지가 주 모니터 작업 영역 아래 가운데로 옮겨 갑니다.
- [ ] 디스플레이 배율을 100%에서 150%로 바꾸거나 해상도를 바꿔도 스테이지가 작업 영역 아래 가운데에 다시 놓이고 클릭 영역이 캐릭터와 어긋나지 않습니다.
- [ ] 작업 표시줄을 화면 위나 옆으로 옮긴 뒤 트레이 메뉴의 위치 초기화를 누르면 스테이지가 작업 영역 아래 가운데로 돌아옵니다.
- [ ] 배율이 100%와 150%로 다른 두 모니터 사이에서 캐릭터 모니터를 바꾸면 스테이지가 캐릭터 크기에 맞고 잘리지 않습니다. 그 모니터에서 때리기나 폭탄 효과를 띄우면 효과가 모니터 전체에 맞게 그려집니다. 진단 요약의 스테이지 줄과 모니터 줄을 함께 적습니다.
- [ ] Windows 작업 보기로 가상 데스크톱을 바꿔도 캐릭터가 새 데스크톱에 보입니다. 결과를 ADR에 적습니다.

## 패널 창

- [ ] 패널 창 입력란에 한글을 입력해도 조합 중인 글자가 깨지거나 두 번 들어가지 않습니다.
- [ ] 설치판의 플레이리스트 창과 마이홈 배경음악에서 유튜브 곡이 오류 153 없이 재생되는지 확인하고 결과를 ADR에 적습니다. 설치판의 페이지 출처는 `app://bundle`이고 개발판과 다릅니다.
- [ ] 클립 스튜디오를 전체 화면으로 앞에 두고 ▼ 메뉴로 이미 열린 포커스 기록 창을 다시 열면 그림 앱 위로 올라옵니다. 설정 창처럼 입력란이 있는 창은 다시 열면 바로 글자를 입력할 수 있습니다.
- [ ] 플레이리스트 창을 닫았다가 다시 열면 재생이 이어지고 그림 앱 위에 뜹니다. 보조 모니터에서 닫은 뒤 그 모니터를 뽑고 다시 열면 주 모니터 가운데에 뜹니다.
- [ ] 포커스 기록 창이나 달성표 창처럼 포커스를 받지 않는 창 위에서 마우스 휠과 펜으로 목록을 스크롤할 수 있습니다. Windows 설정의 비활성 창 스크롤을 켠 상태와 끈 상태를 모두 봅니다.
- [ ] 달성표 창의 선택 목록(select)을 펜과 마우스로 열고 다른 값을 고를 수 있습니다.
- [ ] Windows 11 아크릴 패널의 글자가 밝은 바탕화면과 어두운 바탕화면 위에서 모두 읽힙니다.

## 안정성

- [ ] 프로그램을 한 번 더 실행하면 새 창이 생기지 않고 숨긴 스테이지가 다시 보입니다.
- [ ] 작업 관리자에서 스테이지 렌더러 프로세스를 끝내면 몇 초 안에 스테이지가 다시 만들어집니다.
- [ ] `%APPDATA%\isshoni-hatarakou\logs`에 날짜마다 `main-YYYY-MM-DD.log` 파일이 따로 생기고 7일보다 오래된 파일은 다음 실행 때 지워집니다.
- [ ] 스테이지나 패널이 검은 사각형으로 보이면 `%APPDATA%\isshoni-hatarakou`에 확장자 없는 빈 파일 `no-gpu`를 만들고 앱을 다시 켭니다. 진단 요약에 하드웨어 가속 꺼짐이 보이고 캐릭터 둘레가 투명해야 합니다. 시험이 끝나면 파일을 지웁니다.

## M2a 화면 설정

- [ ] 설정 일반 탭에서 컴퓨터 켤 때 자동 실행을 켜고 다시 로그인하면 앱이 스스로 켜집니다. 끄고 다시 로그인하면 켜지지 않습니다.
- [ ] 자동 실행을 켠 채 Windows 설정의 시작 앱(또는 작업 관리자의 시작 앱 탭)에서 isshoni-hatarakou를 끄고 앱을 다시 켜면 설정 창에도 꺼짐으로 보입니다.
- [ ] 모니터 두 대에서 설정 화면 탭의 모니터 버튼으로 보조 모니터를 고르면 캐릭터가 그 모니터 작업 영역 아래 가운데로 옮겨 갑니다. 앱을 다시 켜도 같은 모니터에 뜹니다.
- [ ] 고른 모니터를 뽑으면 잠시 뒤 캐릭터가 주 모니터로 옮겨 가고 다시 꽂으면 고른 모니터로 돌아옵니다. 두 모니터의 배율이 달라도 클릭 영역이 캐릭터와 어긋나지 않습니다.
- [ ] 화면 탭의 캐릭터 크기를 60%와 160%로 바꾸면 캐릭터, 이름표, 레벨 배지, 메뉴 칩이 함께 바뀌고 캐릭터와 ▼ 칩을 누르는 자리가 그림과 맞습니다.
- [ ] 머리 위 표시를 끄면 레벨 배지와 말풍선이 사라지고 이름과 상태 점은 남습니다.
- [ ] 영상 겹침 우회를 켜면 앱을 다시 켜지 않아도 바로 적용되고 진단 요약에 영상 겹침 우회 켜짐이 보입니다. 이 상태로 위 화면과 입력의 영상 시험을 다시 하고 두 결과를 함께 적습니다.
- [ ] 패널 창을 화면 끝으로 옮긴 채 화면 탭의 창 위치 초기화를 누르면 열린 패널이 가운데로 오고 닫았다 다시 연 패널도 가운데에 뜹니다.
- [ ] 친구 그림 앱이 앞에 있어도 캐릭터 위를 누르면 캐릭터가 클릭을 받고 캐릭터 밖의 투명한 부분을 누르면 그림 앱에 그려집니다. 기본 목록에 없는 그림 앱은 일반 탭의 직전에 쓴 앱을 그림 앱으로 넣기로 더한 뒤 같은 시험을 하고 펜으로 30분 그려 선이 끊기거나 직선이 되지 않는지 봅니다.
- [ ] 진단 기록 폴더 열기를 누르면 로그 폴더가 열리고 `diagnose.txt`에 앱 버전, Windows 버전, 모니터 배치, 모듈 켜짐과 꺼짐, 모듈 진단 줄이 있습니다. 창 제목과 채팅 내용은 없습니다.
- [ ] 이름에 🫧와 🪄를 넣으면 이름표와 설정 창에서 빈 네모 없이 보이는지 Windows 10과 11에서 각각 확인하고 결과를 ADR에 적습니다.

## M2a 자동 업데이트

- [ ] GitHub Releases의 낮은 버전 설치 파일로 설치하고 켠 뒤 더 높은 버전의 태그를 올려 release가 끝나기를 기다립니다.
- [ ] 잠시 뒤(최대 6시간, 앱을 다시 켜면 바로) 스테이지 위에 업데이트 안내가 뜨고 다시 시작을 누르면 높은 버전으로 다시 켜집니다. 설정, 캐릭터, 집중 기록이 그대로 남아 있습니다.
- [ ] 안내를 누르지 않고 앱을 껐다 켜도 안내가 다시 보입니다.

## M2a 서버 운영 스크립트

- [ ] `node scripts/backup.ts`를 두 번 실행하면 `~/isshoni-hatarakou-backups`에 오늘 날짜 JSON이 생기고 두 번째 실행은 새 파일 0개라고 적습니다. 선물하는 사람 PC의 예약 작업에 하루 한 번으로 등록합니다.
- [ ] `PROTO`를 올린 버전을 친구가 받은 것을 확인한 뒤 `node scripts/set-min-protocol.ts <번호>`를 실행하면 옛 앱은 방에 들어갈 때 업데이트 안내를 봅니다.

## 설치와 출시

- [ ] 설치 파일을 처음 실행할 때 SmartScreen 경고가 뜨면 추가 정보와 실행을 눌러 설치됩니다. Windows 11에서 스마트 앱 컨트롤이 켜져 있으면 서명하지 않은 설치 파일이 막히는지 보고 결과를 ADR에 적습니다.
- [ ] 이전 버전이 설치된 PC에서 새 버전 설치 파일을 실행하면 설정의 설치된 앱에 Isshoni Hatarakou가 하나만 있고 설정, 캐릭터, 집중 기록이 그대로입니다.
- [ ] 버전 태그를 올린 뒤 GitHub Releases에 그 태그의 릴리스가 하나만 생기고 그 안에 설치 파일, `.blockmap`, `latest.yml`이 모두 있습니다.
- [ ] 저장소 변수 `VITE_FIREBASE_DATABASE_URL`을 비운 채 태그를 올리면 release가 Firebase 주소 확인 단계에서 멈춥니다. 시험용 태그는 끝난 뒤 지웁니다.

## Mac판

Mac판을 만들 때 Mac에서 확인합니다.

- [ ] universal dmg가 Intel Mac과 Apple 실리콘 Mac에서 모두 켜집니다.
- [ ] Dock에 아이콘이 없고 메뉴 막대 아이콘의 메뉴로 보이기와 숨기기를 합니다. 켜져 있는 앱을 Finder에서 다시 열면 숨긴 스테이지가 보입니다.
- [ ] Control+Option+H로 스테이지가 숨겨지고 Cmd+Option+H는 원래대로 다른 앱 가리기입니다.
- [ ] 패널 창에서 Cmd+R을 눌러도 창이 비지 않고 입력란에서 Cmd+C와 Cmd+V가 됩니다.
- [ ] Mac을 종료하거나 다시 시작할 때 앱이 종료를 막지 않고 다시 켜면 바꾼 설정이 남아 있습니다.
