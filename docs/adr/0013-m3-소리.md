# 0013 M3 소리 묶음에서 정한 것

날짜 2026년 10월 9일

SND-03부터 SND-07까지와 COM-03을 sound 모듈에 넣었습니다. 코어는 바꾸지 않았습니다.

## 정한 것

- 플레이리스트는 프리셋 세 개이고 프리셋마다 20곡까지 담습니다. 이 PC에 두는 로컬 기록을 v2로 올렸고 v1의 목록 하나는 프리셋 1로 옮깁니다. 창 제목은 고른 프리셋의 이름이고 이름이 없으면 프리셋 1은 플레이리스트이고 나머지는 프리셋 2와 프리셋 3입니다. 친구 목록을 듣는 동안에는 친구 이름이 들어갑니다.
- 기준 목록은 이 PC에 둡니다. 바뀌고 1초 동안 더 바뀌지 않으면 친구가 읽는 사본을 `mod/sound/u/{uid}/share`에 올리고 앱을 켤 때도 한 번 올립니다. 사본은 `friendsRead` 템플릿이라 본인과 친구만 읽습니다. 프리셋 셋, 고른 프리셋, 소개글, 잠금을 담고 Firebase가 빈 목록을 지워 배열에 빈 칸이 생기지 않도록 프리셋을 `p0` `p1` `p2` 키로 나눠 둡니다.
- 프로필 줄(SND-05)에는 이름, 레벨, 140자 소개글을 둡니다. 프로필 사진과 마이홈 공개 체크박스는 넣지 않았습니다. 공개 프로필에 사진으로 쓸 그림이 없고 마이홈은 언제나 친구에게만 보이기 때문입니다. 친구 목록을 들을 때 친구 이름 버튼을 누르면 그 친구의 마이홈이 열립니다.
- 파도타기(SND-06)는 친구로 등록한 사람만 대상으로 합니다. 잠그지 않은 친구의 프리셋 가운데 곡이 있는 것을 무작위로 하나 고르고 다른 후보가 있으면 지금 듣는 목록은 뺍니다. 잠금은 계정마다 하나이고 파도타기에만 적용합니다.
- 친구 플리 구경(SND-07)은 물결 버튼을 우클릭해 친구를 고르는 방식입니다. 고른 친구의 목록을 내 플레이어에 불러와 첫 곡부터 틀고 잠금과 상관없이 볼 수 있습니다. 처음에는 친구가 고른 프리셋을 보여 주고 고르기 칸으로 다른 프리셋도 봅니다. 친구의 곡을 내 목록에 담는 기능과 두 사람이 같은 곡을 함께 듣는 기능은 넣지 않았습니다.
- 축소 플레이어(SND-04)는 같은 창의 높이를 줄여 플레이어 줄만 남깁니다. YouTube 약관 때문에 영상은 200x200 그대로 둡니다. 창 크기는 패널 문서의 `window.resizeTo`로 바꾸고 Electron이 이 요청을 창 크기에 반영합니다. 줄여도 iframe을 다시 만들지 않으므로 재생이 끊기지 않습니다.
- 채팅 알림음(COM-03)은 소리 파일 없이 WebAudio로 만든 짧은 소리 세 가지입니다. 설정 창 일반 탭의 소리 묶음에서 끄기와 알림음 1, 2, 3 가운데 고르고 고르는 순간 한 번 들려줍니다. 기본값은 알림음 1입니다. chat 모듈은 대화하기 창이 닫혀 있을 때 다른 사람의 메시지를 받으면 bus로 `chat.heard`를 보내고 소리는 sound 모듈이 냅니다. chat에는 `api.ts`의 이벤트 타입과 `state.ts`의 보내는 줄 하나만 더했습니다.
- 표시 모드 `quiet`(회사원 모드)에서는 내 백색소음, 같은 방 사람의 백색소음, 채팅 알림음을 내지 않습니다. 플레이리스트 음악은 그대로 둡니다. 10.5에는 조용한 모드에서 모든 소리를 0으로 둔다고 적혀 있지만 2026년 10월 9일에 선물하는 분이 음악은 계속 나오는 쪽으로 정했습니다. 알림음 설정 값은 바꾸지 않고 소리만 내지 않으므로 모드를 끄면 고른 소리로 돌아옵니다. `hidden`(화면 숨김)에서는 소리를 모두 그대로 냅니다.
- 마이홈 배경음악(HOM-04)을 위해 공개 API `tracks()`와 `play(track)`을 둡니다. 마이홈은 `tracks()`로 내 플레이리스트 곡을 후보로 보여 주고 방문자가 누르면 `play()`를 부릅니다. `play()`는 플레이리스트 창을 열어 그 곡을 틀고 목록에 없는 곡이면 끝난 뒤 멈춥니다.

## 알려진 한계

- 기준 목록이 PC마다 있어서 한 계정으로 두 PC를 쓰면 마지막에 고친 PC의 목록이 친구에게 보입니다.
- 회사원 모드에서도 내 백색소음 종류와 타이핑 여부는 같은 방에 그대로 보냅니다.
- 축소 플레이어 높이는 Mac에서만 확인했습니다. Windows 창 테두리에서도 높이가 맞는지는 친구 PC에서 봐야 합니다.
- 실제 Firebase에서 두 PC 사이의 친구 플리 읽기는 확인하지 않았습니다. 규칙은 에뮬레이터 시험으로 확인했고 화면 흐름은 메모리 서버로 확인했습니다.
- 알림음과 백색소음은 귀로 들어 보지 않았습니다. 검증은 WebAudio 노드를 만든 횟수로 했습니다.
