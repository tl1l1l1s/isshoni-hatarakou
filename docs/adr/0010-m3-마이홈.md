# 0010 M3 마이홈 묶음에서 정한 것

날짜 2026년 10월 9일

HOM-04, HOM-07, HOM-11, HOM-13, HOM-15, HOM-16, HOM-21, HOM-22를 넣었습니다. 코어는 바꾸지 않았습니다.

## 정한 것

- 마이홈 창의 탭은 home 모듈 공개 API `addTab`으로 더합니다(10.6의 `home.tabs`). 탭 화면은 주인 uid와 이름과 내 마이홈인지를 받고 친구 마이홈을 보는 동안에는 읽기 전용으로 그립니다. 보는 사람이 바뀌면 탭 화면을 새로 만들어서 앞 사람에 대한 늦은 결과를 버립니다.
- 친구 마이홈을 보는 동안에는 탭 줄 옆에 내 마이홈으로 돌아가는 버튼이 있습니다. 전에는 [마이홈] 탭을 누르면 내 마이홈으로 돌아왔는데 탭이 늘어서 친구의 스케줄러를 보다가 친구 마이홈으로 돌아갈 수 있게 바꿨습니다.
- 배경음악(HOM-04)은 링크를 따로 받지 않고 이 PC 플레이리스트의 곡 가운데 하나를 고릅니다. sound 모듈에 곡 목록을 읽는 공개 API `tracks()` 하나를 더했습니다. 들어가자마자 소리가 나지 않도록 보는 사람이 ▶를 누를 때만 플레이어를 띄웁니다. 플레이어는 YouTube 약관대로 200x200으로 보이게 프로필 칸 안에 둡니다. 플레이리스트와 배경음악이 함께 재생되는 경우는 막지 않았습니다.
- 마이홈 색(HOM-07)은 일곱 가지 색에서 고르고 기본은 무채색입니다. 고른 색은 마이홈 보기 화면 안의 강조, 채움, 선 색만 바꾸고 프로그램 디자인 테마는 그대로 둡니다. 창 바탕 그림은 바탕화면 영역의 배경 그림처럼 가로 960px 정도로 줄여 64KB 안에 넣고 그 위의 칸에는 반투명한 흰 판을 깔아 글씨가 보이게 합니다.
- 북마크(HOM-11)는 50권까지이고 책마다 제목(14자), http나 https 링크(300자), 책등 색, 책등 그림 하나, 공개 여부를 둡니다. 책장 전체 `shelf`는 주인만 읽고 공개한 책은 같은 쓰기로 `shelfPub`에도 두어 친구가 읽습니다. 책등 그림은 긴 변 400px로 줄여 64KB 안에 넣습니다. 순서는 앞으로와 뒤로 버튼으로 바꿉니다.
- 말랑이(HOM-13)는 걷기와 쉬기를 번갈아 하고 양끝 벽에 닿으면 반은 벽을 타고 반은 돌아섭니다. 벽을 탈 때는 그림 한 장을 90도 돌려 그립니다. 떨어지다 다른 말랑이 머리에 닿으면 올라타서 따라가고 아래 말랑이가 잡히거나 벽을 타면 떨어집니다. 걷다가 앞의 말랑이에 닿으면 밉니다. 짧게 누르면 제자리에서 두 번 뛰고 하트를 띄웁니다. 받은 선물은 받는 순간 내 말랑이가 되므로(HOM-14) 선물 메시지를 머리 위에 띄우는 동작은 없습니다.
- 웹박수(HOM-15)는 방명록 옆 버튼입니다. 친구가 누르면 주인이 고른 이모지(32자까지, 기본 👏)가 터지고 수가 오릅니다. 수는 받은 기록 `in/{보낸 사람}/clap`에 보낸 사람마다 1씩 올리고 주인 화면은 그 합을 보여 줍니다. 10.7.2 표의 `counter` 템플릿을 코어에 더하지 않고 home 규칙의 받은 기록 아래에 한 줄로 넣었습니다. 메모리 서버의 받은 기록 확인을 그대로 쓸 수 있어서입니다. 하루 5번 한도는 규칙 없이 이 PC의 계정 로컬 기록에 마이홈마다 셉니다. 주인이 누르면 이모지만 터지고 수는 그대로입니다.
- 웹박수의 공개 웹 페이지는 만들지 않았습니다. 명세 메모가 앱 안의 박수 버튼만 말하고 데이터는 친구에게만 보이기로 정했기 때문입니다(10.14의 16번).
- 스케줄러(HOM-16), D-day(HOM-21), 다가오는 일정(HOM-22)은 `scheduler`, `dday`, `upcoming` 세 모듈입니다. 일정과 카드는 본인만 읽는 칸(`ev`, `cards`)에 두고 공개한 것은 같은 다중 경로 쓰기로 `pub`에도 써서 친구가 읽습니다. 일정 키는 날짜로 시작해서 키 순서가 날짜 순서이고 날짜를 바꾸면 새 키로 옮깁니다. 날짜는 한국 시간 자정에 바뀌는 달력 날짜이고 포커스 기록의 오전 6시 기준과 다릅니다. 친구가 한두 명이라 친구 태그는 넣지 않았습니다.
- D-day 카드는 20개까지이고 이름, 날짜, 고른 날을 1일째로 세기, 카드 색, 그날 알림 받기, 친구에게 공개를 둡니다. 카드 배경 그림은 넣지 않았습니다.
- 다가오는 일정 창은 오늘부터 7일 뒤까지 내 일정, 친구가 공개한 일정, 내 D-day를 날짜 순서로 보여 주고 상태칩 🔔 배지는 그 수를 셉니다. 오늘 날짜인 일정과 알림 받기를 켠 D-day는 하루에 한 번 `ctx.notify`로 알립니다. 일정을 받거나 바뀔 때와 1분마다 확인해서 앱을 켜 둔 채 날짜가 바뀌어도 알립니다. 설정의 일반 탭에서 끌 수 있습니다.
- 모듈 밖에서 바꾼 파일은 `src/modules/index.ts`(모듈 세 줄), `src/modules/sound/api.ts`(새 파일), `src/modules/sound/index.ts`(setup이 공개 API를 돌려줌), `database.rules.json`입니다.

## 알려진 한계

- 오늘 날짜로 일정을 새로 더하면 그 일정도 바로 알림으로 옵니다. 같은 일정은 하루에 한 번만 알립니다.
- 친구가 나를 아직 친구로 등록하지 않았으면 그 친구의 공개 일정을 구독하지 않습니다. 나중에 그 친구가 나를 등록해도 앱을 다시 켜야 다가오는 일정 창에 보입니다.
- 일정은 날짜가 늦은 쪽부터 300개만 구독합니다.
- 검증 환경에서는 배경음악 플레이어가 200x200으로 뜨는 것까지만 봤고 실제 재생은 확인하지 않았습니다. Windows 알림, 실제 Firebase에서 두 PC 사이의 박수와 공개 일정도 확인하지 않았습니다.
