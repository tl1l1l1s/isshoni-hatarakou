# 0005 M2b에서 정한 것

날짜 2026년 10월 9일

## 정한 것

- 채팅은 방 사람 모두가 씁니다. 방 주인이 방 설정에서 채팅을 켜고 끕니다(기본 켜짐). 서버에는 방마다 최근 100개만 구독해 보여 줍니다.
- 이모티콘은 그림 파일 대신 OS 이모지 글꼴로 그린 12개입니다. 어떤 PC에서 보이지 않으면 그림 파일로 바꿉니다(NFR-22).
- 친구 맺기는 서로 수락하는 방식입니다. 수락 신호만 보내 남의 친구 목록에 들어가는 일을 막으려고 신청한 쪽이 자기 신청이 상대 받은 기록함에 남아 있는지 확인한 뒤에 친구로 적습니다. 친구를 끊으면 내 목록에서만 빠지고 상대는 내 방 코드를 더 보지 못합니다.
- 계정 접속 상태의 `m`(지금 있는 방 코드 등)은 친구에게만 보이고 접속 여부와 마지막 접속 시각은 로그인한 사람 모두가 봅니다.
- 마이홈은 친구에게만 보입니다. 배경 그림은 가로 960px 정도로 줄여 64KB 안에 넣습니다(10.14의 13번). 스티커 10개, 말랑이는 화면에 5마리까지입니다.
- YouTube 삽입 플레이어는 Referer가 없으면 재생을 막아서(오류 153) 허용한 외부 출처로 가는 요청에만 앱 id 주소를 Referer로 붙입니다. 플레이어는 약관에 따라 200x200 이상으로 보이게 두고 YouTube 스크립트는 불러오지 않고 postMessage로 조작합니다.
- 플레이리스트 창을 닫으면 창은 숨기되 재생은 멈춥니다. YouTube 약관이 플레이어를 숨긴 채 재생하는 것을 막기 때문입니다. 목록과 위치는 그대로 남아 다시 열면 이어서 고를 수 있습니다.
- 백색소음은 소리 파일 없이 WebAudio로 만듭니다(빗소리, 타자 소리, 모닥불, 카페). 내가 타이핑하는 동안만 소리가 나고 같은 방 사람의 소리는 종류마다 한 벌만 틀어 사람 수에 따라 음량 비율을 0.5에서 0.9까지 올립니다.
- 상태칩 줄이 좌석 폭을 넘으면 두 줄로 접힙니다.

## 알려진 한계

- 받은 기록함 규칙은 보낸 사람이 자기 칸의 글을 고치거나 지울 수 있게 둡니다. 방명록 글을 쓴 친구가 나중에 자기 글을 고칠 수 있다는 뜻이고 친구 사이라 위험이 작아 그대로 둡니다.
- 채팅 말풍선의 글은 모듈 안 한 곳에 모아 두어서 한 프로세스에서 앱 여러 개를 돌리는 시험에서는 섞일 수 있습니다. 실제 앱은 프로세스마다 하나라 영향이 없습니다.
- Windows 알림 표시와 클릭, 실제 Firebase에서 두 PC 사이의 채팅과 친구 맺기는 아직 확인하지 않았습니다.
