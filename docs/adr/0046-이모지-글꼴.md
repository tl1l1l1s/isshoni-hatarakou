# 0046 이모지 글꼴

날짜 2026년 10월 20일

Windows 10 PC에서 닉네임 끝에 넣은 🫧와 🪄가 설정 창 입력란과 실행 화면 이름표에 빈 네모로 보였습니다(이슈 #9). Windows 10의 컬러 이모지 글꼴 `seguiemj.ttf`에 Emoji 13.0 이후 이모지가 없어서입니다. 이 문서는 OS 글꼴만 쓰던 NFR-22를 바꿔 그 이모지만 담은 글꼴을 앱에 넣은 이유와 확인한 것을 적습니다.

## 원인

- 앱 글꼴 순서는 한국어 글꼴 다음에 Segoe UI Emoji, Apple Color Emoji, Noto Color Emoji를 두고 이모지를 OS 글꼴로 그렸습니다. Windows 10에는 Emoji 13.0 이후 이모지를 가진 글꼴이 없습니다.
- 앱 문구에는 그런 이모지가 없습니다. Unicode `emoji-test.txt`의 Emoji 13.0 이후 코드포인트 136개와 시퀀스 649개를 `src/` 전체와 대조해 하나도 없는 것을 확인했습니다.
- 빈 네모는 사용자가 직접 넣는 글자에서 생깁니다. Mac이나 Windows 11에서 닉네임, 대화, 칠판에 넣은 새 이모지가 Windows 10 친구 화면에서 네모로 보입니다.

## 정한 것

- 관리자가 글꼴을 넣는 쪽을 골랐습니다. NFR-22와 NFR-23을 함께 고쳤습니다.
- 글꼴은 Noto Color Emoji 2.057의 COLRv1판입니다. Emoji 13.0부터 18.0까지 136개를 모두 가진 것은 이 글꼴뿐이었습니다. OpenMoji 17과 Twemoji COLRv0판은 127개였고 Mozilla Twemoji는 93개였습니다. 라이선스는 SIL OFL 1.1이고 예약된 글꼴 이름이 없어서 부분 집합으로 줄여도 됩니다.
- Electron 44.7.0의 Chromium 152는 Windows에서 COLRv1 웹 글꼴을 DirectWrite를 쓰지 않고 직접 그립니다. 그래서 Windows 10에서도 색이 나옵니다.
- 새 이모지만 남긴 부분 집합으로 줄였습니다. 크기는 146,260바이트이고 설치 파일은 0.1.2보다 0.12%쯤 커집니다.
- 피부색과 ZWJ로 이은 묶음은 묶음 전체가 한 글꼴로 그려집니다. Chromium은 묶음 안 글자 가운데 하나라도 앞 글꼴에 없으면 묶음 전체를 다음 글꼴로 넘깁니다. 그래서 새 이모지와 함께 묶이는 옛 코드포인트(U+200D, 피부색 다섯 개, 🏳, 👨, 👩, 🧑, ⚧)도 글꼴과 `unicode-range`에 넣었습니다. `unicode-range`는 부분 집합 글꼴의 cmap 그대로입니다.
- 글꼴 순서에서는 OS 이모지 글꼴 다음, `sans-serif` 앞에 둡니다. Mac과 Windows 11처럼 그 이모지가 있는 OS에서는 OS 글꼴이 먼저 그립니다.
- 부팅할 때 화면을 그리기 전에 `document.fonts.load`로 이 글꼴을 불러옵니다. 글꼴을 불러오기 전에 그린 이모지가 불러온 뒤에도 네모로 남는 경우가 시험에서 나왔습니다. `unicode-range` 글꼴은 범위 안의 글자가 있어야 불러오므로 🫧를 함께 넘깁니다.
- 글꼴을 직접 적은 두 곳도 고쳤습니다. 날리기 채팅 글자는 글꼴을 따로 적지 않고 테마 글꼴을 물려받습니다. 칠판 글씨는 캔버스 글꼴 끝에 OS 이모지 글꼴과 이 글꼴을 붙였습니다. 기능 창 문서는 이 글꼴을 처음 쓸 때 불러오고 캔버스는 글꼴을 다 불러와도 다시 그리지 않습니다. 그래서 칠판 그림판은 그 창 문서가 글꼴을 다 불러오면 다시 그립니다. 스티커 사진의 이모지 스티커 12개는 모두 Windows 10에 있어서 그대로 둡니다.
- 저작권 표시와 라이선스 원문은 글꼴 옆 `OFL.txt`에 두고 `electron-builder.yml`의 `extraResources`로 설치 폴더의 `resources`에 `LICENSE.noto-color-emoji.txt`를 넣습니다. `extraFiles`는 Mac에서 `Contents` 바로 아래에 파일을 두어 서명이 실패해서 쓰지 않습니다. 글꼴 안의 `name` 테이블(라이선스 문구 포함)도 지우지 않았습니다.

## 만드는 법

받은 글꼴과 라이선스입니다. `v2026-09-24-unicode18_0` 태그가 가리키는 커밋입니다.

- `https://raw.githubusercontent.com/googlefonts/noto-emoji/e20cbc2bbec1926686be9f9bee7d1d2cfa1fea0e/2D/fonts/Noto-COLRv1.ttf` (5,038,236바이트, sha256 `b8e25ea68db82f9e4d0aee921f4420be2be39887bd5c893a2ad98710531f9d0c`)
- `https://raw.githubusercontent.com/googlefonts/noto-emoji/e20cbc2bbec1926686be9f9bee7d1d2cfa1fea0e/LICENSE` (sha256 `500bb1ccf43df7bbb522112f9133a52b16e1c35e809632f5d8609b179152de5b`)

fontTools 4.67.0과 brotli 1.2.0으로 줄였습니다. 같은 명령을 다시 돌리면 같은 파일(sha256 `b4ee94f5b4edb6a70e191ccfc281fb19de0cf74d6964299a2ddb9182eb5da826`)이 나옵니다.

```
pyftsubset Noto-COLRv1.ttf --unicodes="200D,26A7,1F3F3,1F3FB-1F3FF,1F468-1F469,1F6D6-1F6D9,1F6DC-1F6DF,1F6FB-1F6FC,1F7F0,1F90C,1F972,1F977-1F979,1F9A3-1F9A4,1F9AB-1F9AD,1F9CB-1F9CC,1F9D1,1FA74-1FA77,1FA7B-1FA7C,1FA83-1FA8F,1FA96-1FAC6,1FAC8,1FACC-1FADD,1FADF-1FAEB,1FAEF-1FAFA,FE0F" --layout-features='*' --name-IDs='*' --flavor=woff2 --output-file=emoji-fallback.woff2
```

새 Emoji 판이 나오면 새 Noto 태그에서 같은 방식으로 다시 만들고 `theme.css`의 `unicode-range`를 새 cmap에 맞춥니다.

## 확인한 것

- 부분 집합에 Emoji 13.0 이후 코드포인트가 모두 있고 COLR v1, CPAL, GSUB 합자와 `name` 테이블이 남아 있습니다.
- e2e 빌드에서 글꼴이 `out/renderer/assets`에 파일로 들어가고 CSP(`default-src 'self'`)에 막히지 않습니다. 부팅 시험(`tests/e2e/boot.spec.ts`)은 런처가 뜬 뒤 실행 화면 문서에서 이 글꼴 상태가 `loaded`인지 봅니다. 화면을 그리기 전에 기다리는지는 시험하지 않습니다.
- 이 Mac(macOS 26.6.2)의 Apple Color Emoji에는 U+1FADD가 없습니다. 이 글자로 실제 글꼴 순서를 시험했습니다. 실행 화면 이름표, 대화 목록, 머리 위 말풍선, 날리기 효과 창에서 CDP가 이 글자를 `Noto Color Emoji`(앱 글꼴)로 그렸다고 알렸고 같은 줄의 다른 이모지는 Apple Color Emoji로 그렸습니다. 이 글꼴만 준 요소에서는 🫧, 🪄, 피부색이 다른 악수, 트랜스젠더 깃발이 모두 이 글꼴의 색 그림으로 그려졌습니다.
- 새로 연 꾸미기 창의 칠판에 U+1FADD를 넣으면 고치기 전에는 키를 하나 더 칠 때까지 빈 네모가 남았습니다. 고친 뒤 다시 확인했습니다.

## 한계

- Windows 10에서 직접 그려 보지 않았습니다. Windows PC 확인 순서는 PR에 적었습니다.
- 옛 코드포인트만으로 이은 Emoji 13.0 이후 ZWJ 묶음(🧑‍🎄, 🐦‍🔥 같은 488개)은 Windows 10에서 지금처럼 나뉘어 보입니다. Segoe UI Emoji가 각 글자를 가지고 있어서 묶음이 이 글꼴로 넘어오지 않습니다.
- Windows 10에서 새 이모지는 Noto 모양이고 옛 이모지는 Windows 모양이라 둘이 섞여 보입니다.
- 창 제목, 마우스를 올리면 뜨는 설명(닉네임 줄임표의 title), OS 알림은 OS가 그려서 이 글꼴을 쓰지 못합니다. 펼친 `<select>` 목록(배경음악 곡 제목, 프리셋 이름)도 이 글꼴을 쓰는지 확인하지 않았습니다.
- Windows 10 `seguiemj.ttf`에 Emoji 12.1 이전 이모지 가운데 빠진 것이 있는지는 이 Mac에서 확인할 수 없었습니다. Windows PC에서 cmap을 읽어 확인합니다.
