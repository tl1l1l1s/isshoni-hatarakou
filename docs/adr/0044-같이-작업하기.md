# 0044 같이 작업하기

날짜 2026년 10월 16일

제안 01(공동 작업 세션)의 첫 버전을 5장 ROM-15 같이 작업하기로 만들었습니다. 같은 방 사람들이 같은 시각에 집중을 시작하고 같이 쉽니다. 이 문서는 데이터 모양, 시각을 다루는 방식, 정한 것과 확인한 것을 적습니다.

## 정한 것

- **모듈 이름:** 새 모듈은 `cowork`입니다. 코어가 이미 방 연결을 `session`(`src/renderer/core/room/session.ts`)이라고 부르기 때문입니다. 코어는 바꾸지 않았습니다. 방 문서, 트랜잭션, 말풍선, 상태칩 슬롯, `ctx.clock.serverNow()`로 만들었습니다.
- **데이터:** 방마다 두 경로를 둡니다. 둘 다 방 사람만 읽고 방을 지울 때 함께 지웁니다.
  - `mod/cowork/r/$room/cur`는 지금 세션 하나입니다. `{ id, by, title, f, b, st, at, go?, v }` 모양이고 `st`는 `wait`, `run`, `stop` 가운데 하나입니다.
  - `mod/cowork/r/$room/parts/$uid`는 각자의 참여입니다. `{ sid, at, goal?, v }` 모양이고 본인만 쓰고 지웁니다.
- **한 방에 세션 하나:** 만들기, 시작, 끝내기는 모두 `cur` 트랜잭션입니다. 규칙은 세 가지 바꾸기만 받습니다.
  - 만들기는 끝난 세션 위에만 새 id로 할 수 있습니다.
  - 시작은 개설자만 시작 전 세션에 할 수 있습니다.
  - 끝내기는 개설자와 방 주인만 진행 중인 세션에 할 수 있습니다.
- **끝은 시각으로 셉니다:** 앱과 규칙이 같은 식으로 끝났는지 셉니다. 아래 셋 가운데 하나면 끝난 세션입니다. 그래서 개설자가 없어도 세션이 끝나고 다음 만들기가 그 위에 씁니다.
  - `st`가 `stop`이다.
  - 시작하고 5초와 집중 시간과 휴식 시간이 지났다.
  - 시작하지 않고 30분이 지났다.
- **진행 중에는 쓰지 않습니다:** 남은 시간은 `cur`의 시작 시각으로 각 PC가 서버 시각에 맞춰 계산합니다. 방에 쓰는 때는 만들기, 시작, 참여, 나가기, 끝내기뿐입니다. 머리 위 남은 분은 분이 바뀔 때 각 PC가 좌석을 다시 그려서 보입니다.
- **시각 칸:** `at`과 `go`에는 서버 시각 표시(`SERVER_TIME`) 대신 `ctx.clock.serverNow()` 값을 씁니다. 규칙은 이 값이 서버 시각과 1분 안인지만 봅니다(코어의 `joinedAt`과 같은 방식). 트랜잭션 안에서 서버 시각 표시가 서버에서 채워지는지는 확인하지 않았습니다. 1분 안 검사는 어느 쪽이어도 맞게 동작합니다.
- **참여자:** `parts`에서 `sid`가 지금 세션 id와 같고 지금 방에 앉아 있는 사람만 참여자로 봅니다.
  - 지난 세션의 참여 기록은 지우지 않아도 세지 않습니다.
  - 앱을 끈 사람은 좌석이 빠지면서 목록에서도 빠집니다.
  - 방을 옮기거나 나오면 앞 방의 내 참여를 지웁니다. 규칙은 방을 나온 뒤에도 내 기록을 지우게 합니다.
- **목표:** 공유를 켠 목표만 `parts`에 씁니다. 켜지 않은 목표는 이 PC의 메모리에만 둡니다.
- **초대:** 방 이벤트를 쓰지 않습니다. 각 PC가 `cur`를 구독하다가 다른 사람이 만든 지 2분 안인 새 세션을 처음 보면 알림을 한 번 띄웁니다. OS 알림은 띄우지 않습니다.
- **개인 뽀모도로와의 관계:** 뽀모도로에 공개 API(`running`, `stop`, `onChange`, `chime`)를 더했습니다. cowork가 뽀모도로를 쓰고 뽀모도로는 cowork를 모릅니다.
  - 개인 타이머가 도는 중에 만들거나 참여하면 끝낼지 묻습니다.
  - 참여 중에 개인 타이머를 시작하면 세션에서 나옵니다.
  - 단계가 끝날 때 소리는 뽀모도로의 끝날 때 소리 설정을 따릅니다.
- **사용자가 고른 것:**
  - 세션을 끝내는 권한은 개설자와 방 주인 둘 다에게 줍니다.
  - 기록 화면은 두지 않고 초대에 OS 알림을 쓰지 않습니다.
  - 소리는 뽀모도로 설정을 같이 쓰고 참여는 시작 전과 집중 중에만 받습니다.
  - 끝난 뒤 결과와 소감, 기지개 같은 캐릭터 반응은 넣지 않습니다.

## 확인한 것

- **단위 시험 7개:** 단계 경계(5초 대기, 집중 끝, 휴식 0분, 30분 대기 만료), 전이 권한, 알림 문구와 1분 기준, 서버 값 검사를 다룹니다.
- **시뮬레이터 시험 3개:** 메모리 서버 하나를 앱 여러 개가 함께 씁니다.
  - 연 사람이 시작하면 참여자들이 같은 끝 시각으로 집중하고 쉽니다.
  - 진행 중 12분 동안 방 데이터가 바뀌지 않습니다.
  - 공유한 목표만 방에 씁니다.
  - 휴식 중에는 참여할 수 없습니다.
  - 동시에 만들면 하나만 남습니다.
  - 개인 뽀모도로를 시작하면 세션에서 나옵니다.
  - 방 주인이 남의 세션을 끝냅니다.
  - 방을 나오면 참여 기록을 지웁니다.
- **규칙 시험 6개:** 에뮬레이터에서 통과했습니다.
  - 방 밖 사람과 남의 이름으로는 만들지 못합니다. 1분 넘게 어긋난 시각과 범위 밖 값도 받지 않습니다.
  - 진행 중인 세션은 덮어쓰지 못합니다.
  - 개설자만 시작하고 개설자와 방 주인만 끝냅니다.
  - 시간이 지나 끝난 세션은 누구나 덮어씁니다.
  - 참여 기록은 내 것만 씁니다.
  - 방 주인은 방을 지울 때 통째로 지웁니다.
- **하네스:** 이 Mac에서 e2e 빌드를 켜고 확인했습니다.
  - 혼자 모드에서는 메뉴 항목이 흐립니다.
  - devdev 방에서 세션을 만들었고 가짜 친구의 참여 기록을 메모리 서버에 써서 넣었습니다.
  - 시작하자 5초 뒤 함께 집중으로 바뀌었고 두 좌석 머리 위에 함께 집중 5분 남음, 칩에 같이 5분이 보였습니다.
  - 개인 뽀모도로를 시작하자 세션에서 나왔습니다. 다시 참여할 때 묻기도 확인했습니다.
  - 세션 끝내기를 누르자 칩이 사라졌습니다.
  - 가짜 친구가 연 세션은 초대 알림과 칩으로 보였고 시작과 세션 끝내기 단추는 없었습니다.
  - 회사원 모드에서는 칩과 머리 위 표시가 숨었습니다.
- **e2e:** windows-smoke에 만들기, 시작, 칩, 끝내기 시험을 하나 더했습니다. 타입 검사, lint, 단위 시험, e2e 전체가 통과합니다.

## 한계

- 실제 Firebase에서 두 PC가 같은 끝 시각을 보는지는 확인하지 않았습니다. 메모리 서버와 에뮬레이터로만 확인했습니다.
- 새 규칙 조각이 생겼으므로 출시 태그를 붙이기 전에 운영 규칙을 먼저 배포해야 합니다. 이전 버전 앱은 세션을 보지 못합니다.
- 앱을 끈 채 세션이 끝나면 그 사람의 참여 기록이 다음 세션을 만들 때까지 남습니다. `sid`가 달라서 세지 않습니다.
- 공유하지 않은 목표는 앱을 다시 켜면 사라집니다.
