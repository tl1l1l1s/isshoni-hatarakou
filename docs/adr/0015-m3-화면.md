# 0015 M3 화면 묶음에서 정한 것

날짜 2026년 10월 9일

SCR-03, SET-03, SET-04, SET-05, SET-08, SET-12, SET-13, SET-15, COM-04를 넣었습니다. SET-04, SET-05, SET-13, SET-15는 10.5의 코어 설정이라 코어 설정과 설정 창 화면 탭에 두었습니다. SET-03과 SET-12도 코어가 그리는 설정 창에 두었고 SET-08과 COM-04는 chat 모듈에, SCR-03은 launcher 모듈에 넣었습니다.

## 정한 것

- 회사원 모드(SET-03)는 설정 창 화면 탭의 체크박스로 켜고 끕니다. `ctx.mode`를 `normal`과 `quiet` 사이에서 바꾸는 화면은 이 체크박스 하나입니다. 회사원 모드에서는 내 화면의 머리 위 말풍선을 모두 숨기고 이름표의 레벨 배지는 그대로 둡니다. 마이홈은 ▼ 메뉴와 다른 사용자 메뉴에서 빠지고 명령도 막힙니다. 켜는 순간 열려 있던 마이홈 창과 스티커 사진 창은 닫힙니다. 막힌 명령이 보여 주는 이유 문장도 회사원 모드라는 이름을 씁니다. 회사원 모드에서 백색소음과 채팅 알림음을 끄는 일은 소리 모듈이 이미 하므로(ADR 0013) 소리 모듈은 고치지 않았습니다.
- 회사원 모드에서는 상태칩에 ▪ 버튼이 생기고 누르면 표시 모드가 `hidden`이 됩니다. 이제 `hidden`은 스테이지와 함께 그때 보이던 패널 창도 숨기고 다시 보일 때 숨긴 패널만 다시 띄웁니다. 트레이의 보이기와 숨기기, Ctrl+Alt+H도 같은 메인 처리를 거치므로 똑같이 동작합니다. 숨긴 화면을 다시 띄우는 방법은 체크박스 설명에 Ctrl+Alt+H와 트레이 메뉴로 적었습니다.
- 테마(SET-05)는 시스템 설정 따르기, 밝게, 어둡게 세 가지입니다. 화면을 무채색과 유리 재질로 깔끔하게 두기로 했으므로 무채색 토큰 안에서 밝기만 고릅니다. 고른 값은 메인 프로세스의 `nativeTheme.themeSource`로 넘기고 그러면 모든 창의 `prefers-color-scheme`이 바뀌어 theme.css에 이미 있는 어두운 값이 적용됩니다. CSS는 바꾸지 않았습니다. 상태칩과 이름표는 어떤 바탕화면에서도 읽히도록 처음부터 어두운 유리라서 테마와 상관없이 같습니다.
- 영상 겹침 우회(SET-04)는 M2부터 화면 탭에 있었습니다. 설명 문장을 다듬고 구분선 아래로 옮긴 뒤 `specIds`에 SET-04를 더했습니다.
- 도트 렌더(SET-13)는 `CharacterView`를 만들 때 넘기는 `ViewOptions.pixel`로 넣었습니다. 값은 점 하나의 CSS 픽셀 크기이고 기능 이름이 없는 그리기 옵션이며 canvas2d backend만 구현합니다. 켜면 좌석 캔버스를 3 CSS 픽셀 점 크기의 해상도로 그립니다. 색 채널마다 8단계로 줄이며 4x4 Bayer 디더링을 넣고 반투명 픽셀은 반을 기준으로 비우거나 채운 뒤 `image-rendering: pixelated`로 키워 보여 줍니다. 내 화면의 모든 좌석에 적용하고 런처와 캐릭터 만들기의 미리보기, 자리비움 그림, 효과 창 그림에는 적용하지 않습니다. debug backend는 이 옵션을 무시합니다.
- 상태칩 자리(SET-15)는 이름표 아래, 캐릭터 오른쪽, 캐릭터 왼쪽 세 가지이고 기본값은 이름표 아래입니다. 옆에 둘 때는 상태칩을 세로 한 줄로 세우고 그 칸의 폭 104 CSS 픽셀만큼 스테이지 창을 넓힙니다. 스테이지 창이 늘 좌석을 감싸므로 보기 좋은 쪽을 고르는 설정입니다.
- 채팅 글자 크기(SET-08, COM-04)는 chat 모듈의 기기 범위 설정입니다. 작게, 보통, 크게, 아주 크게가 12, 13, 15, 18 CSS 픽셀이고 기본값은 보통입니다. 대화하기 창 위쪽의 글자 크기 고르기와 설정 창 일반 탭의 대화하기 묶음이 같은 값을 바꿉니다. 대화하기 창 목록에만 적용하고 머리 위 말풍선은 그대로 둡니다.
- 프로그램 정보와 개인정보 처리방침(SET-12)은 설정 창 일반 탭의 시스템 묶음 아래에 둡니다. 버전은 `app.info`가 주는 값입니다. 처리방침은 웹페이지 대신 펼쳐 읽는 글로 넣었습니다. 서버인 Firebase Realtime Database에 저장하는 것, 규칙에 따라 그 기록을 볼 수 있는 사람, 서버로 보내지 않는 것, 이 PC의 앱 데이터 폴더에 남는 것, 기록을 지우는 방법을 적었고 연락처는 적지 않았습니다. 규칙이나 저장 위치가 바뀌면 `coreModule.tsx`의 `PRIVACY` 문장도 함께 고칩니다. 아직 앱 아이콘이 임시라서 아이콘 제작자 표기는 넣지 않았습니다.
- 내 정보 화면(SCR-03)은 런처 미리보기 아래 줄로 줄였습니다. 이름 옆에 레벨을 보이고 친구 코드가 있으면 그 아래에 친구 코드와 복사 버튼을 둡니다. 전체 랭킹은 친구 두 명에게 쓸모가 적어서 넣지 않았습니다. 보관함과 휴지통은 4장 캐릭터 기능이라 이 줄에 두지 않았습니다. 자리비움 그림은 설정 창의 자리비움 그림 탭에 있고 닉네임은 설정 창 계정 탭에서 바꿉니다.

## 코어 변경

- 코어 설정에 `theme`, `pixel`, `chips`를 더했습니다. 기본값이 기존 화면과 같아서 설정 버전은 올리지 않았습니다.
- 브리지에 `theme.set` 채널을 더했습니다. 기존 채널은 바꾸지 않아서 `BRIDGE_VERSION`은 그대로입니다.
- 메인의 `setVisible`이 패널 창도 함께 숨기고 다시 띄웁니다.
- 렌더링 port의 `ViewOptions`에 `pixel`을 더했습니다.
- 스테이지는 좌석 칸을 늘 한 겹 더 감쌉니다. 상태칩 자리를 바꿀 때 React가 뷰 캔버스가 붙은 DOM 요소를 다른 칸으로 다시 쓰면 캔버스가 좌석 밖에 그려지기 때문입니다.

## 알려진 한계

- 테마는 Mac의 시험 빌드에서 OS 반투명 재질 없이 확인했습니다. Windows 11 Acrylic 창과 Mac vibrancy 창이 고른 밝기를 따라가는지는 실제 빌드로 봐야 합니다.
- 앱을 켠 뒤 코어 설정을 읽기 전까지 설정 코드 창과 첫 화면은 OS 밝기를 따릅니다.
- 영상 겹침 우회는 Windows에서만 효과가 있고 이번에도 Windows에서 확인하지 않았습니다.
- 숨긴 화면을 다시 띄우는 Ctrl+Alt+H는 시험에서 누를 수 없어서 트레이 메뉴와 같은 메인 처리를 불러 확인했습니다.
- 도트 렌더의 점 크기와 색 단계는 고정값입니다. 옅은 색 위에는 디더링 무늬가 눈에 띕니다.
- 런처의 레벨은 growth 공개 API의 평생 레벨이라 2회차부터도 Lv.999로 보입니다.
- 회사원 모드에서도 내 말풍선 내용과 상태는 같은 방 사람에게 그대로 보냅니다. 숨기는 것은 내 화면뿐입니다.
