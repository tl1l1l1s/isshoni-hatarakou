# 0012 자리비움 그림과 자동 퇴장

날짜 2026년 10월 9일

M3 자리비움과 방 관리 묶음(CHR-07, CHR-13, ROM-14)에서 정한 것입니다. 10.3의 11번에 따라 코어에는 기능 이름이 없는 좌석 그림 선언 하나만 더했습니다.

## 정한 것

- manifest에 `seatImages`를 더했습니다. 모듈이 좌석마다 그림 파일과 한 변 길이를 돌려주면 코어가 우선순위가 가장 높은 그림 하나를 캐릭터 몸 대신 세웁니다. 몸은 `detach()`로 숨기므로 책상과 바닥과 이름표는 남습니다. 그림은 아래 가운데를 몸의 발 위치에 맞추고 말풍선과 클릭 영역도 그림 쪽으로 옮겨서 그림을 눌러도 메뉴가 열립니다. 다른 좌석에 올라탔거나 효과로 자리를 떠난 좌석과 로컬 좌석에는 쓰지 않습니다.
- 자리비움 그림은 새 모듈 `awaypic`에 두었습니다. 방 사람들도 보도록 파일 해시와 크기를 presence에 싣는데 status의 상태 글이 최대 60바이트라서 해시 64자를 더하면 모듈 하나의 상한 128바이트를 넘기 때문입니다.
- Spark 요금제를 그대로 쓰려고 그림을 64KB(base64) 파일 한도에 맞춥니다. `prepareImage`로 긴 변을 500px, 400px, 300px 순서로 줄이며 PNG와 WebP 품질 0.92, 0.8을 차례로 시도하고 처음으로 한도에 드는 결과를 저장합니다. 300px WebP 0.8로도 넘으면 등록을 거절하고 이유를 탭에 보여 줍니다. 정사각형으로 자르지 않고 비율을 지켜 정사각형 칸 안에 맞춥니다. 시험에 쓴 600x600 팻말 그림은 500px PNG로 12KB였습니다. 그래서 Blaze로 올리지 않았습니다(10.7.6).
- 크기는 60, 80, 100px 가운데 고르고 기본은 80px입니다. 그림을 등록한 사람이 고르고 방 사람 화면에서도 같은 크기로 보이며 캐릭터 크기 배율을 따릅니다.
- 자리비움이면 자동이든 직접 고른 것이든 그림이 섭니다. 조용한 모드에서는 그림을 숨기고 잠든 캐릭터를 보여 줍니다. 고른 그림은 이 PC의 계정 파일에만 기억합니다. 친구끼리 쓰는 선물이라 자리비움 그림 신고는 만들지 않았습니다(ROM-13 제외).
- 자동 퇴장은 자동 자리비움을 정하는 status 모듈이 맡습니다. 입력 없이 6시간 19분이 되면 자리비움 안내 창을 띄우고 1분 뒤 방에서 나갑니다. 유휴 시간은 OS가 알려 주는 값으로 셉니다. 나가기는 안내를 띄운 때부터 1분 타이머로 해서 안내가 언제나 1분 먼저 뜹니다.
- 상태를 직접 고른 동안(자리비움, 밥 먹는 중, 쉬는 중, 바쁨)에는 내보내지 않습니다. 직접 적은 상태 글은 코어 상태를 바꾸지 않으므로 자동 퇴장 대상입니다.
- 방 주인은 내보내지 않습니다. 주인인지는 rooms 공개 API `isOwner()`로 읽습니다.
- 그림 앱이 앞에 있는 동안에는 내보내지 않습니다. 펜 태블릿 입력이 OS 유휴 시간을 되돌리지 않는 기기에서 그림을 그리는 친구가 방에서 나가지 않게 하려는 것입니다. 그림 앱 판정은 focus 모듈이 펜 앱의 타이핑 판정에 쓰는 활동 샘플의 `pen` 값을 그대로 씁니다. focus 공개 API에는 펜 여부가 없어서 `ctx.activity`를 직접 읽습니다.
- 안내 창에서 취소하면 그때의 유휴 시간을 기준으로 삼아 0부터 다시 세고 자동 자리비움도 풀어 접속 중으로 돌아갑니다. 실제 PC에서는 취소를 누른 입력으로 유휴 시간이 0이 되므로 결과가 같습니다.
- 자동으로 나온 뒤 입력이 다시 오면 그 방에 다시 들어갑니다. 친구가 아침에 돌아와 마우스만 움직여도 방으로 돌아오도록 했습니다(ROM-14). 마지막 방 기록도 지우지 않아서 그사이 앱을 다시 켜도 그 방에 들어갑니다. 그사이 정원이 찼으면 늦게 들어온 쪽이 스스로 나가는 규칙(OUR-01)에 따라 다시 나옵니다.
- ROM-14의 나머지 두 경우인 정원 초과와 다른 PC 로그인은 rooms 모듈(OUR-01)과 코어의 한 계정 한 기기(0007)가 이미 처리합니다.

## 알려진 한계

- Windows에서 펜 입력이 OS 유휴 시간을 되돌리는지 확인하지 않았습니다. 되돌리지 않으면 그림을 그리는 동안에도 20분 뒤 자리비움이 됩니다(CHR-06). 그림 앱 예외는 자동 퇴장에만 두었습니다.
- 그림 앱을 앞에 둔 채 자리를 오래 비우면 방에서 나가지 않습니다.
- 고른 그림은 PC를 다시 설치하면 다시 등록해야 합니다.
- 실제 Firebase와 두 PC에서 그림이 보이는지와 자동 퇴장은 확인하지 않았고 메모리 서버, 시뮬레이터, 가짜 플랫폼에서만 확인했습니다.
