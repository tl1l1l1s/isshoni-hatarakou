# 0003 M2a에서 정한 것

날짜 2026년 10월 9일

## 정한 것

- 동물 캐릭터 해금(GRW-03)은 10.5의 코어 `gates` 대신 wardrobe 모듈이 처리합니다. growth 레벨이 `animalUnlockLevel`(기본 30) 이상이 되면 해금 시각을 wardrobe의 서버 데이터에 남겨 다른 PC에서도 열려 있습니다. gate를 쓰는 기능이 둘 이상 생기면(M3의 춤, 폭탄) 코어 `gates`로 옮깁니다.
- 그림 앱이 앞에 있을 때 따로 다루지 않습니다. 커서가 캐릭터 위에 있을 때만 클릭을 받으므로 그림을 그리는 중에도 캐릭터를 누를 수 있습니다(NFR-25, 10.8.1). 그림 앱에서는 입력 뒤 4초까지 타이핑 자세로 봅니다(CHR-12).
- 좌석 크기(AVT-12)는 기기마다 하나인 화면 크기 배율(SET-07, SET-17)로 대신합니다. 캐릭터마다 크기를 따로 두지 않습니다.
- 직접 적은 상태 글은 코어 상태를 바꾸지 않아서 자동 자리비움을 막지 않습니다. 직접 고른 자리비움은 입력이 들어와도 풀리지 않습니다.
- 머리 위 말풍선은 모듈이 `bubbles`로 선언하고 좌석마다 우선순위가 가장 높은 글 하나만 보입니다. 자리비움 400, 채팅 300(M2b), 고른 상태 200, 오늘 집중 시간 100입니다.
- 방별 가챠의 규칙은 방이 지워졌는지를 코어 `meta/deletedAt` 대신 gacha가 방을 지우기 직전에 쓰는 `tomb/_room`으로 확인합니다. 모듈 규칙 조각이 자기 namespace 밖을 읽지 못하게 한 10.7.2의 검사 때문입니다.
- 뽑기 1회에 필요한 시간은 5분부터 240분까지 고르는 목록입니다. 숫자 칸에 입력하는 도중의 값이 서버에 써지면 잠깐 동안 모두가 싸게 뽑을 수 있어서 목록으로 정했습니다.
- 스티커는 캐릭터마다 12개, 책상 소품도 12개까지 붙입니다. 함께 지우기로 회수된 아이템은 모든 캐릭터 슬롯에서 뺍니다.
- 업데이트 파일을 두는 곳은 0006에서 GitHub Releases로 정했습니다.

## 확인하지 않은 것

- Windows의 자동 실행, 모니터 여러 대, 불투명도 252 우회, NSIS 업데이트 흐름은 실제 기기에서 확인하지 않았습니다. `docs/checklists/windows-m0.md`의 M2a 항목으로 확인합니다.
- 규칙은 자식 항목을 반복해 셀 수 없어서 고친 앱이 뽑기 1회로 아이템 두 개의 개수를 1씩 올리는 것까지는 막지 못합니다. 막으려면 서버 함수(Blaze)가 필요합니다.
