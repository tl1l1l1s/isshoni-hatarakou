# 0008 M3 놀이 묶음 A

날짜 2026년 10월 9일

춤추기(COM-10), 때리기(COM-11), 폭탄(COM-13), 러시안룰렛(COM-14), 깜짝쇼(COM-17), 채팅 날리기(COM-05), 쓰다듬기와 머리 위 반응(CHR-11)은 새 모듈 `play`에 넣었습니다. 커스텀 이모티콘(COM-18)은 기본 이모티콘이 있는 chat 모듈에 더했습니다.

## 정한 것

- 연출은 0007에서 정한 대로 시드를 담은 방 이벤트를 보내고 받은 곳에서 `playEffect`를 부릅니다. 방 밖의 혼자 모드에서는 이벤트를 보내지 않고 이 PC에서 바로 실행합니다. 받는 쪽은 30초가 지난 신호를 버립니다(CHR-11).
- 코어 변경 하나. `playEffect`의 옵션에 `data`를 더했고 효과는 `args.data`로 받습니다. 날리는 글처럼 시드로 정할 수 없는 내용을 넘기는 데 씁니다.
- 코어 변경 둘. 말풍선 `text`가 글 대신 `{ image: 해시 }`를 돌려주면 스테이지가 그 파일을 그림으로 보여 줍니다. 커스텀 이모티콘을 기본 이모티콘과 같은 말풍선에 띄우려고 더했습니다.
- chat 모듈에 공개 API `intercept`를 두었습니다. 대화하기 입력란의 글을 채팅보다 먼저 받고 true를 돌려주면 채팅으로 보내지 않습니다. play가 춤 명령 `/80`, `/150`과 날리기를 이 경로로 받습니다. 날린 글은 대화 기록과 머리 위 말풍선에 남지 않습니다(COM-05).
- 레벨 보상(GRW-02)은 play의 gate 네 개입니다. `play.dance`는 80, `play.bomb`은 100, `play.dance2`는 150, `play.flyColor`는 200이고 growth의 `level`로 엽니다. 모두 sticky라서 한 번 열리면 회차가 넘어가도 열려 있습니다. 레벨 값은 `@modules/play/api`의 `PLAY_LEVELS`에 모아 보상표 화면이 같은 값을 읽게 했습니다. 레벨이 모자라면 메뉴 항목과 버튼을 숨깁니다.
- 캐릭터를 누르면 메뉴가 열립니다(ROM-11). 클릭 동작을 바꾸면 다른 묶음이 쓰는 메뉴 열기가 흔들려서 쓰다듬기는 다른 사용자 메뉴의 항목으로 두었습니다. 그래서 내 캐릭터 쓰다듬기와 캐릭터를 흔들어 어지럽히기는 넣지 않았습니다. 이 결정은 0017에서 바꿨습니다.
- 머리 위 반응(하트, 어지러움)과 러시안룰렛 주사위는 말풍선 하나를 함께 쓰고 채팅보다 위에 보입니다. 잠 반응 z는 잠든 자세 그림에 이미 들어 있어서 따로 그리지 않습니다. 설정 일반 탭의 머리 위 반응 보이기로 하트와 어지러움을 끕니다.
- 캐릭터가 효과 창으로 옮겨 간 동안에는 좌석의 말풍선도 숨습니다. 그래서 어지러움 표시는 납작해졌다 돌아온 뒤나 날아갔다 돌아온 뒤에 띄우고 러시안룰렛은 멈춘 주사위를 잠깐 보여 준 뒤에 날립니다.
- 하루 횟수는 때리기 30번, 러시안룰렛 6번이고 이 PC의 계정 파일에 오전 6시 기준 날 번호로 셉니다. PC 자정과 오전 6시를 섞지 않습니다(COM-14). 친구끼리 쓰는 앱이라 서버 규칙으로 막지 않았습니다.
- 깜짝쇼는 대화하기 창의 같은 춤 명령만 1분 안에 세 번 셉니다. ▼ 메뉴 춤추기는 세지 않습니다. 이유를 모르면 오류로 보일 수 있어서 누가 일으켰는지 방 사람 모두의 화면에 안내를 띄웁니다. 대화 기록에 줄을 남기는 방법 대신 고른 것은 채팅이 꺼진 방에서도 보이기 때문입니다.
- 러시안룰렛은 어느 방에서나 ▼ 메뉴에 있고 대화하기 창에는 🎲를 두지 않았습니다. 폭탄은 다른 사용자 메뉴와 대화하기 창의 💣에서 던지고 💣는 `pickTarget`으로 대상을 고릅니다. 폭탄은 횟수 제한이 없습니다.
- 조용한 모드에서는 날리기 체크를 숨기고 흐르던 글과 연출을 바로 멈춥니다. 러시안룰렛과 폭탄은 누르면 쓸 수 없다는 안내가 뜨고 받은 반응과 주사위 말풍선은 보이지 않습니다. 춤, 쓰다듬기, 때리기는 보내는 것을 막지 않습니다.
- 효과는 캐릭터 그림이나 글자를 DOM 요소 하나에 놓고 Web Animations로 움직입니다. 프레임마다 JS가 돌지 않아 NFR-05에 맞습니다. 날아가는 궤적은 시드로 미리 계산한 점 48개입니다.
- 내 이모티콘은 8칸이고 목록은 공개 프로필 `m.chat.emo`에 두어 다른 PC에서도 같습니다. 그림은 긴 변 128px로 줄이고 48KB 이하 GIF는 움직임을 살리려고 그대로 올립니다. 보내기는 기본 이모티콘처럼 방 이벤트이고 대화 기록에 남지 않습니다.

## 알려진 한계

- 효과 창이 Windows에서 영상 위에 검게 뜨거나 깜빡이는지는 0007과 같이 확인하지 않았습니다.
- 때리기 효과음은 넣지 않았습니다. 소리 모듈이 정하는 몫입니다.
- 실제 Firebase에서 두 PC 사이의 연출은 확인하지 않았습니다. 받는 쪽 동작은 메모리 서버 세션에 신호를 넣어 확인했습니다.
- 화면 크기가 다른 PC에서는 날아가는 캐릭터가 튕기는 자리가 다릅니다. 시드가 같아서 처음 방향과 세기는 같습니다.
- 대상 좌석이 그려지지 않은 PC에서는 그 연출을 건너뜁니다.
