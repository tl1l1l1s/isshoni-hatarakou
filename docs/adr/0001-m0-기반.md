# 0001 M0 기반에서 정한 것

날짜 2026년 10월 8일

## 정한 것

- 의존성은 2주 넘게 지난 안정판으로 고정했습니다. Electron 44.4.5, TypeScript 5.9.3, Vite 7.3.6, electron-vite 5.0.0, React 19.3.0, zod 4.6.5, firebase 12.19.0입니다. TypeScript 6과 7은 typescript-eslint가 아직 받지 않아서 쓰지 않았습니다.
- 프로그램 이름은 10월 9일에 isshoni-hatarakou로 정했고 아이콘은 트레이에서 코드로 그린 임시 도형입니다(9.1 결정 7).
- Firebase 설정값이 없으면 앱은 메모리 서버로 켜지고 기기마다 정한 개발 계정으로 들어갑니다. 설정 코드 창은 Firebase 설정값이 있을 때만 뜹니다.
- 코어 설정 화면과 코어 명령은 `core` 모듈로 등록해서 모듈과 같은 창과 명령 경로를 씁니다.
- npm 11이 설치 스크립트를 막으므로 `package.json`의 `allowScripts`에 esbuild와 get-windows만 허용했습니다. Electron 실행 파일은 `node node_modules/electron/install.js`로 받습니다.

## 측정하지 않은 것

- 패널 창을 `window.open`과 React portal로 그릴 때 Windows에서 포커스와 한글 입력과 스타일 복사가 되는지 확인하지 않았습니다. 실패하면 10.4에 적은 대로 패널마다 렌더러를 따로 두는 방식으로 바꿉니다.
- 클릭 통과, 오버레이 창, 활성 창 감지는 Windows PC에서 `docs/checklists/windows-m0.md` 순서로 확인해야 합니다.
- 10좌석 CPU와 메모리, 연결이 갑자기 끊겼을 때 좌석이 사라지기까지 걸린 시간은 아직 재지 않았습니다.
