# 0006 출시와 업데이트

날짜 2026년 10월 9일

## 정한 것

- 업데이트 파일은 공개로 바꾼 이 저장소의 GitHub Releases에 둡니다. 처음에는 같은 Firebase 프로젝트의 Hosting에 두려 했지만 무료 Spark 요금제의 Hosting은 실행 파일(.exe)을 받지 않아서 바꿨습니다(10.14의 8번).
- 버전 태그를 올리면 GitHub Actions의 release가 설치 파일, `latest.yml`, blockmap을 만들어 같은 이름의 릴리스로 올립니다. 앱은 설치 파일 안의 `app-update.yml`을 읽어 토큰 없이 받습니다.
- 설치 파일은 누구나 받을 수 있지만 선물하는 사람이 스크립트로 만든 설정 코드가 없으면 로그인할 수 없습니다. 설치 파일 안의 Firebase 웹 설정값은 원래 공개되는 값입니다.
- 설치 파일 이름은 주소에 공백이 들어가지 않게 `isshoni-hatarakou-Setup-버전.exe`로 정했습니다.
- 보안 규칙은 `firebase login` 없이 서비스 계정으로 배포합니다(`npm run rules:deploy`).

## 확인하지 않은 것

- Windows에서 업데이트를 받아 다시 시작 버튼으로 설치되는 흐름은 실제 기기에서 아직 확인하지 않았습니다.
