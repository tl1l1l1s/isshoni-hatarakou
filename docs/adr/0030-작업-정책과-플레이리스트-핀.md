# 0030 작업 정책과 플레이리스트 핀

날짜 2026년 10월 11일

기획 명세와 구현을 맞추고, 작업 대상을 그림 작업이나 특정 인원으로 한정하는 표현을 제거했습니다. 집중 기록에는 OS가 식별할 수 있는 모든 종류의 앱을 등록할 수 있습니다. 펜 입력 보호 목록은 집중 기록 목록과 별개입니다. 방 정원은 기존 코드대로 최대 5명입니다.

- 폰 연결은 기존 단축어·MacroDroid의 앱 열림·닫힘 신호를 사용합니다. focus의 외부 활동 여부를 status가 읽어 유효한 열림 신호 동안 자동 자리비움과 퇴장 시간을 초기화합니다. 닫힘·4시간 만료 이후부터 유휴 시간을 다시 셉니다. 수동 상태와 PC 잠금·절전 우선순위는 유지합니다.
- 뽑기 기록에 `earned`를 더했습니다. 정수는 획득 횟수, 소수는 다음 횟수 진행률이며 사용분은 기존 `spent`로 차감합니다. tick 당시 `secPerTicket`으로 계산하고, 변경 전 미전송분도 그 기준을 유지합니다. 서버 변경은 앱이 수신한 시점부터 적용합니다. 기존 기록은 첫 설정 변경 때 고정한 `legacySecPerTicket`으로 한 번 환산하고 기존 사용분 때문에 빚이 생기지 않게 합니다. 초와 획득분은 같은 transaction으로 저장하고 실패하면 둘 다 재시도 목록에 돌려놓습니다.
- 보안 규칙은 획득분 삭제, 시간 없는 획득분 증가, 획득분 없는 시간 갱신, 과다 사용을 거절합니다. 클라이언트가 작업 시간을 계산하는 기존 신뢰 모델은 그대로입니다. 규칙은 변경 전 미전송분을 허용하기 위해 추가 시간 대비 획득분을 허용 시간 기준 범위로 검사합니다.
- 성장 속도는 1시간당 1레벨로 고정하고 과거 누적 전체를 재환산하던 `secondsPerLevel` 조정값을 제거했습니다. 기간 한정 성장 속도 이벤트도 제외했습니다. 다른 해금 조정값과 가챠 아이템의 기간 한정 설정은 유지합니다.
- 진단은 기존 자동 오류 보고 경로를 유지하고 개인정보 안내의 모순을 수정했습니다. 오류 요약과 최근 로그 일부는 선물한 사람의 웹훅 및 서버 제보 기록으로 전송합니다. 전체 진단 파일은 요청 시 직접 전달합니다.
- 플레이리스트의 📌 버튼은 Electron의 `setAlwaysOnTop`을 사용합니다. 기본·축소 화면에서 고정·해제할 수 있고 창을 숨겼다가 다시 열어도 이번 실행의 상태를 유지합니다. 재시작 시 해제하며 독점 전체 화면 위 표시는 보장하지 않습니다. 창 닫기뿐 아니라 전체 화면 숨기기도 재생을 멈추고 다시 열 때 자동 재생하지 않습니다.

## 검증과 배포 주의

- 타입 검사, 린트, 일반 테스트 602개와 에뮬레이터 테스트 165개를 통과했습니다. 기준 변경 전 미전송분, 여러 번 기준 변경, 기존 기록 환산, 동시 뽑기, 보안 규칙을 포함합니다.
- `verify-isshoni`의 기능별 검증 절차를 갱신했습니다. 실제 앱 검증은 가짜 플랫폼·메모리 서버에서 수행하며, 폰 신호·장시간 누적 기록을 준비 데이터로 넣습니다. 유튜브 iframe은 로컬 페이지로 대체해 창 숨김에 따른 일시정지 상태를 확인합니다.
- 실제 앱에서 핀 켜기·끄기와 축소/재열기, 닫기·화면 숨김 후 일시정지, 뽑기 기준 변경 후 진행률 보존과 재열기, 1시간 고정 성장, 폰 신호 종료 후 20분 유휴를 확인했습니다. 각 성공 세션의 `errors.json`은 비어 있습니다.
- 서버 규칙과 앱을 함께 업데이트해야 합니다. 새 기록에 예전 앱이 초만 쓰면 거절됩니다. 운영 서버에는 배포하지 않았습니다. 기존 서버에서 성장 속도를 3600초 이외로 운영했다면 업데이트 전에 누적 시간과 표시 레벨을 점검해야 합니다.
- 실제 Windows 창 고정, 폰 자동화, 유튜브 음성 출력, 운영 웹훅·Firebase 전송은 이번 검증에 포함하지 않았습니다.
