# 0002 M1을 위한 코어 확장

날짜 2026년 10월 8일

10.3의 11번에 따라 둘 이상의 모듈이 쓰는 기능 이름 없는 범용 기능만 코어에 더했습니다.

- `ctx.files.openImage`와 `ctx.files.prepareImage`를 더했습니다. 자세 그림(OUR-03), 책상 그림(AVT-11), 가챠 아이템(OUR-02), 마이홈 배경(HOM-06)이 함께 씁니다. 그림 줄이기는 Web Worker에서 하고 긴 변 320px부터 PNG, WebP 순서로 64KB(base64) 안에 드는 첫 결과를 씁니다. 10.7.2는 256px 정도를 적었지만 좌석이 160x200이라 배율 2배 화면에서 또렷하도록 320px로 시작합니다.
- 슬롯 항목에 `component`를 더하고 `ctx.ui.Slot`을 두었습니다. 이름표(`seat.badge`), 상태칩(`chip.buttons`), 설정 탭(`settings.tabs`), 런처 카드(`launcher.cards`)가 같은 방식으로 들어옵니다.
- `ctx.activity.lastForeignApp`을 더했습니다. 메인 프로세스가 알려 주는 이 앱의 키를 빼고 직전 활성 앱을 줍니다(FOC-01).
- 닉네임은 `users/{uid}/public/name`에 저장하고 부팅 때 읽습니다. `ctx.self.friendCode`는 계정 발급 스크립트가 쓴 친구 코드를 줍니다(ACC-04).
- 방 주인이 방을 지우면 코어가 `deleteWithRoom` 컬렉션을 먼저 지운 뒤 `deletedAt`을 씁니다(OUR-01).
- 메인 프로세스가 패널 창 위치를 `device/windows.json`에 기억하고 트레이의 위치 초기화가 함께 지웁니다(SCR-07).
- 런처 화면(`ctx.app.setMode('launcher')`)에서는 스테이지가 좌석을 숨깁니다(SCR-02).
- presence 필드에 `sync: 'local'`을 더했습니다. 타이핑 자세처럼 내 좌석에만 보이고 방으로 보내지 않는 값입니다(10.7.5 내려받기 비용).
- 입장 실패 결과에 `kind`(blocked, proto, missing, gone, auth, network)를 더해 모듈이 한국어 문장을 비교하지 않게 했습니다.
- 모든 모듈의 setup이 끝나면 `ctx.lifecycle`에 `ready`를 한 번 보냅니다. 자동 재입장이 다른 모듈의 `beforeJoin` 등록 뒤에 일어나게 하려는 것입니다.
- 종료할 때 메인 프로세스가 먼저 `shutdown`을 보내고 렌더러는 모듈에 알린 뒤 저장하고 방에서 나간 다음 끝냅니다. 1.5초 안에 끝나지 않으면 메인이 끝냅니다.
- `ctx.shell.copy`(메인 프로세스 클립보드), `ctx.self.onChange`, `ctx.ui.CharacterPreview`를 더했습니다.
- 정원 확인은 입장한 뒤에 합니다. 처음 들어오는 사람은 규칙상 `roster`에 들기 전에 멤버 기록을 읽지 못하기 때문입니다. 정원을 넘으면 늦게 들어온 사람이 스스로 나가고 그동안 다른 멤버 화면에 좌석 하나가 잠깐 더 보입니다(10.14의 15번).

## 확인하지 않은 것

- 상태칩 안에서 방 코드를 클립보드에 복사하는 동작은 포커스를 받지 않는 창이라 막힐 수 있어 복사는 포커스를 받는 패널에서 합니다.
