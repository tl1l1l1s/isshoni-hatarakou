# 0026 방 정원 5명과 상태칩 정리

날짜 2026년 10월 10일

## 정한 것

- 방 정원은 2명부터 5명까지입니다. 10명까지 두면 좌석이 화면 폭에 맞춰 줄어들어도 바닥이 꽉 찹니다. 선물하는 분이 5명으로 정했습니다. `ROOM_CAP_MAX`와 rooms 규칙의 상한을 5로 바꿨고 기본값 4명은 그대로입니다. 이미 정원을 더 크게 만든 방은 없습니다.
- 상태칩 줄에 항상 보이는 것은 상태, 방 코드, ▼ 셋입니다. 💬는 안 읽은 글이 있을 때, 🔔는 7일 안에 일정이 있을 때, ✉는 안 읽은 우편이 있을 때만 보이고 ♫는 재생 중일 때만 보입니다. 창을 여는 길은 ▼ 메뉴에 그대로 있습니다. 칩이 많아 한눈에 들어오지 않는다는 지적을 반영했습니다.
- 실행 화면 알림은 창 폭이 넓어도 글 길이만큼만 가운데에 띄웁니다. 좌석이 많아 창이 화면만큼 넓으면 알림이 화면 폭의 띠로 보이던 문제입니다.
